# 手段与破法表

戏剧层（DESIGN-戏剧层 5、11，2026-09-27）给戏用页第一问、第三问与第六问用：一个十神当令或透出来的人，多半去要什么、怎么去要、什么事不肯做、盖不住的时候怎么破。十神性格表写的是人的样子，本表写的是人去要东西时的样子，两表叠着用；旺弱的认法与十神性格表相同，以命盘 features 里的 T-（透干）、H-（藏干）、S-（旺衰）与格局判定为准，取这个人最当令、最透的一两个十神。全表自起草，锚点只在《滴天髓阐微》能对上处填。去要什么一栏给的是类，落到书里的哪样东西由编配表定。破有两种：反着来，做了不肯做的那件事；过了头，把惯用的手段用到伤人。本表的破法一栏写的是反着来的那一种，过了头的那一种从怎么去要一栏往重里写。破按这个人自己的常态量，不按嗓门量。本表不产生编号，戏用页引 T-、H-、G- 编号。破的那一栏只写他自己破的样子；另有两种不由他破：别人当面把事摊开，一样东西递到他手上（物证）。戏用页的破另标谁来破，六本女频长篇里后两种是常态，多数一两章完成。
