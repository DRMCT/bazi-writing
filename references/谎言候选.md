# 谎言候选表

谎言是人物对世界的一个错误结论（DESIGN 8.1、8.2）：来源落到童年一件具体的事，形态由忌神格局决定。上半张按忌神格局给三到五条候选，格局由脚本从用神档案认出（yongshen 的 side 与病神 bing.family，从格与调候按 method）；下半张是童年钉法：六到十二岁里年表的哪种机制，谎言就长成什么形状。候选、他真正怕的、露出来的方式各栏是自起草；锚点指向《滴天髓阐微》性情、官杀伤官、六亲、何知章的卡（references/校核/滴天髓_*.md），只作旁证。脚本 bazi_core/lies.py 求值，命中的格局与候选进命盘档案 lies 一节并入 features，编号前缀 LI；模型从候选里挑一条，改写成这个人的话，sources 引 LI- 编号加钉事件的 L- 编号。

## 童年钉法：六到十二岁的机制怎么长成谎言

| 年表机制（六到十二岁） | 钉成什么样的事（自起草） | 孩子得出的结论形状（自起草） | 古籍锚点 |
|---|---|---|---|
| 冲提纲 | 家塌一角：父母失势、家底出事、搬离原来的环境 | 大人靠不住，或家塌了是因为我不够好 | 六亲-父母 |
| 冲日支 | 身边最近的人离开，或自己一场病伤 | 亲近的人会走，身体会背叛我 | 无 |
| 冲年支 | 来历被翻出来：家里的旧事、身份、故乡 | 我从哪里来是件要藏着的事 | 无 |
| 冲时支 | 一个比他小的人（弟妹、伙伴）或他的一件作品出事 | 我留下的东西会害人，或会被夺走 | 无 |
| 天克地冲 | 正面撞击，没有缓冲：一夜之间的变故 | 好日子会在一夜之间没掉，所以别信它 | 岁运-战、岁运-冲 |
| 伏吟 | 同样的事再来一遍：搬了又搬、病了又病、大人反复 | 事情不会变，我也逃不出去 | 岁运-好 |
| 岁运并临 | 那一年把整段童年的好坏压成一年：暴得或暴失 | 好事坏事都是一阵，别当真 | 岁运-好 |
| 换运 | 换地方、换学校、换照顾他的人 | 换了地方就能重来，问题留在原地 | 岁运-总 |
| 合绊用神 | 他最需要的那个人被别的事牵走了：父母忙别人、师长走了 | 我要的东西总在别人那里，要不来 | 岁运-和 |
| 忌神透干 | 威胁公开化：家里的麻烦被外人看见，被指着说 | 被人看见就是被人拿住 | 岁运-战 |
