# 写作层：主题、文风与师承、卷稿、单元会、细纲、写章、读稿、期待账

从人物真相到成章的后半，写的是网文连载：读者一章一章追，每章都要有东西动，读者等的那一刻要真的来，做成一本期待账每章对账。已有：`书/` 的模板（含口味卡、改稿对照）、check-plan 与 check-prose、文体量尺，卷稿、单元会、细纲、写手、读稿、活化润色、炼字（备用）、审计、冷读、师承读法卡与师承汇总的任务书。还没做：追踪表的投影与回纲会的任务书。

写作层读戏剧层的产物：卷稿与单元会读编配、事件链的骨与每一年的源、梗概；细纲、写手、读稿、审计读在场各人的戏用页（`人物/{名}.戏用页.md`，情绪过程在它的第六问，五拍，含破），不读底册与读者本。

## 目录与模板

在项目根下与 `命盘/`、`人物/` 并列，一本书一个项目根：

```
书/
  主题.md               目标读者、主期待、全书一问、乐子（调子与笑从哪来）、开篇（照编配）、命题、两半、叙述结构、装置表（物件、重复句、意象、回声：编号 F001、谁、认法、全书上限、碰的上限）、照抄白名单（律文一类原话）
  文风.md               本书的许可与禁令，十节；写手每章读；末尾阈值表覆盖轮廓表的默认值
  口味.md               作者口味卡：作者要什么、不要什么、手法的分寸，从改稿对照归出；跨书带着，开新书从上一本拷来；活化、读稿、炼字读它；不进公开库
  龙套.md               没有盘的人：称呼、功能、一句、首次出场；不进矩阵不开线程不做选择，做选择就升成只有命盘的配角
  师承/                 作者点的书：{书名}.txt 文本、片段.md（几段原文，写手读）、读法/{书名}/第N章.md 逐章读法卡、读法/{书名}.量尺.md 与 {书名}.章首章尾.md 量尺表（style-stats 产出）、读法/{书名}.md 汇总；作者自备，不进公开库；整个目录是 check-prose 的照抄来源
  卷/卷N.md             卷稿：长跨度的书一卷约主角的一步大运，短跨度与回到关口年照编配的段（事件链的一卷骨）；只到单元，不到章；骨（落下风、破、默认下场）、单元表（来路、两难可空）、发动机、期待线与卷末兑现
  单元/U-N.md           单元会记录：来路（一个热年、一个两难，或一局）、三个走法、作者选的哪个与为什么、兑现一行、章数估计与每章一句功能，章按回合分组
  细纲/第N章.md         一章一页：主视角、时候、位置；意图、赌注、决定、弧（要什么、起承转合）、在场与知情表、场表（时候与地点、转折写成一对正负、读者担心、对面要什么、怎么去要、谁的五拍、碰线、破、感官锚点、落点）、禁放、物件、承接、钩子（类型、停在、章题）、期待一节（开、压、推、兑现、落空、搁置；松紧、调剂、反应层）；场表带视角一栏；不给台词、不写描写句；章号待排时叫 U-N-第K章.md
  正文/第N章.md         正文；只有标题行加正文
  稿/第N章.vK.md        每一稿留底
  稿/试/第N章.{标签}.md 试验稿（几个模型比稿、旁路试写），不进 vK 序列
  会/                   会议记录与代理报告，作者本；一道工序一个子目录，文件名只写对象，第二回加 .第2回（读稿按稿号 .v2），复审加 .复审
    构思/                种子.md、构思.md（第 0 步）
    对手戏/              {甲}-{乙}.md
    冷读/                梗概.md、开篇三章.md、第N章.md；给冷读代理读的材料放 材料/
    现实核/              设定卡.md、卷N.md、第N章.md
    审计/                卷N.md、U-N.md、第N章.md
    读稿/                第N章.md，第二稿起 第N章.v2.md
    活化/                第N章.md（改动表；改后全文落 稿/）
    炼字/                第N章.md（改动表）
    改稿对照/            第N章.md  作者亲手改过的章：原句、作者改成、类、为什么；活化润色的样子
    回纲/                第N次.md  回纲会记录
    留底/                改过的卷稿与单元记录改前留底：卷N.v1.md、U-N.v1.md
    备忘/                一次性的研究、遗留清单、试验记录；改过的本地任务书不留这里（进 skill 或删）
  追踪/在场与知情.json、登记.json、期待.json   JSON 为准
```

开新书把 `$SKILL/references/写作层/模板/` 整目录拷成 `书/`，尖括号里的提示填完删掉；每个文件的字段、谁写、检查器查什么见那里的 README。写法轮廓写在 `主题.md` 的字段行，现在只有 webnovel 一张表；默认值（章长、句尾否定、感叹号、照抄与重复的连串长度、线程闲置章数、期待账的阈值）在 `references/写作层/轮廓.json`，按六本作者认可的女频长篇逐章量过定，`文风.md` 的阈值表逐项覆盖。

## 规矩

- 卷不排到章；单元一次一个，选定再开下一个；细纲写章前一章一议。
- 卷按编配的时间尺度分：长跨度的书一卷约主角的一步大运（卷稿写 D- 编号），短跨度与回到关口年照编配主脑表的段（大运写无）。单元的来路照事件链那一年的源一栏（十种之一：热年出事、默认下场到点、过去追上来、对手出招、家人出招、得知与认出、主角布局、局与日历、旁人求上门、关系自己往前走）；短跨度的书单元多从钟、对手出招、得知里来。两难只在事件链把两难给了的单元写，主角全书一两回，其余给配角、对手、单元客；主角的单元可以是打脸局，看怎么赢。
- 卷稿的骨照事件链这一卷的骨落到单元上，另写两条：编配的每一段主角在哪个单元落一回下风（出手的人与手段从他的戏用页来，几段各不相同）；几个人的破挨在一段里的，谁来破分开。
- 单元会的三个走法必须在谁做选择上不同，不许只是顺序不同；主视角不随走法换，永远是卷稿那一行的人；三个走法换的是这一场哪个人的决定把事推到主视角面前，可以是主视角自己，也可以是别人；别人的决定只写主视角看得见的那一面，主视角自己在每个走法里都要落下一个可以不这样做的决定，两头代价从他自己手里有的东西拿；作者没选（选：待定）不排章，合两个时把合成的顺序写在作者选下面。
- 细纲不给台词、不给固定动作、不给逐点字数；文件里出现引号就是 error。卷稿与单元记录里的引号 warn。
- 口头禅只有一个出处：那个人戏用页附问末问（他怎么被记住）引号里那一句，每人至多一句，要反复出现。主题卡装置表登记它，类型记作重复句，谁一栏写说它的人，一人一行，各设全书上限；细纲物件节写这一章让它落在第几场；写手照细纲写，不自行每章搬；check-prose 照装置表的认法数次数，照抄与跨章重复放行它，细纲没排的章里出现报 warn。回声（一句话、一个人、一个动作隔几十上百章再响）也登进装置表，不设间隔。
- 伏笔物件在 `主题.md` 的装置表登记：编号、认法（正文里认出它的字串）、全书上限、碰的上限。全书上限数认法在正文里出现的次数，提到也算，草蛇灰线要多次、轻、不点破；碰的上限数特写与碰（人去摸、去看、去说它）。细纲的物件节写编号，每个后面写碰还是提到，各章细纲合计不超上限；正文按认法数次数，超了 error；碰的次数读稿按登记表数。
- 计划里出现对标、爽点、公式、榜单一类字样报 warn：写作层不从市场出发。师承不是对标：对标从市场出发，师承从作者读过的书出发，学的是讲法（叙述者是谁、述几演几、情绪怎么写、信息怎么进、章怎么开怎么收），不借句子、情节、人物、意象；文风卡的师承与叙述者两节从它提炼，叙述者一节压过文风卡后面各节：只教人和事长什么样、不教文长什么样，写手就照清单出句。
- 师承是作者认可、想让这本书读起来像那样的书，多半是同类的网文；读法卡另记期待、断章、兑现怎么写三项，汇总多一节连载怎么走（单元几章、兑现隔几章、章尾停在哪几种上、反应写几层）。读法卡另有场内手法一项、汇总另有场内怎么写一节，记一拍怎么写（停几层、旁人心声、登场样子、夸张、接头等），文风卡的情绪怎么写、进内心的许可、接头与停从这里填，不然从师承学到的只有结构。
- 师承什么时候进：开书时与命题、叙述结构一起问作者点书，请作者给文本（epub 或 txt，作者自备，不进公开库），先过导入脚本切章、看报告；师承读法（量尺、读法卡、汇总）在第一份细纲之前做完，可与卷稿、单元会并行，因为叙述者一节管的是细纲的述演比与章长、写手的腔，卷稿与单元会用不着它；回纲会上文风卡可改，师承跟着可改。长书抽样：量尺全跑；读法卡头十章加末五章全做，中间每隔几章一张，让总数落在二十到三十张，抽到的章号写进汇总报告。多本师承：一本一套量尺、卡与汇总，文风卡师承节的书那一行顿号分开列几本，叙述者八行只写一套，汇总时写清各学什么。没有师承：先问作者读过什么、喜欢什么，帮他找出一本；实在说不出，叙述者八行由作者口述、主会话记，不由模型默认填（模型的默认就是查出来有病的那套）。
- 写手一条总则：细纲、戏用页、文风卡上的项目是他知道的事，不是要逐条兑现的清单。写手那一页是正面写法（写什么、怎么写）；机械的限度交给检查器，判断的交给读稿。
- 模型写手很遵循指令：指令里写了的手法它能写好，没写的它不会自己发挥，写出来是一拍接一拍的流水账。所以写手任务书列明那几样最容易缺的手法（感官与心情、刺激与反应、他才会有的反应、聪明归人物、心声口语、接头、停、开脸、旁人一句心声、斗嘴接话头、包袱、看得懂、事实接得上），文风卡给分寸；可光靠规矩教不会"人活不活"，那一层靠作者亲手改过的样子：开书头一章作者改一遍，整理成改稿对照，活化润色代理照它改后面的章（样例书试出：头一章作者改了二十六处，第二章过活化后作者只动一处）。
- 事实接得上：追踪表 `在场与知情.json` 的 facts 一栏记前后要接得上的事实（点了什么、多少钱、谁穿什么、谁在哪），读稿代理提案，进正文后主会话照定稿登，写手照它接；设定卡的时代规矩里写上日常物价与服色，写手、读稿、现实核都照它算。
- 状态卡什么时候生成：写某一年第一章细纲之前，主会话给在场有档案的人生成那一年的状态卡（`人物/状态/{名}/{年}.md`，命令见 `人物层.md` 的 stateyear）；细纲的时候与天气、写手的季节都从它的年景来。
- 登追踪：一章进正文，主会话当场照定稿登三张追踪表：在场与知情（谁新知道了什么、前后要接得上的事实）、登记（装置碰了几回；本章第一次用的比喻、包袱、身体反应与盖法、章尾怎么落，写手下一章不再用）、期待。读稿报告第七节的提案是对着它读的那一稿抽的，定稿改过的照定稿。不登，下一章细纲与写手就不知道前文用过什么，同一个包袱、同一个手势会一章一章再来；check-plan 对进了正文的章查两张表里有没有这一章。
- 跟前几章换开：细纲起草先列前两三章定稿的形状（谁发难、怎么解、反应、决定的样子、身体反应与盖法、包袱与比方句式、章尾），这一章每样换开，对过登记表再排；审计与读稿各问一遍撞不撞；check-plan 报章尾同一种类型连用（轮廓表 sameHookRun）。戏用页第六问的身体先动写部位与方向、盖法写一类手段，不写死一个动作或一句话。
- 上游与正文对不上：已进正文的章与追踪表的 facts 是定下的事实，细纲照它写，偏离单元记录的地方列进交付，回纲会改单元记录。
- 编号后面跟空格或标点，不紧贴汉字；引的 J-、TH-、Q-、L-、D-、E-、DF-、PH- 编号都要在 `命盘/` 下的 JSON 里找得到。

## 期待账

读者一章一章追：每章都要有东西动，章尾停在让人想翻下一章的地方（或者把钩交给下一章），读者等的那一刻要真的来。这一层做成一本账，卷稿登记、细纲逐章写、check-plan 对账、读稿代理从定稿抽成 `追踪/期待.json`。

- 期待：读者在等的一件事（要的东西到不到手、秘密什么时候被谁知道、被看轻的人什么时候翻过来、一对人什么时候说开）。
- 做法六种：开（读者开始等）；压（绷紧：受阻、受辱、被看轻、代价加码、知情差拉大；看着落空其实在压也算）；推（关系或局面往前挪一步，不是压也不是到手，感情线大半靠它）；兑现（等的那一刻来了：翻盘、揭露、到手、突破、说开；揭底，即翻开一件读者没想到要问的事，也算；由旁人转述出来的也算）；落空（没来，换来一个更大的期待）；搁置（让一条长线先睡，写明人物为什么先不动它）。兑现的大小与压了多久、多紧相称。
- 尺度：回合（两到四章）、单元、卷、全书、常驻。常驻是全书不兑现、一直开着的知情差或处境（她不知道别人听得见她、他不知道她是谁），给每一场添味，不查闲置。一章之内开了就收的小循环（一次识破、一句预言当场应验）不登记，细纲里编号写 章内。
- 期限：读者看得见的倒计时（七日内、中秋前、八天凑够一笔钱）；有期限悬着，几章松着也撑得住。
- 期待从哪来：从这本书自己的线里长，不从榜单与公式来。线程埋下是开，压着是压，响是兑现；读者知道、某个人还不知道，是最常用的一种，也是整本书的发动机，每次"谁知道了谁"都是一回兑现；戏用页的他要什么、什么时候破，给出人一级的期待；默认下场年表与编配透的那几条是预告式的知情差：让读者先知道一个人照常会怎样（借传闻、旁人的判断、一个梦、一段旧事），前几条照样应验，再看改没改得了。
- 发动机与交棒：卷稿写这一卷读者主要追的那一条，与卷末交棒给哪一条；长跨度的书换一步大运，发动机多半也换。开篇的那一条用完就交棒，长线可以睡几十上百章，睡之前让人物说清为什么先不动，醒的那一章带一句旧账。
- 调剂：笑、甜、暖、反应（旁人、看客对一句话一件事的反应）。它不是期待，却让人往下读；连着紧、连着松的检查看它。
- 乐子：主题卡写这本书许给读者的调子与笑从哪几处来（主角的性子与嘴、处境与知情差、人和人之间的错认、他爱做的那件事）；卷稿人话页、单元会每个走法、细纲每章都写这一段乐在哪。乐子是局本身好玩，调剂是紧的中间喘一口气，两样不互相顶替；许了轻松调子的书，主角碰到险的第一反应照他的性子写。check-plan 查主题卡有没有乐子一节，细纲期待一节的乐子一栏空了报，连着三章写无报（阈值在轮廓表 funlessRun）。
- 兑现写足：现场可以短，反应要厚：章尾一句落地，下一章开头由近到远写反应（在场的人、旁观的人、更远的人），随即给代价或新的期待，或者让知情差照旧开着。细纲的反应层一栏写到第几层。
- 视角：一场切给谁，写为什么切：误读（把局面读错的人）、知情多（知道得比主视角多的人、对手）、不信（让应验落在他身上）、听见（写他对一句话的反应）、情敌、受害者（主视角不在场）。
- 断章十一种：悬念、危机、反转、期待、情绪、包袱、甜、看客、场中切、兑现收、松收。约一半的章可以不留钩（兑现收、松收），钩交给下一章的章题、下一章开头的反应和一直开着的知情差；章尾多停在一句被人听见的话、一句心声或旁人的反应上。回合（单元章表的回合栏，两到四章一组，给一个名字）是断章的单位：回合里可以松收、场中切，回合的末章要兑现或设钩。章题可以取本章最响的一句，也可以预告兑现。
- 开篇：第一章开出主期待的那一截、立住谁要什么谁挡着；前三章里先给一回兑现（章内的也算，第一章就给更好）；约一万字以内（默认六章）有一回登记过的期待兑现，局面翻过来一回。
- 回声：一句话、一个人、一个动作隔几十上百章再响一回，登进主题卡装置表，不设间隔。
- 内心：主视角的短心声、吐槽随处可以放；关系转折、揭底、回忆的章给整块内心，男方、配角、对手也可以；一句对白后面可以跟在场几个人各一句心声。
- 落到哪：构思的长篇盘子写主期待；编配的开篇写开篇三章；主题卡写目标读者、主期待、全书一问与开篇；卷稿写发动机、期待线与卷末兑现；单元会作者选下写兑现，章表分回合；细纲写期待一节、视角、钩子；写手把兑现那一回写足、压的不提前泄、章尾照钩子的类型落；读稿与审计各有期待一问；冷读有开篇三章冷读；追踪有期待账。
- check-plan 对账（全报 warn，跑过一本真书再定哪几条升 error）：期待线的编号、尺度、期限，发动机与卷末兑现，单元的兑现；细纲期待一节的编号与做法、松紧、调剂、搁置的理由、钩子类型；第一次出现要是开，兑现以后不再出现（新的期待另起编号）；回合与单元尺度的期待隔八章没人动报，卷与全书尺度的不按章数查、隔三十章以上再碰提醒带旧账，常驻的不查，搁置以后不查；第一章一个登记过的期待都没开、前三章没有兑现、前六章没有登记过的期待兑现；连着紧六章以上又没有调剂、连着三章以上没兑现没推没调剂又没有期限悬着、连着三章以上不留钩、章尾连着三章同一种类型、回合末章停在场中切或松收上、空章、卷稿期待线里没有的编号。检查器只管账，不定每几章一回兑现：间隔由这本书自己的线定，够不够由读稿与作者看。

## 代理与额度

问作者的只有故事的事：裁卷稿、选走法、定命题与叙述结构、点师承（读过什么、想让书读起来像谁）、裁存疑的事实。工具的事不问：用哪个模型、起几个代理、跑不跑检查，按下面的默认走，事后报个数。

任务书是清单，不是代理的数目。代理分三类：必须分开起的，单元会的三个走法（三个各写一个，同一个脑子写不出三个真不同的）与写手读稿（不让同一个模型给自己的稿子打分）；核查类，审计、现实核、因果逐环，必须起子代理，主会话写的东西不由主会话自己核，额度紧也不省这一道；模型按"低一级"自动挑：主会话 Fable 用 Opus 核，Opus 用 Sonnet 核，主会话本来就是 Sonnet 的还用 Sonnet、另起一个干净上下文的子代理，不用 Haiku；换的模型只要求不是写它的那个脑子，不要求更强，判断重的题（像不像这个人、两头疼不疼）存疑多时再换高一级复核一遍。核查在产物落盘后自动起，报告落 `书/会/` 下那道工序的子目录，主会话只把末尾三句话用人话转给作者；起草类，档案、事件链、卷稿、裁决，起不起只看主会话的上下文够不够，不是多一道工序。逻辑审查不另起代理，因果逐环是审计各层都问的一问、现实核的一项。参考开销（两本样例书实测，一个代理一次；八个人的书，人头上的那几行乘八）：

| 工序 | 模型 | token | 时间 |
|---|---|---|---|
| 构思会，三个起草者 | Opus | 各七到九万 | 三到六分钟 |
| 命局段，一人 | Opus | 十四到十六万 | 六七分钟 |
| 编配会，三个起草者；合版一个 | Opus | 各二十六七万；合版二十万 | 十五分钟；九分钟 |
| 戏用页，一人 | Opus | 十五到十七万 | 四五分钟 |
| 事件链 | Opus | 四十五万 | 三四十分钟 |
| 梗概；冷读 | Opus；Sonnet | 十五万；六七万 | 六分钟；一分钟 |
| 年份段，一人 | Opus | 二十一到二十四万 | 七八分钟 |
| 现实核 | Sonnet 或 Opus | 十一到二十万 | 六到十五分钟 |
| 师承读法卡，三四章一个代理 | Sonnet | 十三到十六万 | 五到九分钟 |
| 师承汇总，一本 | Opus | 二十万 | 十分钟 |
| 卷稿；卷稿审计 | Opus | 各二十万 | 十分钟 |
| 单元会，三个走法 | Opus | 各十三到十六万 | 三四分钟 |
| 细纲；细纲审计 | Opus；Sonnet | 十七万；十九万 | 八分钟；十分钟 |
| 写手，一章 | Opus | 十五万 | 十分钟 |
| 读稿，一章 | Sonnet | 十九到二十二万 | 十到十四分钟 |

合起来看：一个人从命局段到年份段约四十万；一本师承抽二十七章做卡，约七个读法卡代理加一次汇总，一百二三十万，开书时最大的一笔；正文每章细纲、审计、写手、读稿四道约七十万。活化润色与对手戏测试没记开销。

## 检查

计划（整个书目录，或单个文件；`--root` 指项目根，默认书目录的上一级；编号池从 `命盘/` 下全部 JSON 收，人名与生年从 `人物/`、`命盘/`、年表收；`--threads` 默认取 `命盘/群像/线程.json`，开着的线程（埋、压，旧文件的悬置）的 `chapters` 字段几章没动超阈值报；编配的时间尺度读 `命盘/群像/编配.json`，卷该写大运还是段按它报）：

```bash
node "$SKILL/scripts/check-plan.js" 书/
```

细纲另与同号单元记录、在场各人的戏用页比十字以上连串（照抄阈值加二，编号抹掉再比），重合报 warn：细纲的字会被写手搬进正文，上游原句也就一路传下去。

别的套装的卷纲、细纲用 `--loose`：不认模板字段，只查引号、编号、借鉴字样、逐点字数。期待账按上面一节对。

正文（一章一跑；路径在 `书/正文/` 下时自动配对同号细纲、文风、主题、`../人物/*.戏用页.md` 与 `*.读者本.md`、章号更小的前几章；查引号照抄（与细纲、戏用页、读者本、文风卡、额外来源做八字以上连串比对，人名折成一个字，连串不跨段，白名单、装置表的重复句与回声、戏用页那一句口头禅放行；与细纲重合不到十二字只报 warn，细纲写的是事项，写手照事实写难免撞短串；师承里出现三次以上的连串算通用语不报，`师承/读法/` 下的卡与汇总不算来源）、跨章重复（六字以上，人名不计长度）、句尾否定的数与比例、双否定、叙述里每千字的感叹号、省略号、破折号（引号与【】里的对白、心声、屏上文字不数，单独成行的分隔符与引出对白的破折号也不数）、装置次数（重复句出现了、同号细纲没排它报 warn）、字数出了章长范围、句长段长）：

```bash
node "$SKILL/scripts/check-prose.js" 书/正文/第4章.md
```

目录不是 `书/` 形状时逐项指定，几章一起给时前面的章自动当后面的前文；`--source` 加导出卡一类的额外来源，`--banned` 加去味词表：

```bash
node "$SKILL/scripts/check-prose.js" 正文/第1章.md 正文/第2章.md --plan 大纲/细纲_第001章.md --plan 大纲/细纲_第002章.md --style 设定/文风.md --theme 书/主题.md --cards 人物/ --source 设定/角色/
```

师承文本导入（作者点完书、给了 epub 或 txt 之后的第一步；量尺与读法卡都按它切出的整行"第N章"走）：

```bash
"$SKILL/.venv/Scripts/python" "$SKILL/scripts/import_shicheng.py" 原书.epub --name {书名} --out 书/师承   # txt 也行；产物 {书名}.txt，有就另出 .番外.txt、.简介.txt
```

epub 按页一章，txt 按整行标题（第N章、第N回、001：标题）切；简介、番外、作者有话说、求票与站点水印另放或清掉，重新编号从 1 起。看 stdout 那一行报告再往下走：章数与原书对不对，断号与重号（gaps、dups）、特别短与特别长的章、正文里像章标题的行（strayHeadings）、清掉的杂行（noise）、丢掉的短页（dropped）。章号藏在正文里或标题怪的书，给 `--split` 整行正则，全书按它切；`--dry-run` 只报不写。报告看着不对就换 `--split` 或手修原文再跑，别带着切错的章去量。

文体量尺（师承文本逐章、或一章稿子对师承；词表在 `references/写作层/套话.json`）：

```bash
node "$SKILL/scripts/style-stats.js" 书/师承/{书名}.txt --md          # 逐章：句长分布、段长、对白占比、句尾否定、体感、比喻词、语气词、标点，末两行中位数与范围
node "$SKILL/scripts/style-stats.js" 书/师承/{书名}.txt --ends --md   # 章首章尾表
node "$SKILL/scripts/style-stats.js" 书/稿/第N章.v1.md --against 书/师承/{书名}.txt --md   # 本章对师承，出界的标出
```

去术语照旧 `check-terms.js 书/正文/`。检查器只报机械的；真两难、删章测试、选择还是遭遇归审计代理，任务书在 `$SKILL/references/写作层/任务书/审计.md`，同目录还有卷稿、单元会（三走法各一个子代理）、细纲（起草一章）、写手（一页纸，写一章）、读稿（只读，换模型）、活化润色（照作者改稿对照改一遍人活不活，出改后全文与改动表，干净上下文）、炼字（备用，只出改动表）、师承读法卡（逐章，三到五章一批，Sonnet 够）、师承汇总（读数、读卡、读三章，写文风卡两节与片段提案）的任务书；写章：写手落 `稿/第N章.v1.md`，读稿代理报告落 `书/会/读稿/第N章.md`（事实接不接得上、哪句要猜才懂），作者定改不改，写手改；改定的稿交活化润色代理（任务书 `活化.md`，干净上下文），它照作者的改稿对照与口味卡改一遍，改后全文落下一稿、改动表落 `书/会/活化/第N章.md`；作者读改后全文，再动的地方补进改稿对照，定稿复制到 `正文/`。开书头一章不走活化：读稿、写手改过以后作者亲手改一遍，主会话照模板整理成 `书/会/改稿对照/第1章.md`、归进 `书/口味.md`，从第 2 章起活化照它改。炼字（只出改动表）是备用的一道，作者读活化稿觉得字啰嗦、不准再叫。讲述顺序与故事顺序脱开：主题卡的叙述结构一节定正叙、倒叙、双线、框架或多视角，单元记录的章表按它填位置栏，章号是全书的格子号，各单元合起来不许重号（check-plan 查）；不是正叙的书，主题卡叙述结构下有一张插入表（现在时分段、每段后面插哪几个回忆单元），填完之前各单元章号按单元内序号、位置栏写待排、不查全书重号，填完统一改格子号、细纲跟着改（双线书的现在时常在后面的卷，前面的单元开会时排不出格子号）。
