# 写人物档案

人物档案 `人物/{角色}.json`（bazi-character/v1）怎么写、阶段状态卡怎么写、写完怎么查。命令与脚本输出怎么读在 `人物层.md`。

## 档案的形状与各段写法

写 `人物/{角色}.json`，形态 `bazi-character/v1`（见 `$SKILL/scripts/character_render.py` 文档串）：

- 必备段落十三个：性格表里、童年事件、谎言、秘密、需要与想要、抵抗线、亲密关系模式、说话方式、能力与漏洞、意象系统、他人眼中的他、年表与两难、阶段状态。字段在场、值可以待补充（traits 或 stages 空列表）。
- 设定卡：档案顶层 `setting`，作者每个项目填一次，写任何段落都照它落词。`period` 必填，取 古代、近代、现代、未来、异世界；`world` 一句话说清时代与世界；其余九个槽位是传统词对应的社会位置，缺的算待补充，检查器只认这十一个键：

  | 槽位 | 传统落法 | 现代都市的落法 | 八字来源 |
  |---|---|---|---|
  | authority 权力与规矩落在哪 | 朝廷官府、家法 | 单位与体制、领导的一句话 | 官杀、事业与权力领域 |
  | elders 上一辈是谁 | 长辈、宗族 | 父母、导师、老领导 | 印、月柱、天乙贵人 |
  | union 结合的形式 | 婚约、成婚 | 恋爱同居、领证可离 | 日支、感情领域 |
  | inlaws 伴侣那边的人 | 夫家、妻家、外家 | 对方父母 | 阴差阳错一类神煞 |
  | path 体面的路 | 仕途、功名、科举 | 学历、考编、升职 | 官印相生、文昌 |
  | legacy 家底与留下的东西 | 祖业、门楣、子嗣 | 房子、存款、人脉 | 年柱、时柱、创造与传承 |
  | money 钱怎么来 | 田产、俸禄 | 工资、副业 | 财星 |
  | output 拿得出手的东西 | 文章、手艺 | 作品、代码、内容 | 食伤 |
  | rules 时代规矩 | 律例、家法、科举的章程 | 校规、单位的规定、政策与房价 | 无；主代理照常识起草，换一个模型按 `references/任务书/现实核.md` 核过再用 |

  时代规矩写的是那个时代这类人什么能做、什么会被罚、罚到哪一步、钱是什么数目，另写两样写正文时最容易错的：日常物价（一碗饭、一碟点心、一身衣裳多少钱，力工一天挣多少，与大数目的比例）和服色（什么人许穿什么颜色与纹样，哪些色是忌讳）；真实年代的书对着史实与现实核，架空的书只核它自己立的规矩（现实核任务书按时代换打法）。两难的两头只能从人手里有的东西里拿（阶段卡第八面"手里有什么"：书生是功名束脩婚约，军户是田户帖军功，学生是学籍名额生活费，职员是编制房位置，架空按设定卡立的那几样），两难模板给的是形态不是词：一个学生没有家可倾，一个没有功名的人押不了功名。

  规则表的译法栏写的是功能位（上一辈、伴侣那边的人、家底、体面的路），不写机构；写档案时按设定卡把功能位落成机构词，一跳到位。设定卡是古代就照古代落（长辈、妻家、仕途都能写），是现代就落成现代词，别把功能位又翻回古代；神煞标签里带"旧书说"的行是古籍原判，按设定反用或弱化。样例 `examples/沈砚/人物/沈砚.现代.json` 是同一张盘换成现代都市：溯源编号一个不动，只换措辞，与古代版的差异度 0.15（换盘对照报告），设定层只动表皮不动真相层。
- 体与用分层：命局定的段只写一次，不带 layer：主题命题、身份层、内核层、矛盾面、童年事件、谎言、秘密、需要与想要、抵抗线、亲密关系模式、意象系统、他人眼中的他、视角声音、潜文本、口头禅。随大运变的三段写两层：说话方式、能力与漏洞每条带 `"layer": "底色"` 或 `"走向"`，性格表里只有表现层那条带（底色一条，再加一条走向、text 也以"表现层："起头）。底色是命局不带运，sources 不引 D- 编号；走向恰一条，把故事窗内几张阶段卡在这一面的偏移按岁数串成一句（"二十五岁前断语多；二十五到三十五岁反问多、话里有话；三十五岁后句子变长"），sources 引在场卡的 D- 编号（至少一张；只沾一头在故事窗内的卡一笔带过或不写）。逐步的偏移正文全在第十三段阶段状态（下面阶段状态卡一节），不在上面。他人眼中的他只写十神边与神煞给的固定看法，随时间变的部分在卡的"关系变化"面和群像快照里，不在单人档案里替对方作答。
- 写法轮廓写 webnovel，加两段可选段落：功能位、主题命题；还可加"情绪过程"（下下条）。
- 口头禅与标志动作不写进底册：底册上只要有一句可搬的话和一个可搬的动作，就会一路被搬进细纲与正文，每章一回，改成倾向写法、加注记、限次数都只是减量，字段在诱惑就在。检查器见到这两个段名照旧报 error。口头禅唯一的出处是戏用页附问的末问（他怎么被记住）：每人至多一句，它本来就是要反复出现的，整页只这一行许带引号；标签、反差、物件或身体记号也写在那一问（见 `戏剧层.md`）。底册里认人靠的是另外几样：说话方式（句子长短、先说什么后说什么、什么绝口不提）、选择（两难与年表）、别人怎么对他（矩阵与他人眼中的他）；身体习惯并进情绪过程的身体先动（新书在戏用页第六问），那里自带条件（哪根线被碰到身体才那样动），有条件的习惯是反应，没条件的是装饰；祥林嫂式的重复句是主题装置，一本书至多一个，作者要就写进主题命题段，写明它是全书的装置、大约出现几次、每次差在哪。导出到 story 时模板那一栏填指路：腔调见语言风格档案，身体反应见情绪过程。
- 说话方式与情绪过程两段的写法：text 里不许有引号，检查器报 error，例句写成句尾添一句好不好、是不是这类商量的话，不写成带引号的原句，写手会照抄引号里的话；用肯定写法，写他做了什么，不写他没做什么，写手照卡的句形写，卡上满是以不、没收尾的短句，正文的句尾否定就跟着多；伏笔物件不写成反复动作，档案里只写他觉出它在，碰它的动作归卷纲的伏笔登记管、只写进排到的那一章细纲，否则每章都按一回。
- 情绪过程（可选段；新书不在底册里写它，写在戏用页第六问，五拍，多一拍破，见 `戏剧层.md`；旧档案里的这一段检查器照认）：写他在一场戏里情绪怎么走，四拍，每条带 `"beat"`：碰线（哪根线被碰到、底下的真情绪是什么，引 U-、LI-、E- 或 IN-，也就是抵抗线、谎言、矩阵边的回应倾向、亲密关系星）、身体先动（情绪先在身上哪里出现、人认出来之前的半拍，引 YQ-、IM-、DM，体感与材质）、盖法（他用什么把真情绪盖住：印以道理盖、伤官以刺盖、财以算盘盖、官以礼数盖，一条线一种盖法，引十神与谎言）、余波（拖多久、落到人还是事上、真正放下要什么，引材质与用神）。至少碰线与盖法各一条；写过程不写结论，先什么再什么；不给台词，引号里的话检查器会报，写手会照抄。它是命局定的定论段，不带 layer；随大运变的偏移仍在阶段卡。导出到 story 时成为角色卡的"情绪过程（写戏用）"块，写章时 narrative-writer 读 `设定/角色/` 就在手边。
- 几个人一起写时分两趟（流程第 2 步与第 8 步）：命局定的段先写、并行；年份定的段（秘密、年表与两难、阶段状态的亲密关系动静与关系变化、他人眼中的他里随边写的句子）等事件链写完再写，逐条引它的 Q-、TH-。先写年份段，同一件事会在几份档案里长出几个说法。
- 每条特质 `{"text", "sources": [编号], "note"}`。sources 至少一个，全部来自命盘的 features 索引。一个特质最好落到具体事实（哪一柱、哪步大运、哪个标签），不要只挂 DM。
- 体质与外貌暗示（性格表里的身份层或表现层里写身子的那几句）引 YQ- 加 DM、Y-：运气只给体格与体感（身量、气色、皮肤干润、怕冷怕热、手脚温度、动作节律）和一句薄弱处，不给病、不给气质；气质底色由十神性格、日主五行、调候给，不从运气取。命盘 yunqi 节的 features 已按主次排好：年主干总起（YQ-年-干支，上司天、中岁运、下在泉揉成的体格体感一句加薄弱处一句，先读它）、运为体（岁运给体格外貌与体感的大路数）、纲气为主（岁半之法定的那一头，给这一路数偏向哪边）、当步之气为用（出生那一段的季节体感）、修正为改写（运与司天在泉、客主加临、年关系、平气、与调候叠加，说的是谁压谁、表里怎么错开）、另一头作背景（一笔带过）。写出来是一句体格加一句体感加一句薄弱处，薄弱处写成习惯不写成症状（"一累先清嗓子""坐久了先揉腰"），一个健康的人读到会觉得是在写他。sources 里至少要引到主干、体或主之一，只引背景与修正会被检查器报出来；平气的盘写平和匀称。
- 字段的八字来源按下面一节的表；抵抗线是防宿命感的关键：用神是他真正需要的，喜神是他以为想要的，戏在落差里。用神、喜忌引 U- 编号（U-用-水、U-忌-土）；年表与两难只写他在事件链里有戏的年份，两难只在事件链把两难给他的那一年写（主角全书一两回），每条引该年的 L- 编号（可加 D- 基调），"二十五到三十五岁逆风十年"这类按运分段的行写进阶段卡；疾病与情志是偶发事件，默认不写，检查器也不要求：作者说这个人要病、要垮一回，才从年表里带 L-…-病候 的年份（身心域被引动的年份，年表已把那年的岁气、疫季、此人的档与薄弱处、病候轻相重相、情志方向写在一条里）挑一条，写成年表与两难里有前因后果的一场戏，引该年的 L-…-病候 加命盘的 YQ-病-、YQ-志-、YQ-档-；一步大运最多一次，一条故事线最好只有一次主崩溃，轻重照档（和档只给闷一阵、话少几个月这一级，显档薄弱处会发，危档才写崩溃、失常、危及性命），情志垮的方向与薄弱处同一个脏，其余年份的情绪起伏归十神性格的正常幅度；亲密关系模式引 IN-（十神行、地支行、命中的修正项），意象系统引 IM-（材质、各五行的意象族、修正项），正文不出现五行名，材质、救赎、威胁、出身与家的色调都用意象表"读者本里的说法"那栏的质地词写（直而易折的那一类、光和热、厚而慢能承住的、冷硬能切开的、流动抓不住的），"材质是金""威胁意象是水与金""出身是火色的"这类写法会被检查器报 warn，五行名只留在 sources 与 note 里；谎言从 lies 节的候选里挑一条改写成这个人的话，引 LI- 加钉事件那年的 L- 编号（钉法条目里已列好）。
- 用神改判规则：档案 yongshen 给什么就按什么写，不凭自己的判断另取。例外只有 notes 里标出的三种：中和临界盘可取比值另一侧的结果；调候为用的盘可退回 reason 里写明的"扶抑原取 X"；从强、从弱候选盘可按身强弱论。改了必须在该特质的 note 写"改判：财→印，因……"，sources 仍引 U- 编号。同一张盘不改判就永远同一个答案，这是它的价值，别为了写得顺手去动它。
- 读者本口径：写人不写命，所有句子都要能脱离八字成立。干支、十神、神煞、命中注定一类词只允许出现在 sources 里。

写 JSON 用固定排版（外层缩进两格、每条特质一行，diff 才只落在真改的行）：改完跑 `"$SKILL/scripts/character_format.py" 人物/沈砚.json` 原地重排，`--check` 只查。

渲染：

```bash
"$SKILL/.venv/Scripts/python" "$SKILL/scripts/character_render.py" 人物/沈砚.json
```

```bash
"$SKILL/.venv/Scripts/python" "$SKILL/scripts/character_render.py" 人物/沈砚.json --reader
```

## 字段的八字来源

| 字段 | 八字来源 |
|---|---|
| 性格关键词与矛盾面 | 天干透出为示人一面，地支藏干为压着的一面；月令与日支不一致时矛盾更尖 |
| 表里三层 | 身份层取年柱月柱环境，表现层取透干十神（底色）加大运天干十神（走向），内核层取藏干与用神 |
| 真正需要的东西 | 用神 |
| 以为自己想要的 | 喜神或忌神的诱惑 |
| 气质底色 | 调候（缺什么）加日主五行的句法节奏；不从运气取 |
| 体质与外貌暗示 | 日主五行与调候，加生年运气的体格体感与一句薄弱处（年主干、岁运为体、纲气为主、当步为用、修正为改写）；运气与调候反向时写成外一层里一层；不带病 |
| 疾病与情志事件 | 年表身心域被引动的年份，乘生年运气的病候、情志方向与严重档，乘故事年岁气与疫季；默认不写，作者挑，一步大运最多一次 |
| 亲密关系模式 | 日支与亲密关系星 |
| 特色标签 | 神煞白名单 |
| 童年状况 | 年柱、月柱、前两步大运、六到十二岁的关键流年 |
| 谎言 | 童年关键流年钉一件具体事，加忌神格局的候选谎言 |
| 说话方式 | 十神加日主五行句法：木直、火急、土慢、金硬、水绕（底色）；大运天干十神的说话偏移（走向） |
| 能力与资源 | 用神所在柱（底色）；顺逆档位、十二长生、运柱神煞说这十年哪些在用（走向） |
| 漏洞 | 忌神所在柱（底色）；冲提纲、天克地冲、伏吟说这十年哪条在动（走向） |
| 抵抗线 | 他在对抗自己的忌神，或错用了用神 |
| 意象系统 | 用神五行给他的救赎意象，忌神五行给威胁意象，日主五行给他看世界的材质 |
| 视角声音 | 十神与五行句法合成：注意力落在哪、句子多长、什么不说 |
| 阶段状态（每步大运一张卡） | 大运天干十神为这十年示人的偏移、地支十神为底色；大运五行为用喜忌仇闲说推他还是压他；大运与命局的冲合说处境与关系怎么换；日主在运支的十二长生说气力；十神与命局的叠合（叠、近、新）说是放大画像还是带来画像里没有的 |
| 情绪过程（旧档案的可选段；新书写在戏用页第六问） | 碰线取抵抗线与谎言（用忌 U-、LI-）、矩阵边的回应倾向（靠近、躲或压）与亲密关系星；身体先动取生年运气的体感与日主材质（YQ-、IM-、DM）；盖法取透干十神与谎言（印以道理盖、伤官以刺盖、财以算盘盖、官杀以礼数盖），一条线一种盖法；余波取日主五行的去势（木直去得快、水渗去得慢）与用神（真正放下要什么）。命局定，不带 layer |

表里的来源给的是功能位（上一辈、伴侣那边的人、家底、体面的路）；落成哪个时代的哪种机构词，由设定卡定。

## 阶段状态卡

前十二段是画像（命局为体）；人的喜好、性格、价值观、说话方式都随大运变（大运为用），所以第十三段按大运分卡，每步一张，写**这十年他与画像差在哪**，不重抄画像；上面那三段带层的只留底色与走向一句，逐步的偏移都在这里。年表已带每步大运的阶段事实（干支十神：天干是示人的偏移、地支是底色；五行各为用喜忌仇闲；顺逆档位；与命局的冲合；日主在运支的十二长生；运柱神煞；十神与命局的叠合：叠是放大已有的一面、近是同家族换了方向、新是画像里没有的活法；这十年最常动的领域；候选年份），编号 `D-{步}-{干支}-…`。草稿：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.stagecard 命盘/林昭.年表.json --chart 命盘/林昭.json --matrix 命盘/矩阵.json --window 24 46 > 命盘/林昭.阶段.json
```

- `--window` 给故事覆盖的岁数段，只出与它相交的大运；`partial` 标出只有一头在窗内的段，那两张卡写短些。给了 `--matrix` 时"关系变化"列出这十年内与谁同步忌运、一顺一逆（E- 编号）。
- 每步七面各一段草稿加 ids：性格、价值观与喜好、说话方式、需要的得失、亲密关系动静、能力与漏洞、关系变化；写进档案时另加第八面"手里有什么"（脚本不出草稿，按设定卡的时代规矩与他的身份写：这十年他手里有什么可押，一句）；性格与说话方式的草稿前半句是命局透干与月令本气的画像底色（T- 与 H- 编号），偏移接在后面；需要的得失末尾列这一步里合绊用神、合化为用的年份。另有 keynoteIds、candidates（该年机制与领域的 L- 编号）、domains、allIds（该段全部事实编号）、hooks。原表 `references/阶段状态.md`（自起草）。
- 写进人物档案：`{"title": "阶段状态", "stages": [{"stage": "D-3-己卯", "ages": [25, 35], "label": "四到八字的阶段名", "traits": [{"aspect": "性格", "text": "……", "sources": ["D-3-己卯-干-偏印", "L-25-乙卯-冲日支"]}]}]}`。aspect 取那八面（第八面"手里有什么"脚本不出草稿，写档案时按设定卡与身份补）；label 与 text 走读者本口径；每条同时引这步大运的 D- 编号和一个具体年份的 L- 编号最好；与"年表与两难""童年事件"已写的年份事件一致。完整段写全八面，partial 段三到四条加第八面。
- 写法：性格与说话方式先说画像里他是什么样，再说这十年偏到哪，不写成绝对句；叠合行决定力度：叠写"放大到过头，旁人第一次觉得他太过"，近写"还是他，只是味道不对"（"她不再驳人"太重，"驳人的话咽回去换成冷"才对），新写"像借来的衣裳"，近与新都不把底色写没。需要的得失只写用神这十年到位、被牵住还是够不着、落到哪一年，需要什么、以为想要什么是画像的定论，不重抄，也别每步忌运都写同一句。亲密关系动静只写配偶宫这十年的动静，挑什么样的人在亲密关系模式里。关系变化只写十年一段的底色（顺逆、同步忌运、冲年支时支、驿马），某一年谁对谁怎么反应归群像快照。干支一推一压（一头用喜、一头忌仇）时草稿先给合并的一句，别把两句矛盾话并排抄。样例：`examples/沈砚/`（三张）与 `examples/林昭/`（四张，含关系边）。
- 起头句式换着用：性格与说话方式两面都要先有底色再有偏移，但别每条都"画像里她……"起头，同一份档案里各卡不重复，一张卡两面也不共用。可用的式样：对照式"画像里她 X；这十年 Y"；动作式"她那股 X 这十年收了、放了、换了方向"；他人视角"旁人认得的她是 X，这十年成了 Y"；时间式"从前 X，如今 Y"；近的写法"X 还在，只是 Y"；新的写法"Y，像借来的衣裳，X 没丢"；回环式"Y……，可骨子里那点 X 没变"。底色可以藏在名词里（那股锋利、那张快嘴、等人来救的习惯），不必每次点名画像。四张卡八条对七种式样必有一式复用，复用时换卡、换面、换名词。
- 年表窗与末卡：年表的逐年表自动延到与窗相交的最后一步大运的末尾（coverage 字段），所以末卡的"需要的得失"也有整十年的挂钩年份可落；年表顶层的候选年份仍只算窗内。

## 检查

契约与溯源（必备段落齐、每条有编号、编号在命盘里找得到；设定卡在场、period 合法、world 非空、槽位只认十一个键；阶段状态段另查 stage 编号、ages、label、aspect 与次序；体用分层查说话方式、能力与漏洞每条有 layer、至少一条底色、有卡时恰一条走向，性格表里只有表现层分层，底色不引 D-、走向引在场卡的 D-，定论段不带 layer，年表与两难每条引 L- 或 J- 落到年份；照抄样例：与 examples/ 的样例档案十字以上连串重合报出，规则表与写法说明里本来就有的串放行，同名的人不比，`--no-examples` 关掉）：

```bash
node "$SKILL/scripts/check-character.js" 人物/沈砚.json
```

引了矩阵、年表、日程或推演编号的（阶段卡的 D- 事实编号在年表里，写了阶段状态就要带 `--timeline`；引了 TH- 或 Q- 就带 `--run`）：

node "$SKILL/scripts/check-character.js" 人物/沈砚.json --matrix 命盘/矩阵.json --timeline 命盘/沈砚.年表.json --schedule 命盘/日程.json --run 命盘/群像/推演.json
```

去术语（读者本与导出本零 error；warn 是常用词兼术语，人看上下文。时代措辞组是夫家、仕途、科举一类古代机构词，只在设定卡 period 为现代、未来、异世界时报 warn，检查器按同目录同名档案 JSON 的 `setting.period` 自动判，或用 `--period 现代` 指定，判不出就报；读者本里出现多半是把功能位又翻回了古代）：

node "$SKILL/scripts/check-terms.js" 人物/沈砚.读者本.md
```

换盘差异度（两份人物档案按溯源编号的事实种类与特质文本两路算距离，0 到 1；同一约束换盘、或打乱生日的对照盘，差异度低说明解读没跟着盘走。阈值 0.65，对照实验定的：同一个人物重写一遍 0.52，同一约束的相邻候选 0.74，无关的盘 0.82 以上（含阶段状态卡与底色走向层）；`--threshold` 不带数就用它，低于即退出码 1；不给只报数）：
