# 人物层：排盘、反推、读命盘与各种草稿

排盘、反推、读命盘档案，和弧光、矩阵、年表与两难、群像快照、日程、年度状态卡这些草稿怎么出、怎么读。写档案怎么落笔在 `写档案.md`，群像推演在 `戏剧层.md`。

## 排盘

命令都在作者的项目根下执行，产物写进项目的 `命盘/` 与 `人物/`。脚本在本 skill 目录的 `scripts/` 里，命令中的 `$SKILL` 换成本 skill 的目录（加载时给出的 base directory）。Python 用本 skill 的 `.venv`：Windows 是 `.venv/Scripts/python`，macOS 与 Linux 是 `.venv/bin/python`；脚本零第三方依赖，运行期只要 tzdata 可用。

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.chart --birth 1986-05-29T22:30 --lon 116.4 --gender male --name 张三 --age 30 > 命盘/张三.json
```

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.chart --pillars 甲申 壬申 乙巳 戊寅 --gender male --epoch 300 --name 沈砚 --age 30 > 命盘/沈砚.json
```

- 现实历给 `--birth`（ISO 钟表时刻）加 `--tz`（默认 Asia/Shanghai）加 `--lon`（出生地经度）；架空历给 `--pillars` 四柱加 `--epoch`（出生所在故事纪年）加 `--start-age`（起运岁数，默认 3）。
- `--age N [N ...]` 附带这几岁的流年（如 `--age 8 29 34`），童年钉事件的那年和年表要用的年份一次给齐。
- **真太阳时按题材选开关**：民国以前的角色，作者给的时辰本身是当地太阳时，加 `--no-true-solar`；1949 年以后按北京时间修正，给 `--lon`；民国看设定，城市可修正，乡下不修正。误用的后果是时柱跑到隔壁时辰。
- 排盘前问清四件事：性别（大运顺逆用）、时辰是否可靠（不可靠就只给三柱，去掉时柱）、题材年代（定真太阳时开关）、设定卡（`写档案.md` 设定卡一条：时代与世界，权力、上一辈、结合、伴侣那边的人、体面的路、家底各落在哪；亲密关系星要不要改；落 `人物/设定卡.json`，各底册顶层 setting 从它抄）。
- 架空历只有四柱，出生所值之气（五运六气那一步）按月支取：寅辰午申戌子六个月定得出，卯巳未酉亥丑跨中气定不出，命盘 `yunqi.step.unresolved` 会标出并写明中气前后各是哪一步。作者知道生在中气前后就给 `--yunqi-step 初之气…终之气`（或 1 到 6）；丑月生在大寒之后的给 `--yunqi-step 次年初之气`，运气年干支随之换。现实历按出生时刻自动定。
- 亲密关系星默认男取财、女取官杀。作者要改就在排盘时给 `--lover-star 财|官杀|食伤|印|比劫`，写进命盘顶层 `loverStar`；亲密关系修正项、年表的感情领域、阶段卡的亲密关系动静都从这里读，条件跟着家族走（财清财浊按财判，官杀混杂按官杀判），不跟性别。

## 反推：没有生日时找盘

作者只说得出"要什么样的人"时，把要求写成约束 JSON，脚本穷举打分给前五名。架空历全量 51.8 万盘约半分钟，现实历每年约四千盘。

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.search 命盘/约束/林昭.约束.json --save 命盘/约束 > 命盘/林昭.候选.json
```

约束不足、只想快速填一个配角时用随机补位：加 `--seed 7`（或约束里写 `"random": {"seed": 7}`），缺的性别随机、架空历缺的起运岁数随机零到九岁，候选从过硬约束且分数不低于最高分八成的池子里按种子抽，不按分排；同种子同结果，种子写进保存的约束里，重跑可复现。结果里 random 一节记种子、池子大小与补了哪些字段。

约束 JSON（字段全可选，gender 必填或给种子；每项 weight 默认 1，加 `"hard": true` 即硬约束）：

```json
{
  "name": "林昭",
  "calendar": {"mode": "fictional", "start_age": 5, "year_pillars": ["戊戌"]},
  "gender": "female",
  "story_age_window": [24, 46],
  "day_master": {"element": ["金"], "weight": 1},
  "strength": {"value": "身弱", "weight": 2},
  "structure": {"any_of": ["七杀格", "伤官格"], "weight": 1},
  "ten_gods": {"prominent": [{"god": "正印", "weight": 2}], "absent": [{"god": "食神", "weight": 1}]},
  "yongshen": {"element": ["土"], "weight": 1},
  "day_branch": {"any_of": ["酉", "戌"], "weight": 1},
  "arc": {"template": "正弧", "turning_age": 30, "weight": 3},
  "events": [{"age_range": [28, 32], "type": "冲日支", "weight": 3}],
  "relations": [{"to": "沈砚", "ten_god_seen_by_them": "七杀", "weight": 2}],
  "shensha": {"require": ["华盖"], "weight": 1}
}
```

- 现实历写 `"calendar": {"mode": "real", "birth_year_range": [1988, 1996]}`，时辰取中点当地太阳时，不做真太阳时修正；选中后按作者定的出生地用 `chart --birth --lon` 重排。
- 架空历可用 `year_pillars`（年柱列表）、`month_branches`（月支列表）收窄。
- arc 的 template 取 正弧、负弧、触底反弹、高开低走、平弧、震荡，或给 `vector` 四个数（起承转合，-1 到 1）。
- events.type 取 冲日支、冲提纲、天克地冲、伏吟、换运。relations 的 to 按角色名读 `命盘/{to}.json`，可给 ten_god_seen_by_them、ten_god_seen_by_me、day_branch（列表：六合、六冲、刑、害）。strength.value 取 身旺、身弱、中和（写身强、身衰也认）；给了 arc 就要给 story_age_window。
- 输出每个候选的逐条命中（want、got、得分）、取格、旺衰、用神、弧光四段向量，以及 `chartArgs`：把它接在 chart 命令后面就能排出正式命盘（再补 --name、--epoch、--age）。arc 一项的说明同时写作者要的模板的匹配分和数字最像的模板，两者常只差零点零几（匹配分偏宽），差距小时看哪一段反了、由作者定。
- 给作者看候选时讲人不讲盘：每个候选一句话说清这个人的压力曲线和它与约束的出入，让作者挑；挑定后才排正式命盘。

## 弧光走势

给故事覆盖的年龄段，看大运压力曲线像哪种弧光，转折点落在哪：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.arc 命盘/沈砚.json --window 24 46 --turning 30 > 命盘/沈砚.弧光.json
```

输出窗内每步大运的分数与来由、起承转合四段向量、六个模板的匹配分、转折候选（换运之年、流年天克地冲或冲日支之年），以及 reading 一节：最佳模板的内在弧光与四段该发生什么、每步大运的顺逆档位（强顺、弱顺、平、弱逆、强逆）与写作陷阱、转折信号的含义、匹配分落在哪一档该对作者说什么（原表 `references/弧光匹配.md`）。弧光方向由作者定，这里只报压力落在哪；与作者要的弧光不合时，照 reading.advice 告诉作者哪段压力反了、三条路是什么（换盘、移时间窗、外顺内塌的反差写法），由作者定。

## 多人矩阵

两个以上角色都排好命盘后：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.matrix 命盘/沈砚.json 命盘/林昭.json > 命盘/矩阵.json
```

每条有向边给：A 看 B 的十神、两人日柱的合冲刑害、B 的日主在 A 是用喜忌哪一个、两人同在忌运的年份段与一顺一逆的年份段（两人都要有纪年锚：现实历或给了 --epoch）。人物档案"他人眼中的他""秘密"两段按边写，sources 引 E- 编号，检查时加 `--matrix 命盘/矩阵.json`。

每条边另带 draft 与 draftIds：注释草稿，按回应倾向表写 A 眼里 B 是什么、A 需要还是受不了 B、偏向哪边，加日柱与岁运同步的事实。写"他人眼中的他"时对着它改成人话，引 draftIds 里的 E- 编号；草稿是脚本拼的，读者本口径要自己换。

## 年表与两难草稿

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.timeline 命盘/沈砚.json --window 0 60 > 命盘/沈砚.年表.json
```

- stages：窗内每步大运的基调（顺、逆、平）与分数来由。
- years：逐年流年干支、十神、顺逆分、机制（冲提纲、冲日支、天克地冲、伏吟、刑害合、岁运并临、岁运相冲、换运、合绊用神、忌神透干、用神到位）、领域（九个，见岁运事件类型表的领域轴，每个带"为什么是这个领域"；只凭"流年见某十神"一条不记领域，要两条以上或有宫位受冲、神煞一类强信号）、流年神煞。
- candidates：两个以上关键机制、或冲提纲/冲日支/天克地冲/岁运并临之一的年份，六十年里十几年，童年钉事件与两难从这里挑。只是换运或分数难看的年份不在候选里，但 years 里都有，要写"平淡里的转折"就自己去 years 里取，照样引 L- 编号。
- 两难草稿由脚本先出一版：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.dilemma 命盘/沈砚.年表.json --chart 命盘/沈砚.json --with 命盘/林昭.json > 命盘/沈砚.两难.json
```

  每个候选年份给主机制（按烈度取最烈的一个）、主副领域（按年表的信号权重，主机制冲到的宫位加分）、两难一句（`references/岁运事件类型.md` 里有精选格就用它，没有按合成规则拼：机制形态加主副赌注）、`ids`（该年的 L- 与 D- 基调编号，写进人物档案就引这些）；给了 `--with` 时 `affects` 列出那一年谁被牵动、双方互看的十神与引动原因。`--ages 6 30` 只改写指定的几岁（非候选年份也行）。这是草稿：作者挑年份与主副领域，模型改写成这个人的话，两个领域互斥时最好（保名誉失感情）；副领域当年也真动了才算，脚本已保证。童年事件要落在具体一年，引 L- 编号；检查时加 `--timeline 命盘/沈砚.年表.json`。

## 群像快照

几个角色都有纪年锚（现实历，或架空历给了 --epoch）时，看故事某一年谁被引动、哪些关系边被激活：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.ensemble 命盘/沈砚.json 命盘/林昭.json --year 330 --months > 命盘/群像/330.json
```

- people：每人当年岁数、大运与基调、流年机制与领域；--months 另列十二流月的冲合（细纲的场景节拍从这里挑月份）。
- edges：被引动的边与原因（同年引动、五行临身、同步忌运、顺逆、日柱引动），附矩阵 E- 编号。
- 单看某一年用快照；整段故事的事件链用群像推演（`戏剧层.md`），它按热年出事件卡，快照的 Q- 编号在推演的 idPool 里一并可引。

## 配角日程与交汇点

主线之外每个配角同期在经历什么、哪几年撞在一起：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.schedule 命盘/沈砚.json 命盘/林昭.json --window 320 345 --main 沈砚 > 命盘/日程.json
```

- people：每人逐年一行（岁数、流年、大运基调、关键机制、领域、是否候选年份），配角的日程从这里读；grid 是按年并排的同期表。
- intersections：交汇点，某一年有被引动的边且两端至少一人是候选年份（边活着不等于有事）；给 `--main` 只看与主角相连的。编号 J-{年}-{A}-{B}，text 里有双方当年的机制与边的原因；写"年表与两难""秘密"时可引，检查时加 `--schedule 命盘/日程.json`。
- 日程行本身不带编号，引各自年表的 L- 编号。

## 年度状态卡

写到某一年时，按需出那一年的一页：

```bash
PYTHONPATH="$SKILL/scripts" "$SKILL/.venv/Scripts/python" -m bazi_core.stateyear 人物/林昭.json --chart 命盘/林昭.json --year 337 --with 命盘/沈砚.json 命盘/裴恪.json --threads 命盘/群像/线程.json --run 命盘/群像/推演.json > 人物/状态/林昭/337.md
```

- 上半照抄档案里不随年变的定论（需要与想要、抵抗线、谎言、秘密、亲密关系模式）与覆盖那一岁的阶段卡；下半是这一年：处境（岁数、流年、大运与顺逆分）、机制与是否候选年份、动了哪些领域、抵抗线哪条在动（流年干支五行对此人是用喜还是忌仇：受不了的临身是第一条，需要的到位是第二条，一推一压两条都动）、流年神煞、哪些边被引动（给了 `--with`）、群像推演这一年他在什么位置与回应倾向（给了 `--run`）、重新上卡的旧账与悬置的账（给了 `--threads`）、病候候选（默认不写）、当年岁气。
- 每条带溯源，引的都是已有编号，不产生新编号；当年岁气那条不带编号，它是全书共享的年景；其下一条『年景』是年景表（tables/yunqi_year.json，references/五运六气年景.md）按流年干支给的一句：全年主色（风年、热年、湿年、燥年、寒年）、上下半年偏什么、年成与市面，有疫季再加一句疫在故事里的样子。年表每年带 yearScene 标签，群像事件卡带 yearScene 整句，同一年所有人共享。作者本草稿，模型改成人话；不进正文，读者本不需要。样例 `examples/林昭/人物/状态/林昭/337.md`。
