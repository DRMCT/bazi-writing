# 频道卡

按频道分文件夹，一个频道一个文件夹，放频道一级的机理：读者怎么一上来爱上人物、怎么期待感情线、主角的赢与亏怎么交替这一类，从同频道多本书合看拆出来，写成通用的两栏（读者得到什么、做法），不带书名、人名、情节与原句。不放题材的桥段、定章位的爽点排表与情绪百分比。

| 文件夹 | 卡 | 适用 |
|---|---|---|
| `女频/` | `附魅.md`：读者怎么爱上主角与感情线上的人、怎么期待感情线、一女多男时魅力不撞 | 古言把握大；别的题材只当参考，见卡头 |
| `女频/` | `爽感节奏.md`：主角每章赢在哪、亏多久打回、当众受辱时读者看不看得见她的牌、感情线上的人给不给她当众的亏 | 读者站在主角这边追的书，古言把握大；虐、悲剧向不用 |

男频还没做（待办 办-088），文件夹不建空的。

## 怎么召回

主题卡写了目标读者与写法轮廓，开书时主会话按目标读者的频道读对应文件夹，照每张卡末尾"怎么用"落下去：附魅落到主题卡、编配、档案、戏用页与文风卡附魅一节；爽感节奏落到主题卡爽感节奏一节，卷稿、单元会、细纲、审计、检查照那一节。写手不读频道卡，读种子里落下来的事。

## 往里加

- 同类干货（频道一级、几本书都这么做的机理）往这里加，一类一张卡，卡头写来源与适用。
- 书的题材不在卡的适用范围里、或作者想换一批样本：拆三到六本同类书出书一级的附魅卡（任务书 `references/写作层/任务书/附魅拆书.md`），在书里试出有效的，再由维护者去掉原书定位并进这里的卡。
