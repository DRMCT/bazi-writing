# 女频 · 附魅：读者怎么一上来就爱上主角与感情线上的人

- 来源：六本女频古言长篇（重生、宅斗、权谋一路），逐章拆男女主头几回出场，合起来看。多数条目两本以上都这么做；末尾标（一本）的只一本这么做，第五节一女多男整节出自一本，用前掂量。
- 适用：古言把握大。现言、仙侠与别的题材只当参考，用一条之前先看它在那个题材里成不成立（身份、名声、衣饰怎么写，各题材不同）；拿不准、或作者想换一批样本，走拆书那一路（`references/写作层/任务书/附魅拆书.md`）。
- 谁读：开书时主会话写主题卡"读者为什么爱上"一行、挑文风卡附魅一节的几条；编配起草者写人表"读者为什么爱他"一栏；命局段写"看得见的样子"；戏用页写"怎么被记住"。卷稿、单元会、细纲、审计、读稿与写手不读本卡，读文风卡附魅一节。

## 最硬的一条

| 读者得到什么 | 做法 |
|---|---|
| 一眼就想看他、看她，没有一处叫人嫌 | 主角与感情线上的人身上不许有一个低的词。身段、脸、眼、肤色、衣饰，每个词都好看（挺、宽、修长、白一路）；写多写少随书，一句写完和几百字慢慢揭都有，每个词都得好看。穷、废物、污名只落在名声与衣着上，身子照样写高、写好看。女主一样，没有一本把她写得不好看。 |

## 一、两条线

| 读者得到什么 | 做法 |
|---|---|
| 读者先爱上，才肯等她慢慢动心 | 读者对他的好感与她对他的心动是两条线。读者那条在他头一两回出场内就满；她那条可以慢，慢到几十章、几百章才明说。 |
| 中间不冷，读者手里一直有糖 | 靠读者知道、她不知道：他背着她做的事由第三人揭底；他视角里的心事读者先看见。 |
| 另一种排法：两个人早就是一对，只是一头不知道 | 重生女主前世已经爱他，读者与她同时满，不知道的是他；张力从他不敢信、或两边都瞒里来。 |

## 二、读者怎么爱上男主

| 读者得到什么 | 做法 |
|---|---|
| 没见到人，先欠他一份情 | 先声：露面之前，读者先从别处知道他一件好事，最好是冲着她的。全书第一记附魅是这件事，不是长相。 |
| 坏名声底下有东西，读者想翻开 | 先声也可以是坏名声，每条污名后面紧跟一张底牌：一句她知道的真相，或点破是有人故意散的。（一本） |
| 人还没到，宠与狠已经到了 | 第三人作证他对旁人冷、对她不同；也可以在他露面前由手下先替他护她、替他狠（一本）。 |
| 一眼认出这才是男主 | 他跟她刚放下的旧人并排出场，一冷一暖。（一本） |
| 惊艳一回，记一辈子 | 头一回露面写满，以后不再开脸：一层层揭（声音或影子、手、脸、眼），中间她的事照常往前走，不停下来专门描写；揭幕里一定有一笔冷或危险。往后只反复用一个标签，或每句话前后夹一笔小动作；他身价升一级时才重开样子。 |
| 这么狠的人对她破了功 | 反差头一回就压成一个画面：开脸下一句就为她破功（身子一绷、一收）；对旁人周到绝无可能，对她心跳快半拍，同一段里写。他的狠由被吓到的人作证。 |
| 从他怎么看她，爱上他 | 头一回见面后马上切进他心里，写一个被她搅乱的小反应：觉得她没传闻那么坏、多看两回、嫌她、替她把坏名声翻案。读者是从他眼里的她爱上他的，不是从他长什么样。 |
| 他只对她软 | 一件只给她的小事，他对旁人那头是冷的、狠的，有第三人作证。危险朝外，软朝她；同一个危险动作一回比一回轻。 |
| 宠一回比一回重，读者数着 | 偏爱是一张梯子，每一级更费他自己：送东西、出气、伺候、为她改自己、照她小时候说过的话造出那样东西。每回宠顺手办掉她一个仇人，甜和痛快落在一件事上；旁人当场吐槽一句，给这份宠称出分量。 |
| 天下只有这两个人懂彼此 | 两个唯一对上：他只偏她一个，她只信他一个，满场只她信他。（一本） |
| 他看见了别人看不见的她 | 他头一个看对她：全书头一个看穿她瞒着所有人的事，或头一个看见新的她。 |
| 她赢是她自己赢的，他是她的底气 | 宅斗里他不抢她的戏：她先出招，他后到场，只推一把或兜底，不替她破案；家事一开场他就走，大事场外办，由仇人上门揭底。进门卡在她刚被羞辱的那一句后面，他就是打脸的人。（一本） |
| 读者早知道他是谁，等她认出来 | 一人两个身份，一个装宠、一个装危险；读者早知道，她很晚才知道。（一本） |
| 少年也让人心动，又不越线 | 少年男主未成年时只写美与克制（手、睫毛、耳朵红），不写身体欲念；将来的身份给眼前的少年盖章（她心里一句往后他会是谁）；前世的细节放在她的回闪里当谜，由他的视角来解；错位保护：她护着根本不用护的他，两个人都可爱。（一本） |

## 三、读者怎么爱上女主

| 读者得到什么 | 做法 |
|---|---|
| 先心疼，再佩服 | 先惨、先心疼（她前世怎么收场、眼下最缺什么），接着一句话露出骨头：又狠又在理、当场换招、拿话压人。读者在这一下爱上她。 |
| 每章都有新的一样本事 | 一章露一样本事，不重复：嘴、智、狠、诈、胆、拼命。 |
| 她美，是别人眼里看出来的 | 她的美不成段，分给旁人一句一句看，看的人带情绪：仇人嫉妒、亲人心虚、外人惊艳、男主心动。特写放在她发狠或得意的时候。正经夸美可以很晚，由分量最重的人夸；也可以由男主一次开满，几十个字（一本）。 |

## 四、读者怎么期待感情线

| 读者得到什么 | 做法 |
|---|---|
| 两头都看得见，急着看他们对上 | 两条线并行：她那头算计、嫌、挑；他那头被搅乱。读者两边都看得见。 |
| 数他还会破几回例 | 他嘴上划界（只帮一次），下一章又多给一样。 |

## 五、一女多男：魅力不撞

| 读者得到什么 | 做法 |
|---|---|
| 每个人都有别人替不了的一份 | 每个男人占一种位置、一道门（她在哪碰得到他）、一样物，不撞。 |
| 主线越少见越想见 | 主线出场稀，每回都是一件事；他不在场时靠场外的事续命：当众送礼、旁人讲他的过去。 |
| 后来的人一上来就有分量 | 后来者借前面的男人抬身价。 |
| 一见面就有好戏 | 主线头一面就撞上另一个男人，开出修罗场。 |
| 两种心动分得清 | 主线是头一个认得新的她的人，与她没有旧账；其余几个带着旧账回头转向她。认与转分开给。 |

## 怎么用

- 主题卡"读者为什么爱上"：从最硬的一条与第一节写成一两句。
- 编配人表"读者为什么爱他"：每个感情线上的人从第二节挑他占的几条，几个人不重；一女多男照第五节分。
- 档案"看得见的样子"：照最硬的一条。
- 戏用页"怎么被记住"：先声是什么、头一回露面先给哪样、留哪一个动的标签，从第二节取。
- 文风卡附魅一节：开书时挑这本书用得上的五到十条，两栏抄进去，可以改成这本书的说法；写手只读那一节。
- 卷稿、单元会、细纲：感情线上的人出场的单元与章，照文风卡附魅一节排读者在哪又多爱他一回（偏爱一回比一回重）；他给主角的亏只在私下、同章补一样好处，当众给她亏的是对头与主子（同频道爽感节奏卡第三节）。审计与读稿问这一段读者多爱他还是少爱他。
- 这张卡不教题材的桥段与爽点排法，只教读者怎么爱上人。
