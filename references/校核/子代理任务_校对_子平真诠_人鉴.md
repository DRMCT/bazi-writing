# 子代理任务书：《子平真诠评注》附录《人鉴·命理存验》67 例 OCR 校对

你是一名校对员。任务是把《子平真诠评注》（中医古籍出版社 2012 年本）附录《人鉴·命理存验》67 例（林庚白著，印刷页 311–487）的 OCR 文本对着扫描页改正，并确认每段的标签。你不做命理判断，不改写，不删句，只改错字、补漏字和改标签。

## 输入

- 待校文本：`source/text/子平真诠_人鉴.tagged.md`。按页分块，`<!-- p311 -->` 是印刷页码（书页下角圆花里的数字）；每段一行，行首是自动打的标签，行末括号是 OCR 最低置信度，校完后删掉。
- 扫描页：`source/ziping/pages/p{页:03d}.png`，如 `p311.png`，用 Read 看图。**每页都要看**，这批的命盘表格 OCR 大半是碎的，只能对图重写。
- 没有参考文本，全凭看图。

## 版面与标签

每例的版面：居中标题"一、曹汝霖"；左上是命盘表，四行，每行从左到右是 十神 | 天干 | 地支 | 支藏十神（有的例只有天干地支两列，有的在藏干旁还印神煞名如"文昌"）；表右是大运一列，每条前两字是起运岁（"初四壬寅"= 四岁起壬寅运，"十四癸卯"，"廿四甲辰"……有的例大运七条）；表下一行"胎元壬辰 立命卯宫"；表右侧与表下是林庚白的判词，直到"【意译与解说】"；意译与解说是今人写的（流年表、生平、白话讲解），一直到下一例标题。

| 标签 | 含义 | 怎么校 |
|---|---|---|
| [标题] | 例号与姓名 | 对图改字，姓名尤其要对 |
| [例盘] | `四柱 \| 大运 \| 胎元立命` 一行 | **整行按图重写**：四柱按表格四行自上而下（年 月 日 时），每柱天干加地支两字，柱间一个空格；大运照书上顺序，每条起运岁两字加干支两字（"初四壬寅"），条间一个空格；胎元与立命照书写（"胎元壬辰 立命卯宫"）。自动拼出的柱里 □ 是没认出来的字，多认错的也有，不要信它，看图 |
| [判词] | 林庚白原判 | 逐字对图改；表右栏的行与表下通栏的行是同一段接着写的，自动打标按页攒成一段，换段只在书上另起一行缩进处；一例判词跨页时在下一页页码标记后接着写，不合并页块 |
| [解说] | 今人意译与解说块 | **有版权，不入语料**，自动打标只留一行占位；你只需确认占位的位置对（"【意译与解说】"那一行），块里的内容一个字都不抄，包括流年表和出生年月日 |
| [?] | 特征不明 | 定成上面之一 |

最容易错的三处：命盘表格的干支字（成戌、已己巳、王壬、末未、酉西、卯卵）；大运条被 OCR 漏掉或错字后自动打标丢了（一例大运一般五到七条，按图补齐）；意译与解说块里的内容被当成判词抄进来了（整段删掉）。

## 改字规则

1. 逐字对图。看不清的字写 □，不猜。
2. 标点照 OCR，明显错的改；不加不减句子。
3. 页眉、页码、右侧竖排书名删掉。
4. 判词里的人名、官职、年份（"今年甲子"）照书。
5. 不删任何判词句子。

## 输出

**不要重抄全文。** 只写修正清单 `source/text/子平真诠_人鉴.fixes.{批次}.md`，主会话用 `scripts/apply_fixes.py 子平真诠_人鉴` 套用生成校对本。每行一条：

```
p311 | 丙子 辛□ 丙申 戊子 | 初四壬寅 => 丙子 辛丑 丙申 戊子 | 初四壬寅        改字：片段在该页必须恰好出现一次，可以是整行（不含行末括号）
p311 | 胎元王辰 => 胎元壬辰
p311 | [判词] 比丙子官官，重叠泄气 => 删                                     不对，删段要用下面的写法
p311 | 删 | 比丙子官官                                                       删段：以段首几个字定位（表格碎片被当成判词时用）
p312 | 合并 | 的流年                                                         并段：把这段并入上一段
p330 | 增 | 立命辰宫 | [判词] 金寒冰冷，泄气太过                             增段：插在以那几个字起头的段之后
p330 | 增首 | [标题] 九、潘复                                                 增段：插在该页最前
p330 | [?] 金寒冰冷 => [判词]                                                改标签：用段首几个字定位那一段
# 井号开头是注释
```

要求：

- 每页看完就写该页的条目，页码用 `<!-- p311 -->` 里的。
- 例盘行整行改写时，`=>` 左边抄自动打标那一行的前面一截（到足以唯一为止），右边写完整的新行内容（不带标签）。
- 拿不准的字改成 □，在文件末尾"报告"节列出：页码、段首几个字、你的怀疑。
- 多个子代理分批校同一个文件时，各写各的清单文件，主会话合并；你只负责分给你的页。

清单写完后自己跑一遍：

```
.venv/Scripts/python scripts/apply_fixes.py 子平真诠_人鉴
```

它会列出套用失败的条目（片段不唯一、找不到段），改到失败为零、你负责的页里剩余 [?] 为零为止。然后在文件末尾加"报告"节：实际起止页、例数、改字条数、例盘整行重写条数、□ 个数、改标签与删段条数、拿不准的地方、疑似原书误字（照抄不改，只登记）。

## 硬规则

- 以扫描页为准。
- 不引入书外内容；意译与解说块的内容一个字都不抄。
- 每页都看图。
- 交卷前自查：apply_fixes 失败为零，你负责的页里剩余 [?] 为零，每例的例盘行四柱齐、大运条数与图上一致。
- 逐页落盘：每校完一页就把该页条目写进清单文件，断了不丢。
