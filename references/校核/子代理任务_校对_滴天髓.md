# 子代理任务书：《滴天髓阐微》OCR 校对

你是一名校对员。任务是把《滴天髓阐微》（中医古籍出版社 2012 年本，刘基撰、孙正治注译，含任铁樵增注）指定章节的 OCR 文本对着扫描页改正，并确认每段的标签。你不做命理判断，不改写，不删句，只改错字和标签。

## 输入

- 待校文本：`source/text/滴天髓_{批次名}.tagged.md`。按页分块，`<!-- p121 -->` 是印刷页码（书页下角花饰里的数字）；页码标记后若有"今注略 N 段"，是自动打标略去的今人段数。每段一行，行首是自动打的标签，行末括号是 OCR 最低置信度，校完后删掉。
- 扫描页：`source/ditiansui/pages/p{页:03d}.png`，如 `p121.png`（按印刷页命名），用 Read 看图。每页都要看，OCR 再好也有错字。图很高，注意看到页底。
- 不给参考文本。网上的《滴天髓》电子本错误很多，本任务全凭看图。

## 版面与标签

书的版面四层：章名居中字大（"二十一、官杀"）；**原文**是黑体加粗的短段；紧接"原注："是刘基原注；"任氏曰："起头的是任铁樵增注，可以连续多段，中间常有"一曰财滋弱杀格"一类加粗小标题和命例；命例左栏是四柱（自上而下年、月、日、时，每柱左侧小字是十神、右侧竖排小字是藏干）、再右一列是大运干支，右栏是这张盘的说明；今人写的"【原文白话释意】""【原注白话讲解】"等块常插在任注的议论与任注的命例之间，也出现在章末。

| 标签 | 含义 | 特征 |
|---|---|---|
| [标题] | 章名 | 居中字大，"数字、两三个字" |
| [原文] | 《滴天髓》原文 | 黑体加粗，通常一两句 |
| [原注] | 刘基原注 | "原注："起头，一段 |
| [任注] | 任铁樵增注 | "任氏曰："起头的段及其后的段；命例右栏的说明也是任注 |
| [小标题] | 任注里的分类标题 | 加粗短行，"一曰……格"，也有别的写法 |
| [例盘] | 命例 | 写成 `年柱 月柱 日柱 时柱 \| 大运1 大运2 …`，四柱顺序自上而下；大运列全（自上而下） |
| [今注] | 今人白话与注释块 | "【……】"起头；**有版权，不入语料**，自动打标只留一行占位并在页码标记里记略去的段数，你只需确认占位与段数对不对，不要把内容抄回来 |
| [页眉] | 书眉"滴天髓阐微""通神论""六亲论"、页码、两侧竖排书名 | 删掉 |

自动标签的 [?] 必须由你定成上面之一。自动标签定错的也要改。最容易错的地方：

1. 今人块与任注的边界。今人块结束后任注的命例接着来，自动打标靠小标题或命例认边界；若某页"今注略 N 段"里其实混着任注的议论（对图看那几段是不是"任氏曰"的延续、字体是不是与任注相同的宋体），用增段把它补回来；反过来，今人段被当成 [任注] 抄进来的，整段删掉。
2. 命例的四柱。OCR 常漏一柱或把十神小字并进柱里，例盘段少于四柱、多于四柱、干支不成对的，对图重写整段。大运列漏的补齐，顺序自上而下。
3. 原文段。黑体加粗的才是原文；任注里加粗的短标题是 [小标题]。原文被标成 [任注] 或反过来的，改标签。

## 改字规则

1. 逐字对图。OCR 常见错字，见到必查：戊 戌 成 互混；己 已 巳 互混（本书 己 巳 字形接近，天干作己、地支作巳、虚词作已）；壬 王 互混；未 末 互混；煞 然 互混；曰 日 互混；辰 展；申 伸；亥 亦；干 千 于；丙 两；丁 了；庚 康；酉 西；卯 卵；辛 幸；印 卩。干支字与十神名（官杀财印食伤比劫）尤其要盯。
2. 看不清的字写 □，不猜。
3. 标点照 OCR，明显错的改；不加不减句子。
4. 页眉页码删掉；跨页被切断的段落在页码标记后接着写，不合并页块。
5. 不删任何原文、原注、任注句子，哪怕看起来重复。
6. 疑似原书误字照抄不改，只在报告里登记。

## 输出

**不要重抄全文。** 只写修正清单 `source/text/滴天髓_{批次名}.fixes.md`，主会话用 `scripts/apply_fixes.py 滴天髓_{批次名}` 套用生成校对本。每行一条：

```
p124 | 癸运有已土当头 => 癸运有己土当头            改字：片段在该页必须恰好出现一次，前后多带几个字保证唯一
p127 | [?] 此造火长夏天 => [任注]                    改标签：用段首几个字定位那一段
p121 | 删 | 事实上，关于通关之说                      删段：残留的页眉页码、今人段、命例的十神藏干碎片
p128 | 合并 | 辰时)，亦长夏天                          并段：换行被误切成两段时，把这段并入上一段
p125 | 增首 | [小标题] 二曰杀重用印格                  增段：OCR 漏掉的段，插在该页最前
p127 | 增 | 杏花香，仕至郡守 | [例盘] 丁未 壬申 戊申 丙午 | 己酉 庚戌 辛亥 壬子   增段：插在以那几个字起头的段之后
# 井号开头是注释
```

要求：

- 每页看完就写该页的条目，页码用 `<!-- p121 -->` 里的。
- 改字条目里的片段不含行末的括号数字。
- 所有 [?] 段都要有一条改标签或删段。
- 例盘段整段重写时用"删"加"增"两条，或用改字把整段片段替换（片段须唯一）。
- 拿不准的字改成 □，并在文件末尾"报告"节列出：页码、段首几个字、你的怀疑。

清单写完后自己跑一遍：

```
.venv/Scripts/python scripts/apply_fixes.py 滴天髓_{批次名}
```

它会列出套用失败的条目（片段不唯一、找不到段），改到失败为零、你负责的页里剩余 [?] 为零为止。然后在文件末尾加"报告"节：实际起止页、改字条数、□ 个数、改标签条数、删段条数、增段条数、拿不准的地方、疑似原书误字（照抄不改，只登记）、每章例盘数量、"今注略"与图不符的页。

## 硬规则

- 以扫描页为准。
- 不引入书外内容；今人白话与注释的内容一个字都不抄。
- 每页都看图，不要只看 OCR 顺不顺。
- 交卷前自查：apply_fixes 失败为零，你负责的页里剩余 [?] 为零。
- 逐页落盘：每校完一页就把该页条目写进清单文件，断了不丢。
- 不改 tagged.md 本身，不改项目里其他任何文件。
