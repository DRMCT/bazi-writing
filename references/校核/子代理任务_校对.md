# 子代理任务书：OCR 校对与正文徐注标注

你是一名校对员。任务是把《穷通宝鉴评注》某一个日主的 OCR 文本对着扫描页改正，并确认每一段是余春台正文还是徐乐吾评注。你不做命理判断，不改写，不删句，只改错字和标签。

## 输入

- 待校文本：`source/text/{日主}.tagged.md`。按页分块，`<!-- pNNN -->` 是 PDF 页码；每段一行，行首是自动打的标签，行末括号是三个数：笔画比、与网上通行本正文的相似度、OCR 置信度。这三个数是打标依据，校完后删掉。
- 扫描页：`source/pages/pNNN.png`，用 Read 看图。每页都要看，OCR 再好也有错字。
- 正文语料：`references/校核/语料/穷通宝鉴_正文_{日主}.txt`，网上通行本的余春台正文。注意本书的正文措辞与它有出入，它只是参考，**以扫描页为准**。

## 标签怎么定

书的版面：余春台正文用**楷体**，徐乐吾评注用**宋体**，字号相同，交替排列，没有其他标记。楷体笔画粗细均匀、略带手写感；宋体横细竖粗、有衬线。看图定标签，不要靠文意猜。

| 标签 | 含义 | 特征 |
|---|---|---|
| [正文] | 余春台正文 | 楷体 |
| [徐注] | 徐乐吾评注 | 宋体；常以"申述""承上""此言其变""盖""凡"起头，但不绝对 |
| [例盘] | 四柱干支列表、命主姓名生辰、按语 | 干支四组起头的段，及其后到下一个正文或标题之前的所有段 |
| [标题] | 卷名、"X月甲木"、"正月"等 | 字大 |
| [校记] | 页脚 ①②③ | 页脚小字 |
| [页眉] | 书眉、页码 | 删掉，不保留 |

自动标签的 [?] 必须由你定成上面之一。自动标签定错的也要改。

## 改字规则

1. 逐字对图。OCR 常见错字，见到必查：戊 戌 成 互混；己 已 巳 互混；壬 王 互混；未 末 互混；大 太 天 夭 互混；辰 展；申 伸；亥 亦；干 千 于；丙 两；丁 了；庚 康。
2. 看不清的字写 □，不猜。
3. 标点照 OCR，明显错的改；不加不减句子。
4. 页眉页码删掉；跨页被切断的段落在页码标记后接着写，不合并页块。
5. **[例盘] 段不逐字校对**，只确认标签和大致不乱码即可。我们后面不用例盘，别在它上面花时间。
6. [校记] 段要校，它有时改变正文的意思。
7. 不删任何正文和徐注的句子，哪怕看起来重复。

## 输出

**不要重抄全文。** 只写修正清单 `source/text/{日主}.fixes.md`，主会话用 `scripts/apply_fixes.py` 套用生成校对本。每行一条，四种形式：

```
p040 | 故庚王为最要用神 => 故庚壬为最要用神        改字：片段在该页必须恰好出现一次，前后多带几个字保证唯一
p039 | [徐注] 茂才而止 => [例盘]                    改标签：用段首几个字定位那一段
p038 | 删 | 四库存目子平汇刊                        删段：残留的页眉页码
p040 | 合并 | 贵艰难，得壬癸                        并段：换行被误切成两段时，把这段并入上一段
p068 | 增首 | [标题] 命理秘本穷通宝鉴卷二            增段：OCR 漏掉的标题或校记，插在该页最前
p070 | 增 | 二月乙木，阳气 | [校记] ②此节抄本无      增段：插在以那几个字起头的段之后
# 井号开头是注释
```

要求：

- 每页看完就写该页的条目，页码用 `<!-- pNNN -->` 里的。
- 改字条目里的片段不含行末的括号数字。
- 所有 [?] 段都要有一条改标签。
- 例盘段不逐字校，只改标签、合并、删除。
- 拿不准的字改成 □，并在文件末尾"报告"节列出：页码、段首几个字、你的怀疑。

清单写完后自己跑一遍：

```
.venv/Scripts/python scripts/apply_fixes.py {日主}
```

它会列出套用失败的条目（片段不唯一、找不到段），改到失败为零、剩余 [?] 为零为止。然后在文件末尾加"报告"节：实际起止页、改字条数、□ 个数、改标签条数、拿不准的地方。

## 硬规则

- 以扫描页为准，语料只是参考。
- 不引入书外内容。
- 每页都看图，不要只看 OCR 顺不顺。
- 交卷前自查：apply_fixes 失败为零，剩余 [?] 为零。
