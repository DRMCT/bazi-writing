# 子代理任务书：《子平真诠评注》格局章 OCR 校对

你是一名校对员。任务是把《子平真诠评注》（中医古籍出版社 2012 年本，沈孝瞻原著、徐乐吾评注、苏全有等注译）格局相关章的 OCR 文本对着扫描页改正，并确认每段的标签。你不做命理判断，不改写，不删句，只改错字和标签。

## 输入

- 待校文本：`source/text/子平真诠_格局.tagged.md`。按页分块，`<!-- p127 -->` 是印刷页码（书页右下角圆花里的数字）；每段一行，行首是自动打的标签，行末括号是 OCR 最低置信度，校完后删掉。
- 扫描页：`source/ziping/pages/p{页:03d}.png`，如 `p127.png`，用 Read 看图。每页都要看，OCR 再好也有错字。
- 参考文本（**慎用**）：`source/wikisource/` 里没有本书，网上通行本的《子平真诠》原文措辞与徐评本有出入，本任务不给参考文本，全凭看图。

## 标签怎么定

书的版面：章名居中字大（"三十一、论正官"），有的带 ①；原文段落与徐评同一字体，徐评以"【徐评】"起头，徐评可以连续几段，直到下一个原文段（原文段前有一个空行的间距）；徐评里常列命例，四柱与大运作一段；每章末尾是今人写的"【注释】"块和"【白话释意】"块，一直到下一章章名。

| 标签 | 含义 | 特征 |
|---|---|---|
| [标题] | 章名 | 居中字大，"数字、论……" |
| [原文] | 沈孝瞻原文 | 默认；段前空行 |
| [徐评] | 徐乐吾评注 | "【徐评】"起头的段及其后紧接的段；自动打标已把"【徐评】"四字去掉，你不用补回 |
| [例盘] | 命例：四柱、大运、人名 | 干支占大半的段 |
| [注释] | 今人注释块 | "【注释】"起到"【白话释意】"前；**有版权，不入语料**，自动打标只留一行占位，你只需确认占位的位置对不对，不要把内容抄回来 |
| [白话] | 今人白话释意块 | "【白话释意】"起到下一章章名前；同上，不抄内容 |
| [页眉] | 书眉"子平真诠""三十一、论正官"、页码 | 删掉，不保留 |

自动标签的 [?] 必须由你定成上面之一。自动标签定错的也要改。最容易错的两处：徐评多段时后面几段被标成 [原文]，或原文段紧跟徐评被标成 [徐评]，请按"原文段前有空行"这条对图定。注释与白话块若自动打标漏了（内容被当成原文或徐评抄进来了），要把那些段整段删掉，只留一行 `[注释] （今人注释，不入语料，略）` 或 `[白话] （今人白话，不入语料，略）`。

## 改字规则

1. 逐字对图。OCR 常见错字，见到必查：戊 戌 成 互混；己 已 巳 互混；壬 王 互混；未 末 互混；煞 然 互混；曰 日 互混；辰 展；申 伸；亥 亦；干 千 于；丙 两；丁 了；庚 康；酉 西；卯 卵；辛 幸。格局规则里一个字错就是一条规则错，干支字与十神名（官煞财印食伤刃禄）尤其要盯。
2. 看不清的字写 □，不猜。
3. 标点照 OCR，明显错的改；不加不减句子。
4. 页眉页码删掉；跨页被切断的段落在页码标记后接着写，不合并页块。
5. 原文里的 ①②③ 是今人注释的编号，照抄保留。
6. 徐评里括号中的参见语（"（参观论正官取运节）"）是徐评原文，保留。
7. 不删任何原文与徐评句子，哪怕看起来重复。

## 输出

**不要重抄全文。** 只写修正清单 `source/text/子平真诠_格局.fixes.{批次}.md`，主会话用 `scripts/apply_fixes.py 子平真诠_格局` 套用生成校对本。每行一条：

```
p127 | 家在已丑斗牛之次 => 家在己丑斗牛之次        改字：片段在该页必须恰好出现一次，前后多带几个字保证唯一
p127 | [原文] 财旺生官者 => [徐评]                  改标签：用段首几个字定位那一段
p127 | 删 | 十五、论相神紧要                         删段：残留的页眉页码，或漏删的今人注释白话段
p128 | 合并 | 相也                                   并段：换行被误切成两段时，把这段并入上一段
p127 | 增首 | [标题] 十五、论相神紧要                增段：OCR 漏掉的标题，插在该页最前
p130 | 增 | 月令既得用神 | [例盘] 甲申 壬申 乙巳 戊寅  增段：插在以那几个字起头的段之后
# 井号开头是注释
```

要求：

- 每页看完就写该页的条目，页码用 `<!-- p127 -->` 里的。
- 改字条目里的片段不含行末的括号数字。
- 所有 [?] 段都要有一条改标签。
- 拿不准的字改成 □，并在文件末尾"报告"节列出：页码、段首几个字、你的怀疑。
- 多个子代理分批校同一个文件时，各写各的清单文件，主会话合并。

清单写完后自己跑一遍：

```
.venv/Scripts/python scripts/apply_fixes.py 子平真诠_格局
```

它会列出套用失败的条目（片段不唯一、找不到段），改到失败为零、你负责的页里剩余 [?] 为零为止。然后在文件末尾加"报告"节：实际起止页、改字条数、□ 个数、改标签条数、删段条数、拿不准的地方、疑似原书误字（照抄不改，只登记）、每章例盘的数量。

## 硬规则

- 以扫描页为准。
- 不引入书外内容；今人注释与白话释意的内容一个字都不抄。
- 每页都看图，不要只看 OCR 顺不顺。
- 交卷前自查：apply_fixes 失败为零，你负责的页里剩余 [?] 为零。
- 逐页落盘：每校完一页就把该页条目写进清单文件，断了不丢。
