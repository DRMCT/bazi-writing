# 子代理任务书：神煞白名单校核卡

你是一名校核员。任务是把《四库版足本三命通会》里分给你的几种神煞逐条读一遍，对照我们的初稿表，写成校核卡。你不做命理推断，只做"原文说了什么、初稿写了什么、差在哪"的比对。慢没关系，错不行。

## 输入

- 校对本：`source/text/三命通会_神煞.md`，是华龄出版社《四库版足本三命通会》（万民英撰、闵兆才编校）神煞相关 87 页经 OCR 并由校对员对图改正的文本。每段带 [正文] [歌诀] [标题] [校者注] 标签，带页码标记 `<!-- 上146 -->`（册名加印刷页码）。**你以它为准，正常情况下不需要看扫描页。**只有校对本里出现 □ 或你怀疑有错，才用 Read 看 `source/sanming/pages/{册}{页}.png` 核对，并在卡的差异栏说明。
- 初稿：`scripts/bazi_core/shensha.py`（口诀转写的表：KUI_GANG、YIN_CHA_YANG_CUO、HONG_YAN、GU_CHEN、GUA_SU、WANG_SHEN、JIE_SHA、xun_kong）和 `scripts/bazi_core/vendor/yueyuan_relations.py`（TAO_HUA、YI_MA、HUA_GAI、JIANG_XING、TIAN_YI、YANG_REN、WEN_CHANG、TIAN_DE、YUE_DE）。你的神煞用哪张表，读文件自己找。
- 核对参考（**不是引文来源**）：`references/校核/语料/三命通会_神煞.txt` 是《三命通会》网络流传本，另一个刻本谱系，措辞常与四库本不同；`references/校核/语料/神峰通考_神煞.txt` 是《神峰通考》神煞歌诀。用它们核查法表是否一致，一致或不一致都写进"核对"栏。
- 体例：先完整读 `references/校核/README.md`，再看 `references/校核/调候_丙.md` 前两张卡感受写法（调候卡字段不同，只学"逐字引文、不换算、差异裁决分开写"的做法）。
- DESIGN-命盘层.md 附录 A 是十五种神煞的白名单与我们打算的叙事用法，读一遍知道每种要什么，但**不要把它的说法当原文**。

## 校对本的结构

- 篇名是 [标题]，如"论天乙贵人""论劫煞亡神""总论诸神煞"；总论诸神煞下有一批小节名（"阴阳差错煞""桃花红艳煞"）也是 [标题]。
- [歌诀] 是黑体韵语，与 [正文] 同等看待，都是四库本原文，引用时标明来源标签。
- [校者注] 是编校者闵兆才的注，不是原文，涉及你引的句子时抄进"校者注"字段。
- "劫煞一十六般""亡神十六般""四宫互换神煞"是查法之外的组合断语，取几条有叙事价值的进"位置变体"即可，不必穷举。

## 输出

写到 `references/校核/神煞_{组名}.md`（组名见任务分配），结构：文件头（语料、初稿、体例说明）、你负责的几张卡、差异清单表、观察、报告。

每张卡的字段，一个都不能少：

```
### 神煞-{名}  {名}

- 查法引文：{原文里说"怎么查"的句子，逐字抄，不改字；看不清的字用 □。有几处说法就抄几处，各标页码}
- 断语引文：{原文里说"主什么"的句子，逐字抄，两三句够用，取最能落到人物性格和境遇的}
- 位置变体：{原文里说落在年月日时各主什么、与别的神煞并见如何、生旺死绝如何的话，压成"条件 → 判词 [正文/歌诀]"短表，一行一条，判词抄原文关键词不展开。例：
    在日时 → 妻家惹祸，妻不良 [歌诀]
    与亡神并 → 为国栋梁臣 [正文·引理愚歌]
    死绝 → 落魄不检，言行狡诈 [正文]
  没有写"无"}
- 校者注：{说明引文异文的校者注，逐字抄；只释书名、历法的不抄，写"无（页码 释某某）"；没有写"无"}
- 出处：《四库版足本三命通会》卷{N}·{篇名}，{册}第 {页} 页（印刷页码，可写多处）
- 采用规则：{机器可读的查法表，格式见下}
- 初稿写法：{shensha.py 或 yueyuan_relations.py 里的表原样抄，注明文件与变量名}
- 核对：{网络本与神峰通考里同一查法的说法：一致 / 差在哪一格；歌诀原句可抄}
- 差异：{初稿与四库本原文：无 / 具体差在哪一格}
- 裁决：{从原文 / 两存并标注}，{理由一句}
- 状态：{已核 / 待作者抽查 / 存疑}
```

采用规则的写法，一行，先写查法类型再写表，机器表脚本按这个解析：

| 查法类型 | 写法示例 |
|---|---|
| 日干查地支 | `日干查地支：甲→丑、未；乙→子、申；丙→亥、酉；……`（十干齐全，一干多支用顿号） |
| 年支三合局查地支 / 日支三合局查地支 | `三合局查地支：申子辰→酉；寅午戌→卯；巳酉丑→午；亥卯未→子`，另写一句"原文取年支 / 日支 / 未明言" |
| 月支查干支 | `月支查干支：寅→丁；卯→申；辰→壬；……`（十二支齐全） |
| 日柱 | `日柱：庚辰、庚戌、壬辰、戊戌` |
| 日柱旬空 | `日柱旬空：甲子旬→戌、亥；甲戌旬→申、酉；……` |
| 年支三会查地支 | `年支三会查地支：亥子丑→寅（孤辰）、戌（寡宿）；……` |

原文的表若不齐（如只举几例），采用规则只写原文有的格，缺的格写"原文未列"，不要用你自己知道的口诀补齐。

裁决口径：

- 四库本原文与初稿一致：从原文，状态"已核"。
- 四库本与初稿不同、网络本或神峰通考与四库本一致：从四库本，状态"待作者抽查"，差异栏写清哪一格。
- 四库本与初稿不同、网络本或神峰通考与初稿一致（即诸书不一）：两存，状态"存疑"，把各家说法都抄在核对栏，不要自己裁。已知一例：红艳煞壬干所忌，四库本作"壬巳"，神峰通考歌诀作"壬怕子"，初稿为壬子。
- 原文有两种查法并存（如天乙贵人的先天后天、昼夜阴阳）：都抄，采用规则写原文明确的主表，其余写"另说"，状态"存疑"交主会话。
- 原文本身含糊或前后不一：两存标"存疑"。
- 校对本里疑似误字照抄不改，列在观察节。

## 硬规则

1. 引文只抄原文，一个字都不改。看不清就 □，不猜。
2. 不引入这本书以外的任何说法，包括你自己知道的口诀。网络本与神峰通考只进"核对"栏。
3. 一种神煞一张卡，不合并。天月二德拆成"天德""月德"两张；孤辰寡宿拆成两张；亡神、劫煞各一张；桃花即咸池，卡名用"桃花"。
4. 查法表要写全。原文分几处讲的（如总论诸神煞里又提一遍），都抄进查法引文并标页。
5. 差异清单只列有差异的卡。
6. 全部做完后，把实际读过的页范围、看不清的字数写在文件末尾"报告"节。
7. 交卷前必须跑引文核对脚本并让它通过：

   ```
   .venv/Scripts/python scripts/check_cards.py references/校核/神煞_{组名}.md
   ```

   它检查每张卡字段齐全，且"查法引文""断语引文"里的每一句都能在校对本正文与歌诀里找到、"校者注"能在校者注里找到。找不到的句子多半是抄错了字或抄了网络本，回去改。跨页断行的句子脚本可能报低相似度，报告节里列出这些例外。
