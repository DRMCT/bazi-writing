初稿：`scripts/bazi_core/vendor/yueyuan_relations.py`（MIT，逐字节录自 yueyuan-bazi）；天干五合在 `relations.py` 初稿里手写。

### 刑冲合害-天干五合  天干五合与化气

- 引文：
    东｜壬子至丁巳六数｜故丁与壬合｜丁壬化木｜甲德统龙（上119）。
    南｜戊子至癸巳六数｜故戊与癸合｜戊癸化火｜丙德统龙（上119）。
    西｜庚子至乙巳六数｜故乙与庚合｜乙庚化金｜庚德统龙（上119）。
    中｜甲子至己巳六数｜故甲与己合｜甲己化土｜戊德统龙（上119）。
    北｜丙子至辛巳六数｜故丙与辛合｜丙辛化水｜壬德统龙（上119）。
    甲己化土，非辰戌丑未月不化，其次午月亦化，有戊字间之则不化，名曰妒合。（上120）。
    乙庚化金，非巳酉丑月不化，其次七月亦化，有甲字间之则不化，名曰妒合。（上120）。
    丙辛化水，非申子辰月不化，其次十月亦化，柱有丁字不化，名曰妒合。（上120）。
    丁壬化木，非亥卯未月不化，其次正月亦化，柱有丙字不化，名曰妒合。（上120）。
    戊癸化火，非寅午戌月不化，其次四月亦化，柱有己字不化，名曰妒合。（上120）。
- 出处：《三命通会》卷二·论十干合、论十干化气（上116–120）。
- 采用规则：天干五合：甲己→土（中正之合）；乙庚→金（仁义之合）；丙辛→水（威制之合）；丁壬→木（淫慝之合）；戊癸→火（无情之合）
- 初稿写法：relations.py STEM_HE 只有合的配对，无化气、无名目。
- 核对：五对配对四库全同。化气四库本上119 表五条与 china-testing 全同；合的名目（中正、仁义、威制、淫慝、无情）四库本此处无，shunshi 与 china-testing 同，作两库一致收录。tyme4py 只给合的对象。
- 差异：初稿缺化气与名目。
- 裁决：化气从四库本。合化成立的条件（"非辰戌丑未月不化""有戊字间之则不化，名曰妒合"）是旺衰 v2 合绊项的古籍依据，记卡不入本表，按 DESIGN-命盘层 2.4 走校准。
- 状态：已核

## 地支（6 张）

### 刑冲合害-六合  地支六合与化气

- 引文：
    无射戌，夹钟卯，取其卯戌之合。（上125）。
    姑洗辰，南吕酉，取其酉辰之合。（上125）。
    夷则申，仲吕巳，盖巳与申合。（上125）。
    蕤宾午，林钟未，盖午与未合。（上125）。
    《天元变化书》云：“子合丑，福轻。丑合子，福盛。寅合亥，福清。亥合寅，福慢。戌合卯，福虚。卯合戌，福厚。辰合酉，福弱。酉合辰，大利。午合未，福慢。未合午，大利。巳合申，福慢。申合巳，官气盛。（上125）。
    夫合者，和也。乃阴阳相和，其气自合。是以一阴一阳和而谓之合。子合丑，寅合亥，却不子合亥，寅合丑，夫何故？造物中虽是阴阳为合，气数中要占阳气为尊，子为一阳，丑为二阴，一二成三数。（上123）。
    十二月建丑，是时玄枵同在壬亥之间，以玄枵在子之辰，此其所以为子丑之合。正月建寅，是时娵訾在壬亥之间，以娵訾在亥之辰，此其所以为寅亥之合。二月建卯，此时降娄在壬亥之间，降娄戌，故卯与戌合。三月建辰，此时大梁在壬亥之间，大梁酉，故辰与酉合。四月建巳，是时实沈在壬亥之间，实沈申，此巳与申合之数。（上124）。
    六月建未，是时鹑火在壬亥之间，鹑火在午，此午与未合之数。（上124）。
    得日月会同之数，则其相合之用，如日月弥漫六合矣。（上124）。
- 出处：《三命通会》卷二·论支元六合（上123–125）。
- 采用规则：六合：子丑→土；寅亥→木；卯戌→火；辰酉→金；巳申→水；午未→两存（火、土）
- 初稿写法：yueyuan LIU_HE 只有配对，无化气。
- 核对：六对配对四库全同，四库本以月建与日月会同之辰释六合，通篇不言所化。化气：shunshi 与 china-testing 五对同（子丑土、寅亥木、卯戌火、辰酉金、巳申水），午未一作火（shunshi）一作土（china-testing）；tyme4py 只给合的对象。
- 差异：初稿缺化气；午未所化库间不一，四库本无从裁。
- 裁决：五对所化按两库一致收录，出处标"两库一致，四库本不言"；午未两存，表中 element 留空、alternates 记火与土，解读层按日月合论不取所化，旺衰 v2 合化项到校准时再定。
- 状态：已裁

### 刑冲合害-六害  地支六害

- 引文：
    因昼夜阴阳之气感而六合，因六合而生六害，因六害而忌昼夜阴阳之气。六害者，十二支凌战之辰也。（上129）。
    子未相害者，谓未旺土，害子旺水，名势家相害。故子见未则为害。（上129）。
    丑午相害者，谓午以旺火凌丑死金，名官鬼相害。（上129）。
    寅巳相害者，谓各恃临官，擅能而进相害。（上129）。
    卯辰相害者，谓卯以旺木凌辰死土，此以少凌长相害。（上129）。
    申亥相害者，谓名恃临官，竞嫉才能，争进相害。故申见亥、亥见申，均为害。（上129）。
    酉戌相害者，谓戌以死火害酉旺金，此嫉妒相害，故酉人见戌则凶，戌人见酉无灾。（上129）。
    如子生人，畏午冲，而未却去合午。丑畏未冲，而午却去合未。寅畏申冲，而巳合申。卯畏酉冲，而辰合酉。申畏寅冲，而亥合寅。酉畏卯冲，而戌合卯。所以皆为害也。（上129）。
- 出处：《三命通会》卷二·论六害（上129–130）。

- 差异：无。
- 裁决：从初稿。方向性断语不进表。
- 状态：已核

### 刑冲合害-三刑  地支三刑与自刑

- 引文：
    三刑生于三合，亦如六害生于六合之义。如申子辰三合，加寅卯辰三位，则申刑寅，子刑卯，辰见辰自刑。寅午戌加巳午未，则寅刑巳，午见午自刑，戌刑未。巳酉丑加申酉戌，则巳刑申，酉见酉自刑，丑刑戌。亥卯未加亥子丑，则亥见亥自刑，卯刑子，未刑丑。（上130）。
    子卯一刑也，寅巳申二刑也，丑未戌三刑也。（上131）。
    故数自卯顺至子，子逆至卯，极十数而为无礼之刑。寅逆至巳，巳逆至申，极十数而为无恩之刑。丑顺至戌，戌顺至未，极十数而为恃势之刑。七则冲，十则刑，六则合，一理之自然也。（上131）。
    辰午酉亥何以谓之自刑？谓寅申巳亥有寅巳申互相刑，内有亥无刑。辰戌丑未有戌丑未互相刑，内有辰无刑。子午卯酉有子卯互相刑，内有午酉无刑。是以此四位谓之自刑，盖无别物相加，乃曰自也。（上132）。
    《三车一览》以寅巳申为恃势，以三宫中各有长生临官之势。丑戌未为无恩，以三位皆属土，比和为兄弟。其说亦通。（上132）。
    又曰：凡命三刑全，须分刑得人，刑不得入。以年为主，月日时为客，如主刑客，刑得入为贵，刑不入即贱。（上133）。
    或曰：“三刑，刑上、刑下、自刑也。如子刑卯，卯为刑下，子为刑上；丑刑戌，戌为刑下，未为刑上；寅刑巳，巳为刑下，申为刑上。”此说更好。（上133）。
- 出处：《三命通会》卷二·论三刑（上130–133）。
- 采用规则：三刑：寅→巳；巳→申；申→寅（无恩）；丑→戌；戌→未；未→丑（恃势）；子→卯；卯→子（无礼）；自刑：辰；午；酉；亥
- 初稿写法：yueyuan XING 循环三刑（寅刑巳、巳刑申、申刑寅；丑刑戌、戌刑未、未刑丑；子卯互刑），ZI_XING 辰午酉亥。注释自称出自《三命通会》。
- 核对：yueyuan 与 china-testing（刑、被刑两栏）方向全同；shunshi 只存两两配对不分方向；tyme4py 无刑表。四库本"申刑寅，子刑卯……卯刑子，未刑丑"与循环方向逐对相符。
- 差异：无。名目：无恩、恃势、无礼四库本正文为主说，《三车一览》寅巳申恃势、丑戌未无恩为另说，只记不用。
- 裁决：从初稿，方向按四库本。主客另有一层：以年为主、月日时为客，主刑客为贵，客刑主须刑不入；"刑上刑下"说（子刑卯则子为上卯为下）与循环方向一致。这两层进解读层，不进表。
- 状态：已核

### 刑冲合害-三合  地支三合局

- 引文：
    如申子辰，申乃子之母，辰乃子之子，申乃水生，子乃水旺，辰乃水库，生即产，旺即成，库即收。有生，有成，有收，万物得始得终，乃自然之理，故申子辰为水局。若三字缺其一，则化不成局，不可以三合化局论。（上126）。
    巳酉丑，寅午戌，亥卯未皆然。五行不言土者，四行皆赖土成局，万物皆归藏于土故也。若辰戌丑未全，自做土局论。（上126）。
    假令丙丁生人，见亥卯未印，巳酉丑财为得局，见寅午戌火为本局，申子辰水为官局，辰戌丑未土为伤局。（上126）。
- 出处：《三命通会》卷二·论支元三合（上125–127）。
- 采用规则：三合：申子辰→水；寅午戌→火；巳酉丑→金；亥卯未→木；辰戌丑未→土（四库全）
- 初稿写法：yueyuan SAN_HE 四局，无土局。
- 核对：四局四库全同。china-testing 另有半合与拱合表（申子、子辰、申辰各化水之类），yueyuan、tyme4py、shunshi 无。四库本明说"三字缺其一则化不成局"，半合不以化局论。
- 差异：初稿无"辰戌丑未全为土局"一项。
- 裁决：从四库本，补土局一项。半合不入表；旺衰 v2 合局项若加半合，按 DESIGN-命盘层 2.4 走校准，不按此卡。
- 状态：已裁
