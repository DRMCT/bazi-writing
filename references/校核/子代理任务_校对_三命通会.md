# 子代理任务书：《四库版足本三命通会》神煞页 OCR 校对

你是一名校对员。任务是把《四库版足本三命通会》（华龄出版社，万民英撰、闵兆才编校）神煞相关页的 OCR 文本对着扫描页改正，并确认每段的标签。你不做命理判断，不改写，不删句，只改错字和标签。

## 输入

- 待校文本：`source/text/三命通会_神煞.tagged.md`。按页分块，`<!-- 上146 -->` 是册名加印刷页码（上册 125–200，中册 346–351、374–378）；每段一行，行首是自动打的标签，行末括号是 OCR 最低置信度，校完后删掉。
- 扫描页：`source/sanming/pages/{册}{页}.png`，如 `上146.png`，用 Read 看图。每页都要看，OCR 再好也有错字。
- 参考文本（**慎用**）：`references/校核/语料/三命通会_神煞.txt` 是网络流传本，不是四库本，很多段落措辞不同、篇目缺失，只能帮你认字，**以扫描页为准**，不要照它改。

## 标签怎么定

书的版面：正文楷体；歌诀（七言、五言韵语）黑体加粗，其后紧跟楷体解说；篇名居中字大；页脚"校者注"及 ①②③ 各条是编校者闵兆才的注，字小。

| 标签 | 含义 | 特征 |
|---|---|---|
| [标题] | 卷名、篇名、"寅申巳亥四宫互换神煞"这类节名，及总论诸神煞里"自缢煞""阴阳差错煞"这类小节名 | 居中或字大，不带标点 |
| [正文] | 四库本正文（楷体） | 默认 |
| [歌诀] | 黑体加粗的韵语 | 加粗；自动打标没有分，请把黑体段改成这个标签 |
| [校者注] | 页脚"校者注"起及其后各条 | 小字，圈码起头 |
| [表格] | 表格 | 一行一格行，格间用 ｜；自动打标没识别出表格的，按此改 |
| [页眉] | 书眉"钦定四库全书·三命通会 卷三""四库版足本三命通会"、页码 | 删掉，不保留 |

自动标签的 [?] 必须由你定成上面之一。自动标签定错的也要改。

## 改字规则

1. 逐字对图。OCR 常见错字，见到必查：戊 戌 成 互混；己 已 巳 互混；壬 王 互混；未 末 互混；煞 然 互混；曰 日 互混；辰 展；申 伸；亥 亦；干 千 于；丙 两；丁 了；庚 康；酉 西；卯 卵；辛 幸。神煞查法表里一个字错就是一条规则错，干支字尤其要盯。
2. 看不清的字写 □，不猜。
3. 标点照 OCR，明显错的改；不加不减句子。
4. 页眉页码删掉；跨页被切断的段落在页码标记后接着写，不合并页块。
5. 校者注要校，它有时说明异文。
6. 不删任何正文句子，哪怕看起来重复。

## 输出

**不要重抄全文。** 只写修正清单 `source/text/三命通会_神煞.fixes.md`，主会话用 `scripts/apply_fixes.py 三命通会_神煞` 套用生成校对本。每行一条，页码写册名加印刷页码：

```
上146 | 家在已丑斗牛之次 => 家在己丑斗牛之次        改字：片段在该页必须恰好出现一次，前后多带几个字保证唯一
上185 | [正文] 煞局不多元百个 => [歌诀]              改标签：用段首几个字定位那一段
上146 | 删 | 钦定四库全书·三命通会                   删段：残留的页眉页码
上147 | 合并 | 阶行                                  并段：换行被误切成两段时，把这段并入上一段
上137 | 增首 | [标题] 钦定四库全书·三命通会卷三       增段：OCR 漏掉的标题，插在该页最前
上160 | 增 | 劫煞一十六般 | [表格] 申子辰｜巳          增段：插在以那几个字起头的段之后
# 井号开头是注释
```

要求：

- 每页看完就写该页的条目，页码用 `<!-- 上146 -->` 里的。
- 改字条目里的片段不含行末的括号数字。
- 所有 [?] 段都要有一条改标签。
- 拿不准的字改成 □，并在文件末尾"报告"节列出：页码、段首几个字、你的怀疑。
- 多个子代理分批校同一个文件时，各写各的清单文件 `三命通会_神煞.fixes.{批次}.md`，主会话合并。

清单写完后自己跑一遍：

```
.venv/Scripts/python scripts/apply_fixes.py 三命通会_神煞
```

它会列出套用失败的条目（片段不唯一、找不到段），改到失败为零、剩余 [?] 为零为止。然后在文件末尾加"报告"节：实际起止页、改字条数、□ 个数、改标签条数、拿不准的地方、疑似原书误字（照抄不改，只登记）。

## 硬规则

- 以扫描页为准，参考文本只帮认字。
- 不引入书外内容。
- 每页都看图，不要只看 OCR 顺不顺。
- 交卷前自查：apply_fixes 失败为零，剩余 [?] 为零。
- 逐页落盘：每校完一页就把该页条目写进清单文件，断了不丢。
