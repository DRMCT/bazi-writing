# 子代理任务书：《三命通会》六亲章与岁运章校核卡

你是一名校核员。任务是从《四库版足本三命通会》校对本里，按篇逐条建校核卡：逐字抄正文与歌诀里规则性的句子，写成机器可读的采用规则，再给一版"叙事译法"（写小说人物用的话，标自起草）。你只抄原文、归纳结构，不自己发挥命理；叙事译法是唯一允许你自己写的栏，且必须能从采用规则推出来。这两章的卡是给已经建好的两张表补锚点：六亲宫位与童年表（tables/liuqin_childhood.json，现锚在《滴天髓阐微》六亲卡）、岁运事件类型表（tables/suiyun_events.json，现锚在滴天髓岁运卡）。

## 输入

- 校对本：`source/text/三命通会_六亲岁运.md`。按页分块，`<!-- 上107 -->` 是册名加印刷页码。标签：[标题] 篇名；[正文] 四库本正文；[歌诀] 韵语；[校者注] 编校者注（不引作依据，只可在核对栏提）。
- 篇目：上册卷二 论大运（上107）、论小运（上112）、论太岁（上113）、总论岁运（上114）、论进交退伏（上115）；中册卷七 论六亲（中484）、妻财引例章（中486）、子息引例章（中487）、父母引例章（中487）、兄弟引例章（中488–493）。上107 页首是论坐命宫的末尾，不建卡。
- 页图：`source/sanming/pages/{册}{页}.png`，只在校对本有 □ 或句子明显不通时看图核字。
- 已有口径（初稿写法栏引它）：`DESIGN.md` 附录 C（财为父、印为母不分正偏；年柱祖辈、月柱父母、日支配偶、时柱子女；星缺只断缘薄）；`references/校核/滴天髓_六亲.md` 四张卡与 `滴天髓_岁运.md` 五张卡（任注：子女以食伤论、父母以印论、兄弟看日主爱憎；岁运战冲和好）；`tables/liuqin_childhood.json`、`tables/suiyun_events.json` 现行两表。与这些不同处写进差异栏，采用规则从四库本正文，裁决栏写"两存、主会话定"。

## 卡片格式

卡文件两个：`references/校核/三命通会_六亲.md`（卡号 三命通会-六亲-总、三命通会-六亲-妻财、三命通会-六亲-子息、三命通会-六亲-父母、三命通会-六亲-兄弟）、`references/校核/三命通会_岁运.md`（卡号 三命通会-岁运-大运、三命通会-岁运-小运、三命通会-岁运-太岁、三命通会-岁运-总论、三命通会-岁运-进交退伏）。一篇一张卡；篇内引例多的（兄弟引例章五页），规则句逐条抄、引例只登记四柱与判词各一行。

```
### 三命通会-六亲-妻财  妻财引例章

- 引文：
    {逐字抄本篇规则性的句子，一句一行，行末括注页码（中486）；歌诀整首抄；引例（"如某命……"）只抄判词句，四柱另列}
- 出处：《四库版足本三命通会》中册卷七 妻财引例章（中486）
- 采用规则：
    {机器可读，见下}
- 叙事译法：
    {自起草，2 到 5 条，每条一句，写"这个人……"式的人物话，不带命理术语；每条末尾括注它对应的采用规则条}
- 初稿写法：{DESIGN 附录 C 或滴天髓卡或现行表的口径，一句}
- 核对：{本篇与滴天髓任注、与附录 C 一致否；本书前后一致否}
- 差异：{不一致处；本书疑似误字处}
- 裁决：{从四库本 / 两存、主会话定}，{理由一句}
- 状态：{已核 / 待作者抽查 / 存疑}
```

## 采用规则怎么写（机器可读）

每个条件一项，项间用"；"。词汇固定：五行用木火土金水；十神用官、煞、财、印、枭、食、伤、比、劫、刃、禄；日主旺弱用身旺、身弱、中和；位置用年、月、日、时、透、藏、当令、有根、无根；关系用生、克、泄、合、冲、刑、会、局、方、重、轻、多、无、清、浊。写不进这套词的照抄原文关键词，报告里登记。

- 六亲：`星：{谁为父、谁为母、谁为妻、谁为子、谁为兄弟，照本篇}；宫：{年月日时各主谁，照本篇}；条件：{…}→{吉凶或事类}`。总卡写六亲的总则（星与宫两套怎么并看）。
- 岁运：大运卡写 `起法：{起运的算法句照抄，顺逆分男女阴阳}；看法：{运干运支各管几年、与命局怎么合看}；吉：{条件}；凶：{条件}`；小运、太岁各写定义与吉凶；总论岁运写岁运与大运谁重、并临怎么看；进交退伏写 `进：{定义}；交：{定义}；退：{定义}；伏：{定义}；吉凶：{…}`。

## 状态口径

- 本篇与滴天髓任注、附录 C 一致：已核。
- 本篇比任注多说的：已核，差异栏注"四库本补"。
- 本篇与任注相反（如父母以印论还是财父印母）：两存，裁决栏写"主会话定"，状态存疑。
- 本篇自身前后不一：存疑，两存并标注。

## 输出与自检

卡写完在仓库根目录跑：

```

.venv/Scripts/python scripts/check_cards.py references/校核/三命通会_岁运.md
```

它把每句引文对校对本核（相似度阈值 0.85），改到零提示。汇报里报：卡数、引文句数、采用规则条数、叙事译法条数、与滴天髓任注和附录 C 的差异清单（逐条）、疑似原书误字。

## 硬规则

- 引文逐字抄校对本，不改字，不引校者注作依据。
- 采用规则不写本篇没有的话。
- 叙事译法不带命理术语（星名、宫名、干支、旺衰这些词不进），每条能回指到采用规则。
