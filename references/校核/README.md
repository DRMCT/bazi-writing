# 校核卡

每张有古籍依据的表，每一条规则一张卡。机器表 `scripts/bazi_core/tables/*.json` 的每条必须带 `source` 字段指向卡号；没有卡的条目不允许进机器表。

## 卡片格式

```
### {表名}-{编号}  {日主}{月支}（或规则名）

- 古籍原文：{逐字引文，繁简随原文}
- 出处：{书名·卷·篇}，{语料版本与取得日期}
- 采用规则：{我们写进机器表的规则，一句话}
- 初稿写法：{vendor 或口诀初稿的写法}
- 差异：{无 / 具体差在哪}
- 裁决：{从古籍 / 从初稿 / 两存并标注}，{理由一句}
- 状态：{已核 / 待作者抽查 / 存疑}
```

体例约定：

- 引文只抄原文，不改字。
- 原文用十神名（财、官、印、食伤、比劫）而不点天干时，"采用规则"照抄十神名，不换算成天干。换算是机器的活：机器表条目带 `kind: stem | tenGod`，运行时按日主用 `shishen.ten_god` 的反查得出天干。人手换算既累又容易错，卡上不做。
- 原文引别书（"书曰""经云"）的话只作旁证，采用时注"引书"，不与本条正文规则并列。
- 可由公式推出的内容不抄：妻子句（妻为生用神之五行，子为用神）不抄；忌句照抄，但由脚本与公式（克用神者、合去用神者）比对，一致的不进机器表，不一致的作例外保留。
- 分支判词（"或……则……"的经验判词）与取用规则分开存，作为十神性格表与谎言候选表的取材来源。

公开版（DRMCT/bazi-writing）不含 `source/` 与 `语料/`：校对本是今人整理本的整本转录，标点校勘和校注、注释属于整理者；网络录入本许可不一。卡上注明版本与页码，可对原书核查。

## 流程

1. 取原文并登记版本。
2. 逐条建卡。
3. 机器表带出处。
4. 差异清单单独列在各表文件末尾的「差异清单」节，交作者抽查；一致条目作者不必看。
5. 古籍例盘写成测试。
6. 口诀歧义先登记再裁决。

## 文件

- `调候_{日主}.md`：日主 × 月支 120 条，每日主一文件。`调候_抽取报告.md` 是 build_tiaohou.py 没放进结构字段的碎片；`调候_忌句比对.md` 是 compare_avoid.py 把 336 句忌句与公式（克用神、合用神、缺用神）比对的逐句判定，公式推不出的作例外进 tiaohou.json 的 avoidExceptions。
- `例盘_抽取报告.md`：extract_lipan.py 从校对本抽书中例盘写成测试夹具的报告，列出未入夹具的行与自检疑点。
- `子代理任务_校对.md`、`子代理任务_调候.md`：穷通宝鉴的校对与抽取任务书；`子代理任务_校对_三命通会.md`：三命通会神煞页校对任务书（页图 `source/sanming/pages/`，清单用 `apply_fixes.py 三命通会_神煞` 套用）。
- `神煞_干类.md`、`神煞_局类.md`、`神煞_柱类.md`：白名单十五种十七张卡（天月二德、孤辰寡宿各拆两张），按查法分组；`神煞_抽取报告.md` 是 build_shensha.py 的解析报告；任务书 `子代理任务_神煞.md`。
- `刑冲合害.md`：天干五合、六合、六冲、六害、三刑、三合、三会七张卡；配对表四库交叉全同，三刑方向、三合土局、六合与天干所化对《三命通会》卷二裁。机器表 `tables/relations.json` 由 `scripts/build_relations.py` 生成，relations.py 读表。
- `十二长生纳音.md`：十干长生位与顺逆、十二宫序、六十甲子纳音三张卡；十二长生只有一条代码谱系，流派（阳生阴死、火土同宫）对《三命通会》卷二裁；纳音五行三方一致，名目从四库本小标题。机器表 `tables/changsheng.json`、`tables/nayin.json` 由 `scripts/build_changsheng.py` 生成，changsheng.py 读表。
- `格局_官财印.md`、`格局_食煞伤.md`、`格局_刃禄.md`：八格成败救应取运八张卡（正官、财、印绶、食神、偏官、伤官、阳刃、建禄月劫），对《子平真诠评注》校对本；刃禄卷末附杂格十一种清单。任务书 `子代理任务_格局.md`；`格局_抽取报告.md` 是 build_geju.py 的解析报告（词表切不动的残片）；`格局_例盘报告.md` 是 extract_ziping_lipan.py 抽徐评命例与取格比对的报告。机器表 `tables/geju.json`，geju.py 读表。
- `子代理任务_校对_子平真诠.md`：子平真诠格局章校对任务书（页图 `source/ziping/pages/`，清单用 `apply_fixes.py 子平真诠_格局` 套用）。
