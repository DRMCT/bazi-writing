# 子代理任务书：五运六气六十年年景（故事年一句，全书共享）

你是起草员。任务：给五运六气新加的分表"六十年：故事年年景"填两个自起草栏（`scene` 年景一句、`epidemicScene` 疫季一句），三十行里你负责一半（任务分派时写明是哪十五行）。据卡栏与年景标签由主会话按卡与规则填好，你不建卡、不改据卡栏、不改标签。

背景（DESIGN-命盘层 4，SKILL 3i）：写小说人物的仓库，按八字生成人物档案与年表。五运六气此前只喂生年底子（某年生的人是什么体格）；这张表反过来按**故事年**说这一年的天下是什么样：同一年所有人物共享的年景（寒年、燥年、风年、湿年、热年，哪一季有疫），年表、年度状态卡、群像推演的事件卡都引它给场景打底。经文依据是六元正纪大论的六十年纪（一年上司天、中岁运、下在泉合看）与六政之纪逐运给的"其运、其化、其变、其病"（太过之年）或"某某胜复同、其运某某某"（不及之年），六步各有本步的气候句与"民乃厉""温病乃作"一类疫季句。

## 输入

- 骨架：`{SCRATCH}/yearscene_skeleton.json`，`rows` 三十行，每行固定值与据卡栏已填：
  - `pair` 一对干支（相隔三十年、运与司天在泉全同）、`years`、`group` 年支组；
  - `shang` 司天、`zhong` 中运（太宫土运一类，太是太过、少是不及）、`xia` 在泉；
  - `zheng` 六政逐运那句（太过之年有其运、其化、其变、其病；不及之年是"某某胜复同，同正某，其运某某某"）；
  - `huaShu` 化数、`zhengHua` 正化日或邪气化日、`zaiGong` 灾宫、`mark` 天符岁会同正；
  - `steps` 六步：每步主气、客气、本步气候句（据卡，六元正纪原句简体）、疫季句（有则非空）；
  - `labels` 年景标签（按规则）：`yun` 是全年主色（岁运太过取本气，不及取乘它的那一气：木不及则燥、火不及则寒、土不及则风、金不及则热、水不及则湿），`upper` 上半年司天之气、`lower` 下半年在泉之气，`epidemicSteps` 有疫季句的步；
  - `scene`、`epidemicScene` 空字符串，你填这两栏，其余一个字不改，不增删行。

## 怎么写

- 写天下不写人命：这一年的年成、天气怎么走、道路河渠、市面与人心。句子里不出现司天、在泉、岁运、太过、不及、运气、六气名、五音名、干支、天符、岁会、正化、邪气化这些词，不出现"命"字。
- `scene` 三十到六十字：开头一句全年主色（照 `labels.yun`），中间上半年与下半年各一笔（照 `labels.upper`、`labels.lower` 与 `steps` 的气候句，写成季节的样子：春旱、夏涝、秋早寒、冬不冻），末尾一笔年成或市面（收成、粮价、路好不好走、人心是躁还是闷）。
- `epidemicScene` 十五到四十字：`labels.epidemicSteps` 非空时写那一季的疫在故事里是什么样（几月起、什么症候的样子用白话、城里还是乡下先起）；为空时留空字符串。三十行里有疫季句的很多，同一年支组六年共享六步，靠 `labels.yun` 与 `zheng` 把它们分开（寒年的疫和热年的疫不是一副样子）。
- 三十行各不相同：同一年支组的五行（六步全同）靠中运与正化邪气化分开；同一中运的六行靠司天在泉分开。不及之年是"先被欺负后反弹"（胜复），年景要写出上半年一副样子、某一季翻脸；太过之年路数一贯，天符、太一天符的四对再加一层"到顶"（灾重、走极端）。
- 每一行都要能从这一行的据卡栏推出来。不写吉凶祝福，不写养生宜忌，不写朝代与地名。
- 病症用白话（"发热出疹子""上吐下泻"），不用医家病名。

## 输出

- 把骨架填完写到 `{SCRATCH}/yearscene_rows_{甲|乙}.json`（任务分派时写明甲或乙），结构与骨架完全一样（key、title、columns、rows），只是你负责那十五行的 `scene`、`epidemicScene` 填上了，另一半保持空字符串。JSON 用 UTF-8、ensure_ascii=False、indent=1。
- 汇报里报：填了几行、有没有留空、有没有带禁词（自己用骨架里的六气名、五音名、干支 grep 一遍）、你觉得哪几行拿不准。

## 硬规则

- 只填 `scene`、`epidemicScene`，其余键与值一个不改。
- 不带任何运气与命理术语，不带干支，不带"命"字。
- 不写养生建议，不写吉凶。
