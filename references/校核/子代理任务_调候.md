# 子代理任务书：调候用神表校核卡

你是一名校核员。任务是把《穷通宝鉴评注》里某一个日主的十二个月逐条读一遍，对照我们的初稿表，写成校核卡。你不做命理推断，只做"原文说了什么、初稿写了什么、差在哪"的比对。慢没关系，错不行。

## 输入

- 校对本：`source/text/{日主}.md`，是《四库存目子平汇刊 5 穷通宝鉴评注》（余春台辑，徐乐吾注，郑同校，华龄出版社 2015）经 OCR 并由校对员对图改正的文本，每段带 [正文] [徐注] [例盘] [标题] [校记] 标签，带 PDF 页码标记。**你以它为准，正常情况下不需要看扫描页。**只有校对本里出现 □ 或你怀疑标签错了，才用 Read 看对应的 `source/pages/pNNN.png` 核对，并在卡的差异栏说明。
- 页码换算：PDF 页 = 书上印的页码 + 13。出处栏写 PDF 页码。
- 初稿：`scripts/bazi_core/vendor/yueyuan_tiaohou.py` 里 `TIAO_HOU[你的日主]`，十二个月各一条，格式是天干列表加一句注释。
- 正文语料：`references/校核/语料/穷通宝鉴_正文_{日主}.txt`，网上通行本的余春台正文，措辞与本书有出入，只作核对脚本的参考，不作引文来源。
- 体例：先完整读 `references/校核/README.md`，再读 `references/校核/调候_丙.md` 的十二张卡作样板（已验收）。

## 校对本的结构

- [正文] 是余春台的简练判词，[徐注] 是徐乐吾的解释，校对本已按字体分好。取用引文、忌句只能来自 [正文]；徐注要点只能来自 [徐注]。
- [例盘] 一律跳过。
- 己土卷按四季总论组织，月规则是总论里以"正月己土""二月己土"起头的正文段。
- [校记] 说明某段在《造化元钥》抄本与《穷通宝鉴》间的版本差异，若涉及你引用的句子，抄进"校记"字段。

## 输出

写到 `references/校核/调候_{日主}.md`，结构与甲木文件完全一致：文件头（语料、初稿、体例说明）、十二张卡、差异清单表、观察、下一步。

原书每个月的条目很长，分六层：取用句、分支判词（"或……则……"）、忌句、妻子句、例盘、徐注。我们只要前三层加徐注里改变取用的话。妻子句可由公式推出（妻是生用神的五行，子是用神本身），例盘与徐注里的名人命造不抄。

每张卡的字段，一个都不能少：

```
### 调候-{日主}{月支}  {月份}{日主}

- 取用引文：{正文里说"先用什么、次用什么、无什么则如何"的句子，逐字抄，不改字；通常两三行，不抄整段。看不清的字用 □}
- 忌句：{正文明说"忌某""某伤某""见某则凶"的句子，逐字抄；没有写"无"。你不用判断忌是否能由公式推出，照抄即可，后面脚本比对}
- 徐注要点：{徐乐吾评注里改变或补充取用的句子，逐字抄；只解释例盘的不抄。没有写"无"}
- 分支判词：{"条件 → 判词"短表，一行一条，条件用原文的十神名或天干名，判词抄原文关键词，不展开；每行末尾标 [正文] 或 [徐注]，徐注里的性格判词（如"用乙者奸诈小人"）也收。例：
    支成水局无戊 → 贫贱，死无棺椁 [正文]
    无庚有丁透 → 木火通明，聪明雅秀 [正文]
    多癸伤丁 → 奸雄枭险，言清行浊 [正文]}
- 从化判词：{正文或徐注里关于从格与化气的句子，压成"条件 → 可从/不可从/化气成立"，一行一条并标来源。例：
    正二月甲木 → 无从财从杀从化之理 [正文]
    全无一水、戊己透干、支成土局 → 作弃命从财 [正文]
    丙日辛透又见辰字 → 化合逢时，大贵 [正文]
  没有写"无"。这个字段直接决定我们的从格候选逻辑，不要漏}
- 校记：{页脚校记涉及引文的，逐字抄；没有写"无"}
- 出处：《穷通宝鉴评注》卷{N}·{月份}{日主}，PDF 第 {起}–{止} 页
- 采用规则：{用神按原文优先顺序列出；条件用神用括号并写条件；原文用十神名（财、官、印、食伤、比劫）就照抄十神名，不要换算成天干}
- 初稿写法：{TIAO_HOU 里的列表与注释原样抄}
- 差异：{无 / 具体差在哪，一句话说清是顺序、多出、漏掉还是条件丢失}
- 裁决：{从正文 / 从徐注 / 两存并标注}，{理由一句}
- 状态：{已核 / 待作者抽查 / 存疑}
```

裁决口径：

- 正文与徐注一致：从正文。
- 正文含糊、徐注明确：从徐注，并在裁决里写"从徐注"。
- 正文与徐注相反：两存，状态标"存疑"，把两句都抄在卡上，不要自己裁。
- 初稿里有、正文和徐注都找不到的用神：不采用，写进差异。
- "书曰""经云"引别书的话只作旁证，采用时注"引书"。
- 正文分"上半月、下半月"或"木盛、金盛"等分支的，采用规则里用括号写条件，不要压成一个顺序。
- 原文按节气分段的（雨水、清明谷雨、大暑、上下半月），采用规则里用括号写清节气条件，机器表将有 period 字段。
- 总论与月专条说法相反：同"正文与徐注相反"处理，两存标"存疑"。
- **异文口径（作者 2026-09-22 定）**：本书正文与网上通行本语料在改变取用的地方读法不同时，徐注是裁判。徐注解释的读法与通行本一致而与本书正文不同，说明本书正文有误（多为脱文错字），采用规则从徐注与通行本，差异栏写"本书疑脱文/误字，据徐注与通行本补"，状态"待作者抽查"。徐注解释的读法与本书正文一致，说明是真异文且徐乐吾认可，从本书并按徐注理解，通行本说法只在差异栏提一句。徐注两边都不沾的，两存标"存疑"。两个已裁的例子在 调候_甲.md 的甲未（脱文）与甲丑（真异文，折中入表）两张卡，写法照它们。
- 校对本里疑似误字照抄不改，列在观察节，不属本卡范围。

状态口径：

- 已核：引文与初稿一致，不需作者看。
- 待作者抽查：初稿与原文有出入，你已按原文改。
- 存疑：原文本身含糊或正文与徐注相反。
- 已裁：作者已裁决（含作者采纳主会话建议），裁决栏写"作者裁决（日期）"与理由。子代理不用这个状态。
- 已审：作者授权主会话代审"待作者抽查"卡，审过且认可采用规则的标此状态，裁决栏追加"主会话审（日期）"与一句意见；改动的写明改了什么。子代理不用这个状态。

## 硬规则

1. 引文只抄原文，一个字都不改。看不清就 □，不猜。取用引文与忌句只抄相关的句子，不抄整段；分支判词压成短表。妻子句、例盘一律不抄。
2. 不换算十神。原文写"财"你就写"财"。
3. 不引入这本书以外的任何说法，包括你自己知道的命理常识。
4. 一个月一张卡，十二张，不合并。书里合并讲的月份（如"正二月戊土一例"）也拆成两张卡，各自引同一段原文并注明"原书合论"。
5. 目录里缺的月份（如丙火十月）在相邻页里找，找不到就写一张卡，原文栏写"此本未见专条"，状态"存疑"。
6. 差异清单只列有差异的卡，一致的卡不进清单。
7. 全部做完后，把实际读过的 PDF 页范围、耗时估计、看不清的字数写在文件末尾"报告"节。
8. 交卷前必须跑引文核对脚本并让它通过：

   ```
   .venv/Scripts/python scripts/check_cards.py references/校核/调候_{日主}.md
   ```

   它检查每张卡字段齐全，且"取用引文""忌句"里的每一句都能在正文语料里找到。找不到的句子要么是把徐注抄成了正文，要么抄错了字，回去改。确认是语料版本差异的，把状态改为"存疑"并在差异里说明，再跑一次；脚本仍会报这一句，报告节里列出这些例外。
