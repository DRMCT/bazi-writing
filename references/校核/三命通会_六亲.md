### 三命通会-六亲-总  论六亲

    六亲者，父母、兄弟、妻子也。（中484）。
    六甲娶己为妻，甲己合而生庚辛为子。（中484）。
    男取克干为嗣，女取干生为息，则己者，庚辛之母；庚辛者，己之子也。（中484）。
    庚娶乙木为妻，乙庚合而生丙丁，则乙庚者，丙丁之父母，庚为父，乙为母，故谓阴干生我为母，我克阳干者为父，克我者为官、为子，我克者为财、为妻，比和者为兄弟、姊妹，生我妻阴干为丈母，妻克阳干为丈人，克我女者为女婿，食神为孙。（中484）。
    且如六甲生人，以癸水为母，癸为正印，如遇己土正财；戊土为父，戊合癸也。（中484）。
    戊是偏财，如遇比劫，则父有伤。（中484）。
    六乙生人，亦以癸为母，癸是偏印；以戊为父，戊是正财。（中484）。
    甲乙俱以庚辛为子，庚金为男，在甲则为七煞，在乙则为正官也。（中484）。
    辛金为女，在乙则为七煞，在甲则为正官也。（中484）。
    己土为妻，戊土为妾，谓乙木克己土也。（中484）。
    虽云阴见阴，不成配合，然阴木克不得阳土，且妇人以阴为正也，故云甲乙俱以己为妻，戊为妾。（中484）。
    如女人，则甲遇庚七煞，乙遇庚正官，皆夫星也。（中484）。
    谓庚是阳男，为正夫属阳，不可以辛阴为夫也，但阳见阳多无情，阴见阳则夫妇和鸣。（中484）。
    或云：取正财为妻，偏财为妾；女甲则辛为正夫，取阴阳之正合也。（中484）。
    甲乙生人，俱以甲为兄姊，乙为弟妹，以丁为婆，生我父者为祖母，丁生戊也。（中484）。
    壬水为公，壬与丁合也。（中484）。
    又以丁火为丈母，生我妻者为我外母，丁生己配与甲作正妻也。（中484）。
    壬为丈人，壬与丁合也。（中484）。
    妻之兄弟为妻舅。（中484）。
    己土为妻，戊土则为妻兄、妻舅。（中484）。
    癸水则是舅之妻，为妗也。（中484）。
    女人取用，与男不同，我生者为子，克我者为夫，生我夫者为姑，克我姑者为公。（中484）。
    其余父母、兄弟，皆与男同断，但须辨其阴阳耳。（中484）。
    如甲乙干，则以丙为男，丁为女，庚为夫，辛为夫之兄弟，己者姑，甲为公……。（中484）。
    ……也。（中485）。
    或曰：食神为子，伤官为女，取阴阳之各生也。（中485）。
    《经》云：“以年为祖业，月为父母、兄弟、门户，日为妻妾、己身，时为子息。”（中485）。
    须看四柱之中，父母、兄弟、妻子星居何地？（中485）。
    论旺相休囚而言其吉凶。（中485）。
    如父母星坐长生、旺库、禄马、贵人之地，则主父母富贵，福寿荣耀。（中485）。
    如坐空刑、克煞、死亡、衰败交并之地，则主父母贫薄、破伤、刑夭或死于外，及不善终。（中485）。
    若带刑、带破害，虽居于生旺库之地，主父母有寿而贫贱。（中485）。
    兄弟星若生得时得令，坐长生、库旺、禄马、贵人之地，则主兄弟富贵荣华成群。（中485）。
    如坐刑克、煞刃、死绝、衰败之地，兄弟不得力。（中485）。
    如坐长生、旺库而遇刑冲、破害者，虽有兄弟而仇敌，及不得力。（中485）。
    如妻妾星坐生旺库、禄马、贵人之地，或有物以生之，主妻妾富贵荣华，美貌多才。（中485）。
    如坐空刑、克煞、羊刃、死绝、冲败之地，则主妻妾贫薄，丑貌、刑夭、淫乱、残疾，或产亡不得力。（中485）。
    如坐生旺、禄马之地，被刑冲、破害，妻虽有寿，亦主破相贫薄。（中485）。
    如禄马、贵人、财库之地带刑冲克煞，主妻虽富贵亦夭。（中485）。
    如子息星坐生旺、禄马、贵人、官印之地，有物以相生，主子息荣华聪明，多得送老。（中485）。
    如坐禄马、贵人居于死绝之地，虽有聪明俊秀，不送老也。（中485）。
    如居生旺之地被刑冲、破害，有子主愚顽，或残疾送老。（中485）。
    如居死绝又刑冲、破害、劫财之地，不得子之力，纵有子，主残疾破相，或不才。（中485）。
    女命如子居生旺之地，主多子；如坐禄马、贵人，主子富贵福寿；如坐空刑、克煞并冲羊刃、死绝之地，主子不得力。（中485）。
    若妾位居生旺则宜，主偏生之子。（中485）。
    《赋》云：“论其眷属，忧其死绝。”（中485）。
    《三命》云：“四柱观其九族，三元辩其六亲”是也。（中485）。
    答曰：本经所谓“明干有时明干取，明干无时暗中求”是也。（中485）。
    如柱无癸字只有戊字，是甲乙之父，将父求其母，如无母，只将壬为母，亦须论戊为父。（中485）。
    其戊壬不得系婚配，非儿女嫁娶，必是服内成亲，或母多父岁，或失婚而再配也。（中485）。
    答曰：不论先后，只以强为兄，弱为弟。（中485）。
    但世人不达正理，以五阳干取为母、为妻、为女，五阴干取为父、为夫、为男，谬戾甚矣。（中485）。
    此法教人甲取己为妻，乙亦取己为妻，不……。（中485）。
    ……当取戊，戊乃阳也。（中486）。
    甲以庚为嗣，以戊为父，以癸为母，乙亦如之，不拘偏正，惟辨阴阳，阳男阴女，理之大顺也。（中486）。
    《神白经》云：“甲人丁为父，壬为母。（中486）。
    乙人戊为父，癸为母。”（中486）。
    是不论阳男阴女，只取阴生阴，阳生阳，生我者为母，与母合干为父，夫妻合而后生子。（中486）。
    阳干伤官为父，正印为母，阴干正财为父，偏印为母。（中486）。

- 叙事译法：
    这个人自小身子弱、家运差，弟弟却处处出头，名声家业都压过了他。（条件：身弱且劫有根且带财得时→弟显，兄不及弟之福）
    这个人和亲兄弟各自投靠了对头的两家，背后的人互相倾轧，兄弟俩也就成了仇。（条件：比劫各带官煞交克→兄弟不和）
    这个人兄弟好几个，彼此冷淡，逢年过节也不走动。（条件：比重→兄弟无情）
    这个人被上头压得太狠，连带着兄弟们也一个个散了。（条件：官煞重→兄弟消疏）
    这个人的父亲半生漂泊在外，最后死在了异乡，没能回到家里。（父母祖上：〔又曰〕月劫且背绝财官→父终外土）
- 初稿写法：现行表兄弟行"比为兄、劫为弟，禄刃同论（任注）；不专看提纲，看日主爱憎"，宫位"月柱（通行）；任注不论提纲"；DESIGN 第 10 节"比劫为手足"；附录 C 无兄弟条，星缺只断缘薄。
- 核对：本章专论兄弟的只前六句：以比劫为兄弟，与任注"比肩为兄，败财为弟"同取比劫；兄弟之分本章按强弱（与论六亲"只以强为兄，弱为弟"前后一致），任注按比劫分，不同。比劫官星交克为不和，任注无此条。赋"官鬼盛，则昆仲消疏"与任注"然官杀太旺亦伤残"同向；"比肩重而兄弟无情"与任注"总之劫刃太旺，财官无气，兄弟反少，纵有，不如无也"同向。宫：赋与"又曰"以月论兄弟，任注"不论提纲之喜忌，全赁日主之爱憎"，不同，与现行表"月柱（通行）"一致。父母：赋与"又曰"以偏财为父、印为母，与父母引例章前后一致；"又曰"另立"男命以年为父，胎为母"，与论六亲《经》"月为父母"不一，本书多说并存。妻：赋"羊刃多而妻宫有损"、"又曰""男逢比劫定伤妻"不分日主衰旺，任注驳"旧书不管日主之衰旺，总以阳刃劫财主克妻"，相反；"夫妻偕老，皆因财旺身强"与原注"财旺身强者，必富贵而多妻妾"同向。子：男命以官煞为子（"男旺官，子必多""七煞有制乃多儿"），女命以食为子（"食比司权，当生贤孝之子""旺夫伤子，乃食位而受伤"），与论六亲、子息引例章前后一致，男命与任注相反。子数：本章"以时之纳音推子之数，水一、火二、木三、金四、土五。有气承旺，则倍数言之；无气背时则减数言之"，任注"命中子只有五数，水一火二木三金四土五也、当令者倍之，休囚者减半"，数目与加减同，任注以子星五行论，本章以时之纳音论。
- 差异：
    1. 兄弟分属：本章按强弱，任注比为兄、劫为弟，不同，两存。
    2. 宫：本章月为兄弟，任注不论提纲，不同；现行表月柱（通行）与本章同。
    3. 四库本补：比劫官星交克不和、比逢禄名高、冲无兄弟、年煞月伤兄弟难有、月伤夺长、时禄煞兄弟无、男命煞重逢比劫兄有弟无、月官兄弟必贵。
    4. 妻：刃劫伤妻不分衰旺（四库本），任注驳之，相反，两存。
    5. 男命子星：官煞（四库本）与任注食伤相反（同子息卡）。
    6. 父母宫另说："又曰"男命年为父、胎为母，与附录 C 月柱主父母不同；本书内与《经》"月为父母、兄弟、门户"并存。
    7. 看法：本章大量以纳音论妻子（日纳音论妻数、时纳音论子数、局中无妻无子看日时所在、子之性情）与神煞（华盖、驿马、井栏斜冲、隔角、惆怅、鼓盆、望乡、狼藉、绝房、狡害、凤凰池），任注与附录 C 皆无，四库本补；子数五数法与任注同数。
    8. 断语硬度：本章断丧父母、克妻、绝嗣处多，附录 C 只断缘薄，比附录 C 重。
