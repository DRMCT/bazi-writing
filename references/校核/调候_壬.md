## 壬水（卷九，12 条）

### 调候-壬寅  正月壬水

- 取用引文：正月壬水，汪洋之象，渊渊不息，既失其令，亦无泛滥之虞，盖水性秉弱故也。先用庚金发水之源，次取丙火以除寒气，又次取戊土以止其流，不致汪洋无度。……凡壬日无比肩羊刃，不必用戊，专以庚金为尊，丙火为佐。或见比劫庚辛，是弱极复生之象，当以戊土为制。戊透科甲，戊藏秀才，异途更显，且事理通达，但无祖业，俱属自创。此格须两透方合。……或戊多有透有藏，得一甲出干，名一将当关，群邪自伏，光辉难掩，权位非轻。
- 忌句：无
- 徐注要点：夫壬水不离丙戊为用，然在春夏，如无庚金发其源，则有涸竭之虞，故必先以庚金为用，有金相生，方取丙火以除寒气，壬水重叠，则用戊土以止其流。虽云庚丙戊并用，序有先后也。……三春壬水，以庚金为主要用神，非金水太旺，丙戊亦不可用，故有庚金透出，无丁火破庚，贡监衣衿不少。……否则，只能用印，不能用煞；……丙火不论用印用煞，皆不可缺，用煞不用印，故业由自创。两透者，谓壬水比肩与戊土七煞并透也，即有比肩刃用戊土之意。……若身弱见煞多，只能取庚印化煞，不能用甲食制煞，即非此论。

- 裁决：从正文，与初稿一致；徐注与正文一致

### 调候-壬卯  二月壬水

- 取用引文：二月寒气悉除，清流湛深，不可用火，专取戊土为堤岸，辛发其源。……或无戊辛有庚，富贵庚透大富，庚藏小富。或支成木局，庚金透干，科甲名显，庚藏异途。或支有木生多火，为木盛火炎，宜取比肩帮身，一滴可润万里，富贵无疑。……凡二月壬水，先戊次辛，又次取庚金。
- 忌句：二月寒气悉除，清流湛深，不可用火，专取戊土为堤岸，辛发其源。……或比肩重重，又须戊土，书曰：土止流水福寿全。若戊不见，名水泛木浮，一生辛苦，再行水运，为水身亡。
- 徐注要点：仲春为壬水死地，木神当旺，泄弱壬水之气，不能无庚辛为用。身弱不能任财，加以春江水暖，无调候之需要，故不用丙火。若比肩多，春水散漫，则用戊土。言专取戊土辛发其源者，用印化煞也。二月壬水，以戊辛为正用，忌甲破戊，忌丁克辛，故无甲丁出干者，不失衣衿之秀。此言无辛用庚。……木盛有火，宜以壬水为主，庚辛为佐，无火专用庚辛。若木多无火而用壬水，无病安用药为？……此节《造化元钥》抄本删除，疑在十月壬水节下，姑志之参考。

    戊辛两藏，无甲丁透干 → 定主秀才 [正文]
    无戊辛有庚 → 富；庚透大富，庚藏小富 [正文]
    单见庚金 → 取富为多；有戊则兼取贵 [徐注]
    支成木局，庚金透干 → 科甲名显；庚藏 → 异途 [正文]
    （同上）→ 有病为贵，病重药重 [徐注]
    木盛火炎 → 取比肩帮身，一滴可润万里，富贵无疑 [正文]
    一派木多，独日干一壬，无庚发源 → 虽儒士亦傍人度日 [正文]；怯懦无能 [徐注]
    无火用壬 → 衣禄常人 [正文]
    木盛有火 → 壬水为主，庚辛为佐；无火专用庚辛 [徐注]
    比肩重重 → 须戊土；戊不见 → 水泛木浮，一生辛苦，再行水运为水身亡 [正文；徐注疑此节属十月]
    甲乙重重无比肩 → 依人度日，全无作为；见庚辛 → 饥寒可免 [正文；徐注疑此节属十月]

    "甲乙重无比肩"当是"无庚辛"之误，"若见庚辛"当是"若见比肩"之误 [正文，疑徐注]
- 从化判词：无
- 校记：无
- 出处：《穷通宝鉴评注》卷九·二月壬水，PDF 第 270–272 页
- 采用规则：戊、辛、庚（庚：无辛用庚，"又次取庚金"；支成木局时庚透科甲），（比肩：木盛火炎时帮身，徐注"宜以壬水为主，庚辛为佐"），（戊：比肩重重时止流，此节徐注疑属十月）；另记忌：不可用火、甲破戊、丁克辛（徐注）；附节"甲乙重重"一条按校勘语读：无庚辛者依人度日，见比肩饥寒可免；木盛救神以庚为主，比肩为辅
- 初稿写法：["戊", "辛", "庚"]，注"三春壬绝地，取庚辛发源"
- 差异：主序无差异，存疑在附节。正文"或甲乙重重无比肩者……若见庚辛，饥寒可免"（通行本同），紧接一段校对本标 [正文] 的话说"甲乙重无比肩，当是无庚辛之误。若见庚辛，当是若见比肩之误"，两说相反。后段是校勘语气，按文意应是徐注，但 p271 扫描页排正文字体；同页"凡二月壬水，先戊次辛，又次取庚金"反排徐注字体（通行本有"先戊後辛，庚金次之"作正文，校对本标 [正文] 合文意），疑原书这几段字体错排。整段附节徐注又说"此节《造化元钥》抄本删除，疑在十月壬水节下"。另，徐注"若比肩多，春水散漫，则用戊土"像是给戊加条件，但同节徐注又说"以戊辛为正用"，不作相反论
- 裁决：两存并标注；主序从正文，与初稿一致，附节救神一条正文与疑徐注两句都抄在卡上，不裁。作者裁决（2026-09-22，授权主会话按建议裁）：分支判词从校勘语（"当是无庚辛之误""当是若见比肩之误"），引文照印本不改。理由：同节前文"又无庚金发源，壬水泄弱，虽儒士亦傍人度日"与总之句"木盛不可无庚"都把"依人度日"归于无庚，徐注"木盛宜用庚金……宜兼取比肩"亦以庚为主、比肩为辅；校勘语的读法与这三处一致，印本读法则与前文自相矛盾。此节是否属十月，不影响取用，存差异栏。
- 状态：已裁

### 调候-壬辰  三月壬水

- 取用引文：三月戊土司权，恐有塞河壅海之患，先用甲疏季土，次取庚发水源。甲庚俱透，科甲显宦；甲透庚藏，亦是秀才品格，名位不少；甲藏寅亥，有庚定主衣衿，如癸出滋甲，异途职高。……或时出丁火，化壬为木，次用庚辛，有火无水，常人。……凡木旺用金，终身有用之命。水旺多见庚金者，乃无用之人，须丙制之方妙。
- 忌句：或支成四库，无甲透克制，名杀重身轻，终身有损；得二甲透干，不见己土，定主富贵。水旺多见庚金者，乃无用之人，须丙制之方妙。
- 徐注要点：辰月为水之墓地，戊土乘旺，不必干透戊土也。无形之中，自有壅塞之患，故必先用甲疏，次取庚金发壬水之源，庚甲以地位相隔，不相克制，各得其用方妙。甲庚相济为用，不可缺一。有癸滋甲者，言甲癸并透也。……墓库之水非旺，故以甲庚并用为原则，若支见子申，会辰成局，弱转为旺，反用财煞者，又当别论。……凡化格以生我化神为用，化木当以水为用，今言用庚辛者，原命有水，而辰月水临墓地，用庚辛发水源也。故云有火无水常人，此与身弱财多，取印劫帮身，看法无异，不必以化格论也。……时值土旺，见己土出干，防甲从己而化，失制煞之用，戊己并透而甲从己合，亦同此论。……总结上文，支见寅卯辰成方，须庚金制之。申子辰成局，无再用庚金之理，须取戊土制之，如见庚金出干，更宜得丙火制金。

### 调候-壬巳  四月壬水

- 忌句：丙透甲出，科甲之贵，然四柱无壬，方妙。或四柱有壬，丙藏常人。或支成金局，不见丙丁，名金水沉寒寒到底，一世孤贫，见火解寒方可。……下半月土旺用事，甲木为佐，金旺，即丙透遇辛，亦不为妙，见丁颇吉。或丁出时干，化合成木，月支又见丁火，无癸破格，亦富贵。
- 徐注要点：十二月壬水，上半月癸辛主事，与十一月同，专用丙火，如比劫出干，酌用戊土，总以丙火解冻为主。下半月己土当旺，木火进气，壬水不作旺论。用丙火解冻，兼取甲木者，防己土浊壬也。但不论上下半月，丙火总为主要之用，故云：有丙，名利两全。以下专论下半月看法。用丙解冻，用辛化己土，生壬水，或用甲木制己土，皆为科甲之贵。但以丙辛甲己不合，无壬伤丙，方可言富贵。……以下三节，述用丁之理，为《造化元钥》抄本所删，据《穷通宝鉴》本补录，可资参考。丙辛俱透，已见上文，但丙辛在冬月，容易化合，即使合而不化，亦不免羁绊用神，减损解冻之力。有丁破辛，则丙火可以保持其温度，故云见丁颇吉。此言以丁火为用。……十二月令见丑，水不冲奔，惟气候太寒，须丙丁而无癸制，方可为用，仍宜甲木为引，通根支下方妙。……冬水以丙戊为主要用神，财官是也，并不限于水木伤官。
