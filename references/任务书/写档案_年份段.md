# 任务书：写一个人档案的年份段（流程第 8 步）

你是 bazi-writing 的解读层。`人物/{名}.json` 的命局段已经写好（第 2 步），事件链 `人物/推演.md` 与裁决 `人物/裁决.md` 已经定了几个人共用的事实（第 6 步）。你补写**年份定的段**：秘密、年表与两难、阶段状态、他人眼中的他，再给说话方式与能力与漏洞各加恰一条走向、性格表里加一条表现层走向；命局段不动。派工那一行给你项目根、`$SKILL` 目录、人名、故事窗（起止年）。

## 先读（按序）

1. `$SKILL/SKILL.md` 流程节；`$SKILL/references/用法/写档案.md` 的体用分层与走向写法、阶段状态卡一节；`$SKILL/references/用法/人物层.md` 的多人矩阵、配角日程两节；`$SKILL/references/用法/戏剧层.md` 的群像推演一节。
2. `人物/推演.md`：逐年的事件链，每步带溯源；`人物/裁决.md`：说法不一的事实的裁定。**共用的事实只认这两份**：谁在哪一年做了什么、先后与因果，档案里不另写一版。事件链没写到的年份，按自己的年表与两难草稿写，写到别人时只写自己这一侧看到的。
3. 本人的材料：`命盘/{名}.json`、`命盘/{名}.年表.json`（逐年机制与领域、候选年份）、`命盘/{名}.两难.json`（带 `--with`，affects 列出谁被牵动）、`命盘/{名}.阶段.json`（带 `--matrix`，七面草稿与 hooks、关系变化面的 E-）。
4. 共用的：`命盘/矩阵.json`（每条边的 draft 与 draftIds）、`命盘/日程.json`（交汇点 J-）、`命盘/群像/推演.json`（事件卡、Q-、TH-）、`命盘/群像/线程.json`。
5. 别人的读者本 `人物/{别人}.读者本.md` 只看命局段，知道他们是什么样的人；他们的年份段不作依据。

## 写什么

- 秘密：一到三条，是他瞒着谁的哪件事；事实照事件链，引 E-（矩阵边）、J-、Q-、TH- 加该年 L-。同一件事补进他的戏用页第七问（瞒着谁、哪件事、谁知道了会怎样，来历标定、ref 写事件链哪一年），补完跑 `check-drama.js … --final`。
- 年表与两难：故事窗内逐年，每条一个两难、他选了哪一头、代价落在哪；照事件链那一年的选择一栏写，事件链写他选了一头的，这里不写成选了一半；每条引该年 L-，可加 J-、Q-、TH-；童年钉事件（六到十二岁）若命局段没写年份，这里补。
- 阶段状态：与故事窗相交的每步大运一张卡，完整段写全七面加第八面"手里有什么"（这十年他手里有什么可押，按设定卡的时代与他的身份写一句：书生是功名、束脩、婚约，军户是田、户帖、军功，学生是学籍、名额、生活费、恋爱，职员是编制、房、婚约、位置，架空世界按设定卡立的那几样），只沾一头的三到四条；每条引 D- 加一个具体年份的 L-，关系变化面引 E-；label 与 text 读者本口径。
- 两难的两头只能从"手里有什么"里拿：一个学生没有家可倾，一个没有功名的人押不了功名。两难草稿（`{名}.两难.json`）给的句子是形态，不是词；"倾家去救还是保住自己这一支"落到学生身上是休学回去还是留下读书、寄钱还是不寄，落到军户身上是回乡还是守屯。规矩以设定卡 `rules` 为准，那个时代不禁的事不写成禁忌，架空世界只认设定卡立的规矩。
- 他人眼中的他：按矩阵指向他的每条边各一句（引 draftIds 的 E-），只写十神边与神煞给的固定看法，随年变的归阶段卡与事件链。
- 走向：说话方式、能力与漏洞各恰一条 `"layer": "走向"`，把几张卡在这一面的偏移按岁数串成一句，引在场卡的 D-；性格表里加一条以"表现层："起头的走向。
- 写班底里的人可以直接写名字；只有命盘的人和龙套按 `书/龙套.md` 的称呼写。
- 读者本口径照旧；不给引号台词；改过的命局段条目一律不动。
