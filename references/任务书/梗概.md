# 任务书：梗概（流程第 7 步）

你把事件链讲成人话。读的人是作者和一个什么材料都没读过的人；他们读完要能回答：这本书讲谁、他要什么、我想不想知道后来怎样。派工那一行给你：项目根、`$SKILL` 目录、写到哪个文件（默认 `人物/梗概.md`）。

## 先读

1. 模板 `$SKILL/references/戏剧层/模板/梗概.md`。
2. `人物/编配.md`、`人物/推演.md`。
3. 主线副线上各人的戏用页 `人物/{名}.戏用页.md`，只为弄清反常举动的来由。

## 怎么写

- 全书一页，每卷一页，开篇一段场面提要，照这个次序排；模板只画了一卷，几卷就写几节。字数照模板，宁短勿长。
- 字数与写全顾不上两头的时候，先保因果：留下一件引出一件的那一串，串不上的事整件删掉，在回复里报删了哪几件。
- 她要什么、丢了会怎样，只从编配表与事件链里取。那里没写的，梗概里也不写，在回复里报哪一卷缺；不拿档案里的话来填，那是替事件链添事。
- 人话。不带编号，不带括号里的出处，不用牌面、线程、热年、主线温度这些词，不用盘上的词。
- 句子靠因为连着，不靠然后。一件事后面跟着它引出的那件事，中间不相干的年份一句跳过。
- 一句讲一件事的因果。一句里挤着三件事，读的人跟不上谁卡了谁，拆开，或删掉一件。
- 人做反常的事，带半句来由，来由从他这个人身上来。
- 大戏写细一点：谁当面对谁做了什么、说了什么意思、什么从此回不去。别的事一句带过。
- 每卷末尾留着那一卷的问题。全书一页停在结局之前。
- 不替事件链添事，不改先后。事件链里标待作者定的地方，梗概里照写两种走法。
- 不给台词，引号不进。

## 交付

文件写到派工给的路径。回复只报：全书一页的头一句、每卷一页各多少字、你觉得最弱的一卷是哪一卷与为什么（一句）。文件写 LF、UTF-8 无 BOM。
