# 任务书：写一个人档案的命局段（流程第 2 步）

你是 bazi-writing 的解读层。为一个人写人物档案 `人物/{名}.json`（bazi-character/v1）里**只看自己的盘就能定的段**，年份定的段先留空列表。这份档案是底册：给作者和起草者查阅，按盘上的事实排，写手不读它。给排戏的人和写手读的那一页叫戏用页，编配之后另写（`写档案_戏用页.md`），他要的是书里的哪样东西、跟谁撞、什么时候盖不住，都在那一页，这里不写。

写完自跑排版、检查、渲染、去术语，零 error 再交。派工那一行给你：项目根、`$SKILL` 目录、人名、这本书的写法轮廓与设定卡（或说设定卡在 `书/主题.md` 之外的哪个文件）、作者给的这个人（一段话或一句）、反推理由（`命盘/约束/{名}.json` 的 note）。Python 用 `$SKILL/.venv/Scripts/python`，跑 bazi_core 模块时 `PYTHONPATH=$SKILL/scripts`，输出中文要 `PYTHONIOENCODING=utf-8`。

## 先读（按序）

1. `$SKILL/SKILL.md` 流程节；`$SKILL/references/用法/人物层.md` 读命盘档案一节；`$SKILL/references/用法/写档案.md` 档案的形状与各段写法、字段的八字来源两节（设定卡、体用分层、说话方式与情绪过程的写法、用神改判、读者本口径）。
2. 样例：`$SKILL/examples/沈砚/人物/沈砚.现代.json`（设定卡怎么落词、每段形状）；主题命题怎么写另看 `$SKILL/examples/林昭/人物/林昭.json`。
3. 本人的材料：`命盘/{名}.json`（features 索引在末尾，溯源编号全从这里取）、`命盘/{名}.弧光.json`（有的话）、`命盘/约束/{名}.json` 的 note。**不读别人的档案、不读事件链**：这一步只写他自己。
4. 规则表按需翻 `$SKILL/references/`。亲密关系、意象、谎言、五运六气四张表脚本已按盘求值进命盘，直接引 IN-、IM-、LI-、YQ-。

## 写哪些段

- 必写：主题命题（写这个人与全书命题的关系，命题没定就写他自己的一问）、性格表里、童年事件（六到十二岁钉事件的年份引命盘的 L-；只写他自己家里的事）、谎言、需要与想要、抵抗线、亲密关系模式（写他要的伴侣像什么，不点别人的名）、说话方式（底色各条；走向那一条留到年份段）、能力与漏洞（同上）、意象系统、视角声音、潜文本提示（literary）。情绪过程不在这里写：它要知道班底才写得准，挪到戏用页第六问，五拍，多一拍破。需要与想要里以为想要的那一条只写心境，落到书里哪样东西由编配定。
- 留空列表待第 4 步：秘密、年表与两难、阶段状态、他人眼中的他。字段在场、traits 或 stages 为空列表，检查器认作待补充。
- 体质与外貌一句引 YQ- 主干或体或主之一，写成习惯不写成症状；同一本书里日主同五行的几个人，体感写法要分开（脚本给的是同一张表），写之前想一句他和同五行的人哪里不一样。
- 读者本口径：所有句子脱离八字成立；五行名、干支、十神、神煞只在 sources 与 note 里；材质用意象表读者本那栏的质地词。不写口头禅与标志动作段。
- 每条 sources 至少一个，全来自命盘 features。

## 交之前自跑

```
"$SKILL/.venv/Scripts/python" "$SKILL/scripts/character_format.py" 人物/{名}.json
node "$SKILL/scripts/check-character.js" 人物/{名}.json --matrix 命盘/矩阵.json
"$SKILL/.venv/Scripts/python" "$SKILL/scripts/character_render.py" 人物/{名}.json --reader
node "$SKILL/scripts/check-terms.js" 人物/{名}.读者本.md --period <设定卡的时代>
```

check-character 对空段不报；三个检查零 error。只写派给你的这一个人；交付只回段数与条数、检查结果、拿不准的三处。文件写 LF、UTF-8 无 BOM。
