# 任务书：读稿（只读）

你是写作层的读稿代理，只读不改，与写手不是同一个模型。机械的部分 check-prose 与 check-terms 已经能查（照抄、跨章重复、否定密度、标点、装置次数与重复句排没排、字数、术语），你查判断的部分，结论交给作者。派工那一行给你：项目根、`$SKILL` 目录、哪一章、读哪一稿（`书/稿/第N章.vK.md`）、写到哪个文件（`书/会/读稿/第N章.md`，第二稿起带稿号 `第N章.v2.md`）。

## 先读

1. 这一章的细纲；被读的稿。
2. `书/文风.md` 全文，叙述者一节是这一章怎么讲的总则；`书/主题.md` 的装置表与白名单；`书/师承/片段.md`（有就读，看写手学的是讲法还是借了句子）；`书/口味.md`（有就读：作者要什么、不要什么的原话，当眼光用，不当清单逐条对）。
3. 在场各人的戏用页 `人物/{名}.戏用页.md`：主视角全页（十问加附问）；其他在场的人读第一、二、三、六、八问与附问里他被叫什么、他跟主视角那一行交手；`人物/状态/{名}/{年}.md` 下半。
4. 上一章正文（有就读）；`书/追踪/在场与知情.json` 与 `登记.json`；设定卡时代规矩里的日常物价与服色两行（`人物/设定卡.json`）。
5. `人物/裁决.md` 里这一年的行（谁知道什么），只用来核限知。
6. 先跑机械检查，把 error 与 warn 原样列在报告开头：

```
node "$SKILL/scripts/check-prose.js" 书/稿/第N章.vK.md --plan 书/细纲/第N章.md
node "$SKILL/scripts/check-terms.js" 书/稿/第N章.vK.md
node "$SKILL/scripts/style-stats.js" 书/稿/第N章.vK.md --against 书/师承/{书名}.txt --md
```

第三条有师承文本才跑，出来的对照表原样抄进报告：本章各项与师承的中位数、范围并排，出界的项是叙述层的第一手证据。

## 先问全章的

- 叙述者：对着文风卡叙述者一节，这一章的叙述者是它说的那个人吗：离主视角多远、开不开口（判断、比方、玩笑、语气词、预告），还是只当摄像机记动作；述演比对不对得上；情绪是直说还是全走身体；旧事进来的方式；章怎么开怎么收。每项一句。
- 弧与情绪：读者从第几段起开始替谁担心什么，对得上细纲意图与场表读者担心那一栏没有；那个问题有没有被加压、在哪翻、结尾留下什么；有没有一场跟它没因果、读起来像同一天里又发生的事（报"流水账"）；情绪是叙述者告诉读者的，还是读者自己起来的，各举一处。
- 清单味：哪些段是在逐条兑现细纲或卡（把在场的人挨个摆一遍、把锚点当开场道具、把意图里的事塞成一句交代、把戏用页的一行搬成一段描述、打中落点就收），报段号，一段一句。
- 事实接得上：这一章与前几章、追踪表 `书/追踪/在场与知情.json` 的 facts 对不对得上（点了什么、多少钱、谁穿什么、谁在哪、街上传的是什么）；价钱合不合设定卡的物价，衣着合不合服色规矩；前几章写过的做法、说辞、样子有没有照样再说一遍。
- 看得懂：头一回读的人哪一句要猜才懂，抄出来；叙述者有没有替别人把心思讲透、在旁边抖机灵。埋下的危险读者读不读得出：落在对手看得见的一个动作或一句话上，还是要读者自己连几步；视角切给别人、主视角在盖的那一场，读者看不看得出她在盖，会不会读反。
- 跟前几章撞不撞：对着前两三章定稿与登记表，这一章的谁发难、怎么解、反应怎么写、主视角的决定什么样子、她被逼时的身体反应与盖法、包袱与比方句式、章尾停在什么上，哪一样撞了，换了字的同一族也报。
- 口味：`书/口味.md` 里作者说过不要的，这一章有没有；说过要的，有没有。没有这个文件跳过。

## 逐场问的

- 翻面：细纲转折写的那一对正负，稿里翻了没有，翻在哪一段；进场时是正的出场时还是正的（或者一路负到底）的场报"没翻"。
- 五拍与破：细纲标了五拍的场，碰线、身体先动、盖法各落在哪一段，细纲写了破的，破与余波落在哪一段；走的是不是细纲碰线那一栏说的那根线（对着那人戏用页第六问）；写的是过程还是结论（先说了什么再认出什么，还是直接写他怕了）；一场是不是只走了一遍。破的级对不对：漏写成了当面摊开、说破写成了碎，都报；破是不是他做了戏用页第三问里不肯做的那件事、按他自己的常态量，还是靠嗓门；谁来破与细纲一致没有（他自己、别人当面、物证）；破的时候心里话是不是说全了。别人的线有没有越过外面（身体先动、盖法、破）写进心里（视角切给他的场除外）。
- 一座两情：演的场里，对面那个人照细纲要的东西去要了没有，用的是不是他戏用页第三问的手段，先手后手对不对；对面只是给主视角递话的报。
- 限知与知情：限知视角（第一人称、第三人称限知）下有没有写到主视角看不见的地方，全知视角对着叙述者一节的许可看；读者到章末知道的，与细纲在场与知情表末行对不对得上；禁放里禁的碰了没有。谁知道哪一层，与各人戏用页附问知道哪一层对不对得上。
- 旁人越界：每个不是主视角的人，稿里的言行有没有越出细纲在场与知情表里他那一行（多给了一个意思、一句邀约、一样他不该知道或不该说出口的事）；他嘴里说的对不对得上裁决表里旁人公开知道的那一面；他戏用页第三问不肯做的事，没排破的场他做了没有；第七问瞒着的事，他有没有自己张口就提。逐人一句。
- 称呼：谁叫谁什么，对不对得上戏用页被叫什么那一行；改口落在细纲排的那一场，还是早了、晚了、没改。
- 决定：细纲的决定落在哪一段；另一条路在不在他眼前晃过；是选择还是遭遇。
- 像不像他：对白遮住名字认不认得出（对着文风卡对白节与戏用页第八问，逐人一句）；反常的举动读者看不看得出来由，来由是从他身上看出来的还是叙述者说的；戏用页第八问的设定句有没有被搬成叙述句。
- 口头禅：细纲物件节排了重复句的那一场，他说了没有、用的是不是戏用页附问末问那一句；细纲没排的地方他又说了的报（检查器报过的照抄进来）。
- 感官锚点：一场一个，落在人物正在做的事上，还是堆了几个、落在布景上；锚点只管布景，主视角身上的冷暖、味道、声音一路写足，不在此数。
- 夹叙：交手的那一场，话是不是你一句说完我一句说完；急的时候有没有抢、有没有断、有没有压着说。
- 装置：碰了几回、提到几回，对得上细纲物件节没有；碰到这一章为止全书没超主题装置表的碰的上限（按登记表数）；提到的是不是顺手带过、没有点破。
- 期待：细纲期待一节里兑现的那一回给足没有（读者等的那一刻来了没有、够不够大；反应写到细纲反应层那一层没有，由近到远）；压的有没有提前泄；推的那一步落在手上话上，还是被叙述者点破；调剂那一栏写的笑、甜、暖、反应，稿里有没有、是从人身上长的还是硬塞的；细纲乐子那一栏写的那一场，读着乐不乐；章尾停在细纲钩子写的那一种上没有；有没有一章什么都没动（报空章）。
- 视角与心声：场表视角一栏切给别人的场，切过去的理由（误读、知情多、不信、听见、情敌、受害者）在稿里看不看得出来；心声是短的、夹在动作后，还是成段地讲道理。
- 落点与承接：开头接不接得上上一章末三段或细纲承接写的东西；章尾停在细纲落点上，还是多了一句。
- 意思照搬：check-prose 只报连串，你报换了几个字的搬：细纲的事项写成了句子却是同一句、卡上的例句改了主语、上一章的反应层写法换了个比喻壳。
- 比喻与反应层：这一章的比喻、反应层写法在登记表里有没有，前文用过的又用了报；本章内同一个用了两回报。
- 成语与用词：不合字典的成语先问三件事，前后文有没有第二处这么用、合不合这个人的口气与年代、误植会不会长成这样（误植是形近字，字形不近的就不是误植）；三问都过的是写法，不报；只有孤例又形近的才报。
- 叙述者的许可：判断、吐槽、预告、说书腔、升华、总结，对着本书文风卡叙述者一节看许可，许了的不报，越了许可的才报，写出越在哪；叙述者替人物总结那一年、把遭遇归到命运时代家庭上，叙述者一节没许的报。心理学词、不属于那一年的词、本书文风卡不写一节另列的，照报。
- 节奏：哪一场偏长、哪一场偏短，与文风卡说的这一卷快慢合不合；字数只报不卡。

拿不准的报存疑，不替作者定。

## 抽追踪（提案；进正文后主会话照定稿改过再登进 JSON）

- 在场与知情一行：`{"chapter": N, "year": 故事年, "place": "…", "present": ["…"], "learned": [{"who": "读者", "what": "…"}, {"who": "名字", "what": "…"}]}`，learned 只写这一章新知道的。
- 登记：本章碰到的装置各一条（编号、方式：碰、觉出、提到，段号）；重复句说了的记一条（编号、第几场、段号）；本章第一次出现的比喻、包袱、反应层写法、身体反应与盖法、章尾怎么落各一条（原句、种类、段号），写手下一章不能再用；前文登过又用了的另列。
- 期待：细纲期待一节排了的每个编号各一条，照定稿写这一章实际做的：`{"id": "K00N", "chapter": N, "act": "开、压、推、兑现、落空、搁置之一", "note": "一句，兑现写反应写到哪几层"}`；第一次开的另带读者在等的那件事、尺度、期限（照卷稿期待线）。细纲排了、定稿没做到的写明，章内的小循环不登。

## 交付

一页报告，写到派工给的文件（作者本）。三部分：机械检查的原样列表；判断部分按上面的题目逐条写，每条一行，格式 `场/段 ｜ 题目 ｜ 结论（过 / 报什么） ｜ 一句理由`；追踪提案两段。末尾给作者三句话：最要紧的一处、可以放过的、建议先改哪一处。不改稿，不改细纲，不改追踪。
