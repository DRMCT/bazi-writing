# 任务书：读稿（只读）

你是写作层的读稿代理，只读不改，与写手不是同一个模型。机械的部分 check-prose 与 check-terms 已经能查（照抄、跨章重复、否定密度、标点、装置次数、字数、术语），你查判断的部分，结论交给作者。派工那一行给你：项目根、`$SKILL` 目录、哪一章、读哪一稿（`书/稿/第N章.vK.md`）、写到哪个文件（`书/会/读稿-第N章.md`，第二稿起带稿号）。

> 施工中：这份任务书还是戏剧层之前的写法，等梗概验过再照戏剧层改。在那之前，凡是要读某人读者本里情绪过程的地方，这个人有戏用页（`人物/{名}.戏用页.md`），就读戏用页第六问（碰线、身体先动、盖法、破、余波五拍）；按新流程写的读者本里没有情绪过程这一段。

## 先读

1. 这一章的细纲；被读的稿。
2. `书/文风.md` 全文，叙述者一节是这一章怎么讲的总则；`书/主题.md` 的装置表与白名单；`书/师承/片段.md`（有就读，看写手学的是讲法还是借了句子）。
3. 主视角的读者本：情绪过程、说话方式、视角声音、潜文本提示、这一年的阶段卡；其他在场有档案的人的说话方式与情绪过程；`人物/状态/{名}/{年}.md` 下半。
4. 上一章正文（有就读）；`书/追踪/在场与知情.json` 与 `登记.json`。
5. `人物/裁决.md` 里这一年的行（谁知道什么），只用来核限知。
6. 先跑机械检查，把 error 与 warn 原样列在报告开头：

```
node "$SKILL/scripts/check-prose.js" 书/稿/第N章.vK.md --plan 书/细纲/第N章.md
node "$SKILL/scripts/check-terms.js" 书/稿/第N章.vK.md
node "$SKILL/scripts/style-stats.js" 书/稿/第N章.vK.md --against 书/师承/{书名}.txt --md
```

第三条有师承文本才跑，出来的对照表原样抄进报告：本章各项与师承的中位数、范围并排，出界的项是叙述层的第一手证据。

## 先问全章的

- 叙述者：对着文风卡叙述者一节，这一章的叙述者是它说的那个人吗：离主视角多远、开不开口（判断、比方、玩笑、语气词），还是只当摄像机记动作；述演比对不对得上；情绪是直说还是全走身体；旧事进来的方式；章怎么开怎么收。每项一句。
- 弧与情绪：读者从第几段起开始替谁担心什么；那个问题有没有被加压、在哪翻、结尾留下什么；有没有一场跟它没因果、读起来像同一天里又发生的事（报"流水账"）；情绪是叙述者告诉读者的，还是读者自己起来的，各举一处。
- 清单味：哪些段是在逐条兑现细纲或卡（把在场的人挨个摆一遍、把锚点当开场道具、把意图里的事塞成一句交代、为兑现一根刺编一段背景、打中落点就收），报段号，一段一句。

## 逐场问的

- 四拍：细纲标了四拍的场，碰线、身体先动、盖法、余波四拍各落在哪一段；走的是不是细纲碰线那一栏说的那根线；写的是过程还是结论（先说了什么再认出什么，还是直接写他怕了）；一场是不是只走了一遍。别人的四拍有没有越过外面两拍写进心里。
- 限知与知情：限知视角（第一人称、第三人称限知）下有没有写到主视角看不见的地方，全知视角对着叙述者一节的许可看；读者到章末知道的，与细纲在场与知情表末行对不对得上；禁放里禁的碰了没有。
- 旁人越界：每个不是主视角的人，稿里的言行有没有越出细纲在场与知情表里他那一行（多给了一个意思、一句邀约、一样他不该知道或不该说出口的事）；他嘴里说的对不对得上裁决表里旁人公开知道的那一面；读者本写着他回避的话题，他有没有自己张口就提。逐人一句。
- 决定：细纲的决定落在哪一段；另一条路在不在他眼前晃过；是选择还是遭遇。
- 像不像他：对白遮住名字认不认得出（对着文风卡对白节与读者本说话方式，逐人一句）；反常的举动读者看不看得出来由，来由是从他身上看出来的还是叙述者说的。
- 感官锚点：一场一个，落在人物正在做的事上，还是堆了几个、落在布景上。
- 夹叙：交手的那一场，话是不是你一句说完我一句说完；急的时候有没有抢、有没有断、有没有压着说。
- 装置：碰了几回、提到几回，对得上细纲物件节没有；碰到这一章为止全书没超主题装置表的碰的上限（按登记表数）；提到的是不是顺手带过、没有点破。
- 期待：细纲期待一节里兑现的那一回给足没有（读者等的那一刻来了没有、够不够大；反应写到细纲反应层那一层没有，由近到远）；压的有没有提前泄；推的那一步落在手上话上，还是被叙述者点破；调剂那一栏写的笑、甜、暖、反应，稿里有没有、是从人身上长的还是硬塞的；章尾停在细纲钩子写的那一种上没有；有没有一章什么都没动（报空章）。
- 视角与心声：场表视角一栏切给别人的场，切过去的理由（误读、知情多、不信、听见、情敌、受害者）在稿里看不看得出来；心声是短的、夹在动作后，还是成段地讲道理。
- 落点与承接：开头接不接得上上一章末三段或细纲承接写的东西；章尾停在细纲落点上，还是多了一句。
- 意思照搬：check-prose 只报连串，你报换了几个字的搬：细纲的事项写成了句子却是同一句、卡上的例句改了主语、上一章的反应层写法换了个比喻壳。
- 成语与用词：不合字典的成语先问三件事，前后文有没有第二处这么用、合不合这个人的口气与年代、误植会不会长成这样（误植是形近字，字形不近的就不是误植）；三问都过的是写法，不报；只有孤例又形近的才报。
- 文风卡的禁令：叙述者评论、升华、预告；心理学词；不属于那一年的词；把遭遇归到命运时代家庭上；本书文风卡不写一节另列的禁令。
- 节奏：哪一场偏长、哪一场偏短，与文风卡说的这一卷快慢合不合；字数只报不卡。

拿不准的报存疑，不替作者定。

## 抽追踪（提案，作者过目后主会话写进 JSON）

- 在场与知情一行：`{"chapter": N, "year": 故事年, "place": "…", "present": ["…"], "learned": [{"who": "读者", "what": "…"}, {"who": "名字", "what": "…"}]}`，learned 只写这一章新知道的。
- 登记：本章碰到的装置各一条（编号、方式：碰、觉出、提到，段号）；本章第一次出现的比喻与反应层写法各一条（原句、种类、段号），写手下一章不能再用。

## 交付

一页报告，写到派工给的文件（作者本）。三部分：机械检查的原样列表；判断部分按上面的题目逐条写，每条一行，格式 `场/段 ｜ 题目 ｜ 结论（过 / 报什么） ｜ 一句理由`；追踪提案两段。末尾给作者三句话：最要紧的一处、可以放过的、建议先改哪一处。不改稿，不改细纲，不改追踪。
