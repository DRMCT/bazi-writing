# 任务书：计划审计（只读）

你是写作层的审计，只读不改。机械的部分 check-plan 已经查过（字段在场、引号、编号在池里、来路认得出、三个走法是否同人、物件次数、章号重号、借鉴字样），你查判断的部分，结论交给作者。派工那一行给你：项目根、`$SKILL` 目录、审哪一层（卷稿、单元记录，或细纲）与文件名、写到哪个文件（默认 `书/会/审计/` 下以被审的对象命名：`卷N.md`、`U-N.md`、`第N章.md`；复审加 `.复审`）。

## 先读

1. 被审的文件；它引的上一层（审单元记录看卷稿那一行与骨，审细纲看单元记录那一章）；`书/主题.md`（全书一问、开篇、命题、叙述结构、装置表）；`书/文风.md` 的叙述节（视角怎么轮）；`书/龙套.md`。
2. `人物/编配.md`（全书一问、主脑、时间尺度、对子表、主次、谁碎、默认下场、钟、物件账）；`人物/推演.md`（事件链，每卷的骨与每年的源、步、选择）与 `人物/裁决.md`（若有）；审卷稿另读 `人物/梗概.md` 这一卷那一页；`命盘/群像/推演.json` 里相关年份的事件卡（在场、各人押了什么、回应倾向）；`命盘/群像/线程.json`。
3. 在场各人的戏用页 `人物/{名}.戏用页.md`：要什么、谁挡着与横着的东西、怎么去要与不肯做的事、信的那句话、碰哪里会疼与破、知道哪一层、跟谁怎么交手；覆盖这一段年份的阶段卡（`人物/状态/{名}/{年}.md`，看"手里有什么"）；设定卡的 `period`、`world`、`rules`。
4. 先跑机械检查，把它的 error 与 warn 原样列在报告开头：

```
node "$SKILL/scripts/check-plan.js" 书/
```

## 各层都问的

- 两难与局：事件链把两难给了的单元，两头都要付代价才算真两难，写出两头各丢什么；一头明显更好的报"选择题"，并说哪一头轻在哪。两头的代价被一个包袱、一个知情差或本来就不想要消掉的是假两难，写明了被什么消掉的算过，没写明的报。主角的打脸局不报选择题，问他怎么赢：赢的那一步是从他自己的手段里出来的，还是从天上掉下来的。主角全书一两回真两难，数一数，多了报；两难多在配角、对手、单元客身上。单元是一局、没有两难的，不报缺两难。
- 选择还是遭遇：主视角的人有没有做一个可以不这样做的决定。承受也算：他选的是一种姿态（活下去、不说、记住、不走），写明另一种姿态是什么、他为什么没取；一个单元里至多一处承受。只是事情落到他头上、他也没取任何姿态的，报遭遇。
- 落差：每一步他以为会怎样、实际怎样，中间有没有落差；样样照预想成了的一段报"记账"。
- 处境：押的是不是这个人这一年真有的东西（对着阶段卡"手里有什么"与他的身份），没有那样东西的人押不了它。
- 规矩与数目：对着设定卡的时代规矩看，这件事在那个时代那种人身上是禁止、默许还是平常事，罚到哪一步，钱和数目对不对；架空的书只对设定卡自己立的规矩。
- 因果逐环：每个后果前面有没有它需要的那一环。规矩里的程序是几步就数几步（第一次怎样、再犯怎样、谁有权、进不进记录、经几道手），一步跳到结果的报"少一环"，写出少的那一环。
- 人与戏用页：这个人这样做，对着他戏用页第三问的手段与不肯做的事、第四问他信的那句话、第六问的破法，撑不撑得住；做了第三问里不肯做的事而计划没把它当成破的，报"不像他"，写出戏用页哪一行顶着。破是不是他的破法（按他自己的常态量，不按嗓门量）。
- 与事件链和裁决的出入：改了事件链定的先后、因果或源的地方逐条列；写到别人的事以裁决为准。
- 调子：对着主题卡乐子一节，这一段乐在哪；许了轻松调子的书，一段里全是藏、怕、被查，主视角碰到险一律写成怕、看不出他的性子，报"调子断了"；乐子只靠调剂栏里插笑话、局本身不好玩的也报。
- 借鉴：从市场、对标、爽点的角度排出来的东西报出来，写作层不从那里出发。

拿不准的报存疑，交现实核（`$SKILL/references/任务书/现实核.md`），不替作者定。

## 审卷稿，逐单元再加

- 主脑：这一卷为哪一人一事，答全书一问的哪一截；每个单元为这一事做了什么，逐年铺陈、单元与单元之间没有那一事串着的报"无主脑"。
- 头绪：这一卷开着几条线，哪几条不为主脑服务；一件事能不能让已经在场的人来做，不另添一个人；主要的几个人隔了几个单元没露面的，该砍还是该叫回来。
- 编配：对子表里横着的那样东西有没有上桌（在谁手里、哪个单元转手或被人拿来挡人）；背景的人有没有当了事件源、开了线程；先手后手与编配的谁主动对不对得上，翻了的有没有写为什么。
- 时间尺度：卷按编配的时间尺度分了没有（长跨度约一步大运，短跨度与回到关口年照编配的段）；短跨度的书单元是不是从局、钟、对手出招、得知里排出来的，还是硬凑热年。
- 来路：每个单元的来路与事件链那一年的源一栏对不对得上；一连几个单元都是热年从天上掉下来的事，报"来路单一"，说漏了哪几种（对手出招、家人出招、得知与认出、局与日历、默认下场到点、旁人求上门）。
- 落下风：编配的每一段，主角在哪个单元真吃了一回亏或被逼到只差一步；出手的是谁、为自己的什么所图、用他什么手段，丢的是两人之间横着的哪样东西。一段里样样照他的安排成了的报"一路赢"；几段的落下风出自同一个人、同一种手段的报"没分开"。
- 破：这一卷谁破、在哪个单元、哪一级；几个人的破挨在一段里的，谁来破分开没有（不全出自主角一张嘴，物证、第三人、期限或局轮着用，被破的那一头先扛一阵）；一连几个人听主角一说就把东西递出来的报。碎的人与编配的谁碎对得上，主角拿信条的没有碎。
- 清算：骨一节写的那条账，在哪个单元当面清算；该当面的一直在暗处的报。
- 默认下场：编配透的那几条，这一卷透、应验、改与事件链对得上没有；先透后兑现，改了的余波落在谁身上写了没有。
- 脱窠臼：这一卷的事读者在别的书里见没见过；见过的那一段，这本书哪里不一样，是不是换了姓名的旧事。
- 删单元测试：删了这个单元，后面哪个单元会读不懂；答不出来的报"可删"。
- 线程账：开着的线程几条、哪几条从开出来就没再动、这一卷合上了几条；闲置超过轮廓表阈值的点名。
- 命题：这一卷回答的那一半，单元表里哪几行真在答它，哪几行与它无关。
- 视角与在场：每个单元的主视角是有戏用页的人；在场名单与事件卡、龙套表对得上；有两难的单元只写一个人的两难。
- 骨架：单元按故事时间排，同年几个单元先后清楚；没有单元的年份怎么过场；开卷开在谁身上、为什么，与主题卡开篇对得上。
- 人话页：开头那一页与单元表、梗概这一卷那一页说的是同一件事，每条两三句，不带编号。
- 期待线：每条有开有兑现的单元（常驻的除外）；尺度写得对不对（回合、单元、卷、全书、常驻）；兑现的大小与压的时间相称；有期限的期限读者看得见；发动机是哪一条、卷末交棒给哪一条，开篇的那条是不是拖到了该交棒以后；卷末兑现够不够大；有没有哪几个单元一个兑现都没有；读者知道、某个人还不知道的那几条，这一卷有没有拿来反讽、有没有让它越叠越高。

## 审单元记录，逐走法再加

- 三个走法真不同：谁做选择之外，事件顺序、两头的代价也不同，不是同一件事换个次序。
- 主视角守住：主视角是卷稿那一行的人；做选择的人是别人的走法里，他的决定有没有写成主视角看得见的一面，主视角自己有没有落下一个可以不这样做的决定；拿别的单元的两难当代价的报越界。
- 来路：走法是不是从卷稿那一行的来路起头的；一局写没写出局上押的是什么。
- 交手：每个人是不是按他自己戏用页的手段去要，先手后手对不对；对面只是给主视角递话的报"独角戏"。
- 兑现：作者选下的兑现一行写实没有，读者在单元结束时拿到的是什么，旁人怎么反应；落空的换来了什么更大的期待。
- 默认下场、物件、破：走法末尾写的透、应验、改，物件转手或被认出，破的级与谁来破，与卷稿骨一节对得上没有。
- 代价最实：哪个走法的两头最疼（有两难的）或赢得最漂亮（打脸局），哪个走法的结尾开着的线程最能往下走。
- 章表（作者选定后）：每章一句功能答不答得出"读者离开时多知道什么"；读者追什么那一栏答不答得出一个问题，答不出的章报"该并"；删章测试逐章做；章数与单元的赌注相称，一件事排得太长是撑；位置栏与主题卡的叙述结构对得上，章号全书不重。

## 审细纲，逐章再加

- 意图与赌注对不对得上单元记录里这一章的功能与卷稿那一行的赌注；赌注是这一章的那一截，不是整个单元的。
- 弧：要什么、起、承、转、合五行齐不齐；起的问题和合留下的问题是不是同一根线上的；场表里有没有跟这根线没因果的场（报"平铺"）；转是不是落在决定那一场。
- 决定：主视角这一章那个可以不这样做的决定写实了没有（哪一场、另一条路是什么）；写无的章，它说的站住的理由成不成立；这个决定是不是从别的章或别的单元挪来的。
- 主视角与限知：主视角是卷稿那一行的人；在场与知情表里别人那一行只写主视角看得见的一面；读者行到章末知道的不超过主视角知道的（回忆章），与裁决表谁知道什么、各人戏用页的知道哪一层对得上，与上一章的在场与知情表接得上。
- 翻面：每场转折写的是一对正负，进场到出场什么翻了面；写成两个画面、没有翻面的场报"没翻"。
- 一座两情：演的场对面要什么、怎么去要，是不是取自他戏用页的第一、三问与交手一行；对面只给主视角递话的场报。
- 场表：述演比合不合文风卡叙述者一节，述的场是不是真能一段带过、演的场是不是真值得演；谁的五拍与这个人戏用页第六问对得上，碰线那一栏说的线在第六问里有，被碰的方式在这一场里真发生；不是主视角的人的线只从外面写（视角切给他的场除外）；五拍只在决定落下的那一场；给了锚点与落点的，转折里说清它承载什么了没有。
- 破：写了破的，级对不对（漏、说破、碎）、谁来破对不对、是不是他做了第三问里不肯做的那件事；碎的人与编配的谁碎对得上，一人全书一回；读者担心那一栏答不答得出替谁担心什么。
- 禁放：禁的三类齐不齐（提前揭的、主视角看不见的、本章不碰的）；放的有没有越出单元那一行的边界；上一轮审计留给细纲的条目落了没有。
- 物件与主题装置表一致，次数不超；伏笔物件不写成反复动作；重复句（口头禅）写了落在第几场，隔章排得匀不匀，一章里不重复。
- 时候与承接：这一天在合成顺序里站得住，月份与天气合事件链、编配的钟与状态卡年景；承接接得上上一章的落点；叙述结构不是正叙时，位置栏与单元章表一致，待排的要标待排。
- 没有台词、没有固定动作、没有逐点字数、没有描写句（写成了正文能直接用的句子报出来，写手会照抄）。
- 期待与断章：期待一节的编号在卷稿期待线里；兑现落在演的那一场，反应层写到哪一层；推是真往前挪了一步，还是压换了个名字；搁置有没有理由；松紧、调剂与前后几章合不合（连着绷没喘气、连着几章什么都没动）；钩子的类型与这一章的合对得上；回合的末章兑现或设钩了没有。

## 交付

一页报告，写到派工给的文件（作者本）。两部分：机械检查的原样列表；判断部分按上面的题目逐条写，每条一行，格式 `单元/走法/章 ｜ 题目 ｜ 结论（过 / 报什么） ｜ 一句理由`。末尾给作者三句话：最要紧的一处、可以放过的、建议先改哪一处。不改任何文件。
