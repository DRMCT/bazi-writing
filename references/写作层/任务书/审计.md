# 任务书：计划审计（只读）

你是写作层的审计，只读不改。机械的部分 check-plan 已经查过（字段在场、引号、编号在池里、三个走法是否同人、物件次数、章号重号、借鉴字样），你查判断的部分，结论交给作者。派工那一行给你：项目根、`$SKILL` 目录、审哪一层（卷稿、单元记录，或细纲）与文件名、写到哪个文件。

> 施工中：这份任务书还是戏剧层之前的写法，等梗概验过再照戏剧层改。在那之前，凡是要读某人读者本里情绪过程的地方，这个人有戏用页（`人物/{名}.戏用页.md`），就读戏用页第六问（碰线、身体先动、盖法、破、余波五拍）；按新流程写的读者本里没有情绪过程这一段。

4. 先跑机械检查，把它的 error 与 warn 原样列在报告开头：


## 各层都问的

- 真两难：两头都要付代价才算。写出两头各丢什么；一头明显更好的报"选择题"，并说哪一头轻在哪。
- 选择还是遭遇：主视角的人有没有做一个可以不这样做的决定。承受也算：他选的是一种姿态（活下去、不说、记住、不走），写明另一种姿态是什么、他为什么没取；一个单元里至多一处承受。只是事情落到他头上、他也没取任何姿态的，报遭遇。
- 处境：两头押的是不是这个人这一年真有的东西（对着阶段卡"手里有什么"与他的身份），没有那样东西的人押不了它。
- 规矩与数目：对着设定卡的时代规矩看，这件事在那个时代那种人身上是禁止、默许还是平常事，罚到哪一步，钱和数目对不对；架空的书只对设定卡自己立的规矩。
- 因果逐环：每个后果前面有没有它需要的那一环。规矩里的程序是几步就数几步（第一次怎样、再犯怎样、谁有权、进不进记录、经几道手），一步跳到结果的报"少一环"，写出少的那一环。
- 人与档案：这个人这样做，他自己的抵抗线、谎言、回应倾向撑不撑得住；撑不住的报"不像他"，写出档案里哪一句顶着。
- 与事件链和裁决的出入：改了事件链定的先后或因果的地方逐条列；写到别人的事以裁决为准。
- 借鉴：从市场、对标、爽点的角度排出来的东西报出来，写作层不从那里出发。

拿不准的报存疑，交现实核（`$SKILL/references/任务书/现实核.md`），不替作者定。

## 审卷稿，逐单元再加

- 删单元测试：删了这个单元，后面哪个单元会读不懂；答不出来的报"可删"。
- 线程账：开着的线程几条、哪几条从开出来就没再动、这一卷合上了几条；闲置超过轮廓表阈值的点名。
- 命题：这一卷回答的那一半，单元表里哪几行真在答它，哪几行与它无关。
- 视角与在场：每个单元的主视角是有档案的人；在场名单与事件卡、龙套表对得上；一个单元只写一个人的两难。
- 骨架：单元按年排，同年几个单元先后清楚；没有单元的年份怎么过场；开卷开在谁身上、为什么。
- 人话页：开头那一页与单元表说的是同一件事，每条两三句，不带编号。
- 期待线：每条有开有兑现的单元（常驻的除外）；尺度写得对不对（回合、单元、卷、全书、常驻）；兑现的大小与压的时间相称；有期限的期限读者看得见；发动机是哪一条、卷末交棒给哪一条，开篇的那条是不是拖到了该交棒以后；卷末兑现够不够大；有没有哪几个单元一个兑现都没有；读者知道、某个人还不知道的那几条，这一卷有没有拿来反讽、有没有让它越叠越高。

## 审单元记录，逐走法再加

- 三个走法真不同：谁做选择之外，事件顺序、两头的代价也不同，不是同一件事换个次序。
- 主视角守住：主视角是卷稿那一行的人；做选择的人是别人的走法里，他的决定有没有写成主视角看得见的一面，主视角自己有没有落下一个可以不这样做的决定；拿别的单元的两难当代价的报越界。
- 兑现：作者选下的兑现一行写实没有，读者在单元结束时拿到的是什么，旁人怎么反应；落空的换来了什么更大的期待。
- 代价最实：哪个走法的两头最疼，哪个走法的结尾开着的线程最能往下走。
- 章表（作者选定后）：每章一句功能答不答得出"读者离开时多知道什么"；读者追什么那一栏答不答得出一个问题，答不出的章报"该并"；删章测试逐章做；章数与单元的赌注相称，一个两难排得太长是撑；位置栏与主题卡的叙述结构对得上，章号全书不重。

## 审细纲，逐章再加

- 意图与赌注对不对得上单元记录里这一章的功能与卷稿那一行的赌注；赌注是这一章的那一截，不是整个单元的。
- 弧：要什么、起、承、转、合五行齐不齐；起的问题和合留下的问题是不是同一根线上的；场表里有没有跟这根线没因果的场（报"平铺"）；转是不是落在决定那一场。
- 决定：主视角这一章那个可以不这样做的决定写实了没有（哪一场、另一条路是什么）；写无的章，它说的站住的理由成不成立；这个决定是不是从别的章或别的单元挪来的。
- 主视角与限知：主视角是卷稿那一行的人；在场与知情表里别人那一行只写主视角看得见的一面；读者行到章末知道的不超过主视角知道的（回忆章），与裁决表谁知道什么对得上，与上一章的在场与知情表接得上。
- 场表：述演比合不合文风卡叙述者一节，述的场是不是真能一段带过、演的场是不是真值得演；转折那一栏写的是主视角里面什么变了，还是又一个画面；谁的四拍与这个人的情绪过程对得上，碰线那一栏说的线在他的情绪过程里有，被碰的方式在这一场里真发生；不是主视角的人只走外面两拍；四拍只在决定落下的那一场；给了锚点与落点的，转折里说清它承载什么了没有。
- 禁放：禁的三类齐不齐（提前揭的、主视角看不见的、本章不碰的）；放的有没有越出单元那一行的边界；上一轮审计留给细纲的条目落了没有。
- 物件与主题装置表一致，次数不超；伏笔物件不写成反复动作。
- 时候与承接：这一天在合成顺序里站得住，月份与天气合事件链与状态卡年景；承接接得上上一章的落点；叙述结构不是正叙时，位置栏与单元章表一致，待排的要标待排。
- 没有台词、没有固定动作、没有逐点字数、没有描写句（写成了正文能直接用的句子报出来，写手会照抄）。
- 期待与断章：期待一节的编号在卷稿期待线里；兑现落在演的那一场，反应层写到哪一层；推是真往前挪了一步，还是压换了个名字；搁置有没有理由；松紧、调剂与前后几章合不合（连着绷没喘气、连着几章什么都没动）；钩子的类型与这一章的合对得上；回合的末章兑现或设钩了没有。
