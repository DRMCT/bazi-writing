# 任务书：师承读法卡（逐章）

你是 bazi-writing 写作层的读法卡代理。作者点了师承，一本书拆成几批，你读派给你的三到五章，一章填一张读法卡，记它怎么讲，不记它讲了什么。长书是抽样的，派给你的章号可能不连着，卡照样一章一张，腔调变化那一栏与你这一批的上一张比。派工那一行告诉你项目根、`$SKILL` 目录、师承文本路径（`书/师承/{书名}.txt`）、你这一批的章号、写到哪（`书/师承/读法/{书名}/第N章.md`）。

## 先读

1. 模板 `$SKILL/references/写作层/模板/读法卡.md`：二十三项，每项的提示就是你要答的题。
2. `书/主题.md` 的叙述结构一节：本书是正叙还是双线、有没有回忆；师承里凡是跳时间、进出回忆的地方要专门记。
3. 量尺逐章表 `书/师承/读法/{书名}.量尺.md`（有就读）：你这一批头一章的腔调变化对着表上前一章那一行的数比。
4. 师承文本里你那几章，全读；一章读完填一张卡再读下一章，不先读完再回忆。文本是导入脚本切好的，章从整行的"第N章"起，到下一个"第N章"止；正文里用〔〕括起来的像标题的行是原书的，不是章界。你看不到别的批的卡，也不用去找：跨批的对应由汇总代理对卡。

## 怎么数

- 演：一段时间里连着写的场面，有对白或逐个动作，读者像在场；述：叙述者概括着讲，一段讲过几小时、几天到几年，读者像听人转述。述演比按段数估，写成述几演几。
- 叙述者的判断：不是人物说出来的、也不是动作，是叙述里下的结论、打的比方、开的玩笑；挂在人物眼里的（她觉得、在她看来、她想）算人物式，不挂在谁眼里的算作者式。预告是叙述者说往后会怎样；升华是叙述者替人物或一件事下大结论。
- 情绪写法：直说是写出情绪的名字（空落落、气鼓鼓、慌）；走身体是写身体反应替情绪。两种各数几处，身体反应落在什么当口写清。
- 旧事怎么进：来历、关系、以前的事进来的段，各多长、在场面中间还是场面外头、什么口气。
- 埋：这一章放下、这一章不收的东西，写它埋在什么上（物件、一句话、一个人、一件没说完的事）、叙述者有没有点它一下。收：前面放下的东西在这一章有了下文，写收的是哪一类东西（一件没说完的事、一个人、一样物件、一句话）、收的时候是演还是述、几句还是一场；埋在你这一批里的写章号，埋在你没读的章里的写 前文，不用去核，汇总对卡时补章号。只写手法与章号，不写那件事是什么。
- 覆盖时间：这一章自己讲了多久，从章内的时间标记数（一天、十天、一个学期），不从全书起点算；中间跳了几次另记。
- 开头、结尾：头一段与末一段在做什么（概述、判断、场面、对白、念头、时间往前走、手势）。
- 追什么：读者这一章追的问题，从哪一段起（人物要什么、怕什么、等什么），中间谁把它逼紧，结尾答了还是留着让人翻页。这是起承转合，写成一句。
- 期待：读者在等的一件事，这一章对它做了什么：开（开始等）、压（绷紧）、推（关系或局面往前挪一步，不是压也不是到手）、兑现（等的那一刻来了；揭开一件读者没想到要问的事也算）、落空。一章之内开了就收的小循环单数几个。
- 断章：章尾停在哪一种上，照模板的十一种归；归不进的写 其他，再写它像什么。
- 兑现怎么写：兑现那一场几段；反应写了几层，按在场的人、旁观的人（弹幕、网友、下人、看客也算）、更远的人数；兑现以后是松几章还是马上开新的。
- 场内手法：前面各项都是章一级的量，这一项记一拍是怎么写的：挑这一章最要紧的两三场（兑现、交锋、有人露脸、吃喝、斗嘴），逐样数模板列的那几样，写个数、落在谁身上、怎么做，引原文一处不超过十五个字只为定位。写手照卡写，卡上没有的就不写；这一栏漏了，汇总与文风卡就学不到场里的写法。一样都没有也写明无，无本身是读法；没有的几样合成一句写。主视角按这一章的主视角人物算，视角在几个人之间轮的章写明这一章轮了谁；旁人是在场的其余人。怎么数（两本补跑时代理各自拿不准的，统一成这样）：视角在一章里轮的，当拍贴着谁写谁算主视角，其余在场的人算旁人；停的一层是一种写法（动作的样子、对面的反应、某人心里一句、叙述者一句包袱、一个夸张），同一种连着写算一层；像、如、似、仿佛、好似、跟什么一样都算带像字的比方，口语与成语式的夸张算不带像字；冷哼、叹气这类人自己出的声音算落在声音上，紧张时的身体反应不算；交锋是两个人之间有暗里对抗的那段对话，劝说与试探里有较劲的也算；输的一方是被逼走或认了亏的那个，没有明确输家的场不数退场；头一回露面按这一章读着像不像头一回判，重露面补一笔变化另记一笔；多场面的章挑的拍至多五个。
- 腔调变化：与上一章比叙述者的口气、述演比、句子长短变没变；你这一批的头一章对着量尺表前一章那一行的数比，第 1 章写无。

## 不写

- 情节、人物做了什么、谁和谁的事。人物名字只在定位时用。
- 对书的评价。
- 引原文一处不超过十五个字，只为定位；check-plan 超了报。
- 派工之外的章。

## 交付

一章一张卡写到派工给的目录，文件名 `第N章.md`，标题行 `# 读法卡 · 第N章`，UTF-8 无 BOM、LF。交之前自跑：

```
node "$SKILL/scripts/check-plan.js" 书/师承/读法/{书名}/
```

零 error 再交。回复只报：几张卡；每章一句最值得学的讲法；你拿不准的三处（一句一处）。
