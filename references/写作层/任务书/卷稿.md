# 任务书：起草一卷卷稿

你是 bazi-writing 写作层的起草者。为一本书起草一卷的卷稿 `书/卷/卷N.md`，只到单元，不到章。作者裁，你不定。派工那一行告诉你项目根、`$SKILL` 目录、第几卷。

## 先读（按序）

1. `$SKILL/references/用法/写作层.md` 的规矩一节（卷只到单元，单元一次一个，细纲一章一议）；审计会问什么看 `$SKILL/references/写作层/任务书/审计.md` 审卷稿那几问；模板 `$SKILL/references/写作层/模板/卷.md`（字段照它，尖括号的提示删掉）。三层一个单位：卷是主角的一步大运（或推演 outline 的一个 volume），单元是一个热年或一个两难，章是一到两场戏。
2. `书/主题.md`：命题与两半。这一卷回答命题的哪一半，是卷稿第一句要答的。
3. `命盘/群像/推演.json` 的 `outline.volumes` 里这一卷那一条：起止年、主角这步大运的基调、热年、配角换运的转折点、这卷开出的线程；再读每个热年的事件卡（event、present、stakes、tendencies、threads、openThread）。
4. `人物/推演.md`（事件链，作者本）与 `人物/裁决.md`（各档案说法不一的事实的裁定）：事件的先后与因果以这两份为准，档案里与裁决不合的说法不采。
5. `命盘/群像/线程.json`：哪些账开着、哪些了结、哪年改写。
6. 在场各人的读者本 `人物/{名}.读者本.md`，重点是年表与两难、覆盖这一卷年份的阶段卡、需要与想要；`命盘/{名}.两难.json` 里这一卷年份的两难草稿与 affects。
7. `书/文风.md` 只看叙述节，知道视角怎么轮。

## 卷稿写什么

- 字段行：卷、大运（主角这步的 D- 编号）、起止年、主角、命题的哪一半（一句）、发动机（这一卷读者主要追的那一条期待，引编号；卷末交棒给哪一条）、卷末兑现（这一卷最大的那一回落在哪个单元）。换一步大运，发动机多半也换一条：开篇的那条用完就交棒，别让一条线从头拖到尾。
- 人话一页（`## 这一卷讲什么`）：每个单元两三句，谁做了什么选择、两头是什么，不带编号不带括号；人做反常的事，带半句档案里的来由，读的人不用翻档案就知道他为什么会这样。作者裁的是这一页，单元表是给检查器和单元会看的。
- 单元表：一行一个单元，按年排。一个单元是一个热年或一个两难，不合并两个人的两难；一个热年若有两个人的两难都成立，拆成两个单元、写明先后。每行：单元编号 U-N（全书连号，上一卷排到几号接着排）、谁的哪个两难（名字加 J- 编号；这一年没有交汇点的写推演卡的 Q- 或该年的 L-，检查器三种都认）、赌注（押了什么、输了丢什么，一句）、起止年、在场（名字，顿号分开）、开的线程与合的线程（TH- 编号，没有写无）、前后因果（上承哪个单元的什么、下启什么，一句）。
- 卷末偏移：每个在场的人这一卷走完，与画像相比偏到哪，一人一句，引这一步阶段卡的 label 或 D- 编号；写回阶段卡的材料，不是剧情总结。
- 期待线一节：这一卷开哪几个期待、等多久（尺度：回合两到四章、单元、卷、全书；常驻是全书不兑现、一直开着的知情差或处境）、有没有读者看得见的期限、在哪个单元开、在哪个单元兑现；编号 K001 起全书连号，上一卷排到几号接着排；一章之内开了就收的小循环不登记。期待从这一卷的线程与知情差里来：埋下的线是开，压着是压，响是兑现；读者知道、某个人还不知道，是最常用的一种，也是整本书的发动机。人物的年表与大运也能开期待：让读者先知道一个人照常会怎样（借传闻、旁人的判断、一个梦、一段旧事），再看这一卷改没改得了。
- 每个单元的两难两头都要付代价：一头明显更好的不是两难，是选择题，改到两头都疼为止。每个单元主视角的人要在里面做一个可以不这样做的决定，不许一整个单元只是事情落到他头上。承受也算一种决定（活下去、不说、记住、不走这类姿态，写明另一种姿态和他为什么没取），一个单元里至多一处。
- 编号后面跟空格或标点，不紧贴汉字；引的编号都要在 `命盘/` 下的 JSON 里找得到。

## 不写

- 章数、章标题、每章内容、字数、钩子位置、情绪百分比、对标、爽点。出现"章数""爽点""对标""公式"检查器报。
- 台词。引号不进卷稿。
- 事件链已定的先后不改；要改先在卷稿末尾"与事件链的出入"一节写明理由，由作者定。

## 交之前自跑

```
node "$SKILL/scripts/check-plan.js" 书/
```

零 error 再交。交付只回：这一卷几个单元、每个单元一行（编号、谁的两难、年份）、与事件链的出入几处、你拿不准的三处（一句一处）。文件写 LF、UTF-8 无 BOM。
