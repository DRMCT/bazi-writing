# 任务书：起草一卷卷稿

你是 bazi-writing 写作层的起草者。为一本书起草一卷的卷稿 `书/卷/卷N.md`，只到单元，不到章。作者裁，你不定。派工那一行告诉你项目根、`$SKILL` 目录、第几卷。

## 先读（按序）

1. `$SKILL/references/用法/写作层.md` 的规矩一节（卷只到单元，单元一次一个，细纲一章一议）；审计会问什么看 `$SKILL/references/写作层/任务书/审计.md` 审卷稿那几问；模板 `$SKILL/references/写作层/模板/卷.md`（字段照它，尖括号的提示删掉）。三层一个单位：卷照编配的时间尺度分（长跨度的书一卷约主角的一步大运，短跨度与回到关口年照编配主脑表的段，一卷是事件链的一卷骨）；单元是一个热年、一个两难，或一局（一场宴、一口钟上的日子、一个找上门的单元客、一条到点的默认下场）；章是一到两场戏。
2. `书/主题.md`：全书一问、开篇、命题与两半；乐子与爽感节奏两节（有就读：这本书许的调子，主角的赢与亏怎么交替、亏多久打回）。这一卷回答命题的哪一半，是卷稿第一句要答的。
3. `人物/编配.md`：全书一问、主脑（这一卷落在哪一段）、时间尺度、对子表、主次、谁碎、默认下场（透哪几条、第几段透、应验还是改）、前史、钟、物件账、开篇。
4. `人物/推演.md`（事件链，作者本）这一卷：先读卷首的骨（为哪一人一事、起承转合、高潮年、响、清算、卷末的问题），再读每一年的源、因、步、选择、知情、线程、默认下场、主线温度、读者；`人物/裁决.md`（各档案说法不一的事实的裁定）。事件的先后、因果与来路以这两份为准，档案里与裁决不合的说法不采。
5. `人物/梗概.md` 这一卷那一页：卷稿人话页的底稿，作者读过、冷读过的就是它。
6. `命盘/群像/推演.json`：`outline.volumes` 里这一卷那一条（起止年、高潮候选、这卷开出的线程）；每个热年的事件卡（event、present、stakes、tendencies、threads、openThread、sources）；短跨度的书读 monthGrid（哪个月挂哪口钟、谁的流月被引动），有单元客读 guests，默认下场读 fate。
7. `命盘/群像/线程.json`：哪些账开着、哪些了结、哪年改写。
8. 在场各人的戏用页 `人物/{名}.戏用页.md`：要什么、谁挡着与横着的东西、怎么去要与先手后手、信的那句话、碰哪里会疼与破、跟谁怎么交手；覆盖这一卷年份的阶段卡（`人物/状态/{名}/{年}.md`，看"手里有什么"）。
9. `书/文风.md` 只看叙述节与附魅节，知道视角怎么轮、读者怎么爱上主角与感情线上的人。

## 卷稿写什么

- 字段行：卷、段（编配主脑表的哪一段）、大运（长跨度的书写主角这步的 D- 编号，短跨度与回到关口年写无）、起止年、主角、命题的哪一半（一句）、发动机（这一卷读者主要追的那一条期待，引编号；卷末交棒给哪一条）、卷末兑现（这一卷最大的那一回落在哪个单元）。开篇的那条发动机用完就交棒，别让一条线从头拖到尾；长跨度的书换一步大运，发动机多半也换一条。
- 骨一节：照事件链这一卷的骨落到单元上：为哪一人一事，起承转合各落在哪个单元，高潮在哪个单元，哪颗雷响、哪条账当面清算，卷末的问题。另写三条：
  - 落下风：编配的每一段，主角在哪个单元真吃一回亏或被逼到只差一步。出手的是谁（对手、家里人、自己这边的人、一条规矩、一个到点的局），他为自己的什么所图，用的是他戏用页第三问的哪样手段，丢的是两人之间横着的哪样东西（第二问）。事件链写好了的照它落；几段出自同一个人、同一种手段的，写进"与事件链的出入"交作者。
  - 打回：主题卡有爽感节奏一节的，每回落下风配一个打回：在哪个单元、谁打回、在人前还是暗里，多半同一个单元就回；一桩要几个单元才清的长账另登期待，挂着的那几个单元人话页写她各赢在哪。承受落下的那个单元，她在别处照样有一处赢。没有这一节写无。
  - 破：这一卷谁破、在哪个单元、哪一级（漏、说破、碎）、谁来破。几个人的破挨在一段里的，谁来破分开：不全出自主角一张嘴，有的靠物证递到手上，有的靠第三人，有的由期限或局逼出来；被破的那一头先扛一阵。碎的人照编配的谁碎，一人全书一回。
  - 默认下场：这一卷透、应验、改哪几条（DF- 编号），各落在哪个单元，怎么透给读者（记得、梦、传闻、卦、旁人的判断）；先透后兑现。
- 人话一页（`## 这一卷讲什么`）：底稿是梗概这一卷那一页，落到单元上，每个单元两三句：谁做了什么、结果和他想的差在哪；有两难的写两头是什么，是一局的写局上押的是什么、主角怎么赢或怎么输；不带编号不带括号；人做反常的事，带半句来由（从他戏用页里取），读的人不用翻档案就知道他为什么会这样。主题卡许了轻松调子的书，每个单元再写半句乐在哪（照乐子一节），一卷的乐子不全靠调剂章撑；主题卡有爽感节奏一节的，每个单元写她赢在哪，不许一个单元从头亏到尾。感情线上的人出场的单元，写半句读者在哪又多爱他一回（照文风卡附魅一节）；他给主角的亏只在私下，当众给她亏的是对头与主子。作者裁的是这一页，单元表是给检查器和单元会看的。
- 单元表：一行一个单元，按故事时间排。单元的来路照事件链那一年的源一栏写：十种之一起头（热年出事、默认下场到点、过去追上来、对手出招、家人出招、得知与认出、主角布局、局与日历、旁人求上门、关系自己往前走），几种用顿号分开，分号后写是哪一件。短跨度的书一个热年底下常排几个单元，单元从钟、对手出招、得知与认出里来，不硬凑热年；长跨度的书一个热年一个单元，余下的来路补在年与年之间。两难一栏只在事件链的选择一栏把两难给了这一单元时写（名字加 J- 编号，没有交汇点引推演卡的 Q- 或该年的 L-），一个单元只写一个人的两难，一个热年两个人的两难都成立的拆成两个单元、写明先后；没有写无。每行另写：单元编号 U-N（全书连号，上一卷排到几号接着排）、赌注（押了什么、输了丢什么，一句）、起止年（短跨度写到月）、在场（名字，顿号分开）、开的线程与合的线程（TH- 编号，没有写无）、前后因果（上承哪个单元的什么、下启什么，一句）。
- 两难与局：主角全书只一两回真两难，其余的两难给配角、对手、单元客，他们的往往更狠。有两难的单元两头都要付代价，一头明显更好的是选择题，改到两头都疼为止；两头的代价被一个包袱、一个知情差或本来就不想要消掉的是假两难，可以用，写明是被什么消掉的。主角的单元可以是打脸局：他必赢，看点是怎么赢，赢的那一步从他自己的手段里来。每个单元主视角的人要在里面做一个可以不这样做的决定，不许一整个单元只是事情落到他头上。承受也算一种决定（活下去、不说、记住、不走这类姿态，写明另一种姿态和他为什么没取），一个单元里至多一处。
- 卷末偏移：每个在场的人这一卷走完，与这一卷开头相比偏到哪，一人一句，引这一步阶段卡的 label（长跨度的书可引 D- 编号）；写回阶段卡的材料，不是剧情总结。
- 期待线一节：这一卷开哪几个期待、等多久（尺度：回合两到四章、单元、卷、全书；常驻是全书不兑现、一直开着的知情差或处境）、有没有读者看得见的期限（编配的钟常是现成的期限）、在哪个单元开、在哪个单元兑现；编号 K001 起全书连号，上一卷排到几号接着排；一章之内开了就收的小循环不登记。期待从这一卷的线程、知情差与默认下场里来：埋下的线是开，压着是压，响是兑现；读者知道、某个人还不知道，是最常用的一种，也是整本书的发动机。编配透给读者的默认下场是预告式的期待：读者先知道一个人照常会怎样，再等它应验还是被改。
- 编号后面跟空格或标点，不紧贴汉字；引的编号都要在 `命盘/` 下的 JSON 里找得到。

## 不写

- 章数、章标题、每章内容、字数、钩子位置、情绪百分比、对标、爽点。出现"章数""爽点""对标""公式"检查器报。
- 台词。引号不进卷稿。
- 事件链已定的先后不改；要改先在卷稿末尾"与事件链的出入"一节写明理由，由作者定。

## 交之前自跑

```
node "$SKILL/scripts/check-plan.js" 书/
```

零 error 再交。交付只回：这一卷几个单元、每个单元一行（编号、来路、两难或无、年份）、每段主角落下风在哪个单元、在哪个单元打回、与事件链的出入几处、你拿不准的三处（一句一处）。文件写 LF、UTF-8 无 BOM。
