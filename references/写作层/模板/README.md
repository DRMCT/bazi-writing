# 书/ 的模板与字段

写作层的产物全在作者项目根下的 `书/`，与 `命盘/`、`人物/` 并列。这里是每个文件的模板；开新书时整目录拷过去，尖括号里的提示填完删掉。

| 模板 | 落到 | 谁写 | 检查器 |
|---|---|---|---|
| 主题.md | `书/主题.md` | 作者与模型一起，开书时；全书一问与开篇照编配 | check-plan 查写法轮廓在轮廓表里、目标读者、命题非空、乐子一节与爽感节奏一节在场（warn）、装置表的编号、类型（物件、重复句、意象、回声）、认法、全书上限与碰的上限，重复句每人至多一句（谁一栏）；check-prose 读装置表数次数，白名单、重复句与回声放行照抄 |
| 文风.md | `书/文风.md` | 模型起草作者改，细纲、检查、润色读，写手不读；附魅一节开书时从频道卡（`references/频道/`）挑几条抄进来 | check-plan 查十一节在场（附魅缺了只报 warn）、对白节无引号、阈值表是数；check-prose 读阈值表 |
| 附魅.md | 一本 `书/师承/读法/附魅/{书名}.md`，汇总 `书/师承/读法/附魅/汇总.md` | 可选一路：题材不在频道卡适用范围里、或作者想换样本时，作者挑三到六本，附魅代理拆（任务书 `../任务书/附魅拆书.md`）；汇总前两栏进文风卡附魅一节 | 不查；读法/ 下不算照抄来源，文本 `书/师承/附魅/` 算 |
| 卷.md | `书/卷/卷N.md` | 模型起草作者裁 | check-plan 查字段（段或大运：长跨度写大运，短跨度与回到关口年写段，照编配的时间尺度报 warn）、骨与落下风（warn）、单元表每行有来路（空 error，没认出一种源 warn）、两难写了要引编号（warn）、编号在池里、章数与借鉴字样；期待线的编号、尺度、期限，发动机与卷末兑现（warn） |
| 单元.md | `书/单元/U-N.md` | 三个走法三个子代理起草，作者选 | check-plan 查来路（空 error，没认出一种源 warn；两难可写无）、三个走法在场且『谁做选择』互不相同、作者选了才查章表、每章一句功能非空；选定后查兑现一行（warn）；主题卡有爽感节奏一节时查章表的赢亏一栏（warn）；章表的回合栏定回合，回合末章的钩子要兑现或设钩（warn） |
| 细纲.md | `书/细纲/第N章.md` | 起草代理排（任务书 `../任务书/细纲.md`），审计审，作者过目 | check-plan 查字段（主视角在在场里、时候、不是正叙的书要有位置）、无引号、决定非空、在场与知情表一人一行末行读者、场表的人在在场里且至少一场走一根线（谁的五拍）、赌注非空（没引编号 warn）、物件编号在装置表里且全书不超上限、重复句写落在第几场（warn）、在场的人那一年已出生、借鉴字样与逐点字数；物件写了碰的按碰的上限数；演的场转折一对正负、读者担心、对面要什么与怎么去要，破的级与碎一人一回（warn）；期待一节（编号或 章内，开、压、推、兑现、落空、搁置，松紧、调剂；主题卡有乐子一节时查乐子一栏，连着三章写无报；主题卡有爽感节奏一节时查赢亏一栏，按章数赢亏：一章赢 0 info，连着两章赢 0、连着四章亏多于赢、开篇十章亏多于赢 warn）与钩子类型，并按章号对账（warn） |
| 种子.md | `书/种子/第N章.md` | 细纲代理照细纲写（任务书 `../任务书/细纲.md` 写种子一节），审计一并核；写手只读它与上一章 | check-plan 不查；check-prose 把它当照抄来源，与细纲一样短串 warn、长串 error |
| 龙套.md | `书/龙套.md` | 模型起草作者改 | check-plan 认表里的称呼为在场，放进场表的五拍报 error；check-prose 把称呼折成一个字。没有盘的人只有这一行；开始做选择就升成只有命盘的配角 |
| 口味.md | `书/口味.md` | 主会话从改稿对照归出、作者改；跨书带着，开新书从上一本拷过来 | 暂不查 |
| 改稿对照.md | `书/会/改稿对照/第N章.md` | 作者亲手改过一章后主会话整理，作者过目为什么一栏；润色拿它当样子 | 暂不查 |
| 回纲会.md | `书/会/回纲/第N次.md` | 模型列作者定 | 暂不查 |
| 追踪/在场与知情.json | `书/追踪/在场与知情.json` | 检查提案，进正文后主会话照定稿登；facts 一栏是前后要接得上的事实，细纲、种子、检查照它接 | check-plan 查进了正文的章登没登；投影随 N4 做 |
| 追踪/登记.json | `书/追踪/登记.json` | 检查提案，进正文后主会话照定稿登 | check-plan 查进了正文的章登没登；投影随 N4 做 |
| 追踪/期待.json | `书/追踪/期待.json` | 检查提案，进正文后主会话照定稿登；主题卡有爽感节奏一节的书另登 tally（主角逐章的赢亏） | 计划那头 check-plan 按细纲的期待一节对账；这份是定稿后的记录；进了正文的章 tally 登没登（warn），逐章赢亏登了的照它数 |

正文落 `书/正文/第N章.md`，每一稿留底 `书/稿/第N章.vK.md`；这两处没有模板，正文文件只有标题行加正文。

## 写法

- 字段行写成 `- 字段：值`，放在标题下、第一个 `##` 之前；小节标题用 `## `，表用 markdown 表。检查器只认这三种形状。
- 编号后面跟空格或标点，不要紧贴汉字（`J-310-甲-乙 的两难`，不是 `J-310-甲-乙的两难`），否则检查器切不出编号。
- 所有文件是作者本，可以带 J-、TH-、Q-、L-、D-、DF-、PH- 编号；正文一个不带，由 check-terms 兜底。
- 主题的写法轮廓行选 `references/写作层/轮廓.json` 里的哪张表（现在只有 webnovel），文风的阈值表逐项覆盖它。
