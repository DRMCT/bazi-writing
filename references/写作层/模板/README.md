# 书/ 的模板与字段

写作层的产物全在作者项目根下的 `书/`，与 `命盘/`、`人物/` 并列。这里是每个文件的模板；开新书时整目录拷过去，尖括号里的提示填完删掉。

| 模板 | 落到 | 谁写 | 检查器 |
|---|---|---|---|
| 主题.md | `书/主题.md` | 作者与模型一起，开书时 | check-plan 查写法轮廓在轮廓表里、目标读者、命题非空、装置表的编号、类型、认法、全书上限与碰的上限；check-prose 读装置表数次数、读白名单放行照抄 |
| 文风.md | `书/文风.md` | 模型起草作者改，写手每章读 | check-plan 查十节在场、对白节无引号、阈值表是数；check-prose 读阈值表 |
| 卷.md | `书/卷/卷N.md` | 模型起草作者裁 | check-plan 查字段、单元表每行有 J-、编号在池里、章数与借鉴字样；期待线的编号、尺度、期限，发动机与卷末兑现（warn） |
| 单元.md | `书/单元/U-N.md` | 三个走法三个子代理起草，作者选 | check-plan 查三个走法在场且『谁做选择』互不相同、作者选了才查章表、每章一句功能非空；选定后查兑现一行（warn）；章表的回合栏定回合，回合末章的钩子要兑现或设钩（warn） |
| 细纲.md | `书/细纲/第N章.md` | 起草代理排（任务书 `../任务书/细纲.md`），审计审，作者过目 | check-plan 查字段（主视角在在场里、时候、不是正叙的书要有位置）、无引号、决定非空、在场与知情表一人一行末行读者、场表的人在在场里且至少一场走四拍、赌注引 J- 或 TH-、物件编号在装置表里且全书不超上限、在场的人那一年已出生、借鉴字样与逐点字数；物件写了碰的按碰的上限数；期待一节（编号或 章内，开、压、推、兑现、落空、搁置，松紧、调剂）与钩子类型，并按章号对账（warn） |
| 龙套.md | `书/龙套.md` | 模型起草作者改 | check-plan 认表里的称呼为在场，放进场表的四拍报 error；check-prose 把称呼折成一个字。没有盘的人只有这一行；开始做选择就升成只有命盘的配角 |
| 回纲会.md | `书/会/回纲-第N次.md` | 模型列作者定 | 暂不查 |
| 追踪/在场与知情.json | `书/追踪/在场与知情.json` | 读稿代理抽作者过目 | W4 |
| 追踪/登记.json | `书/追踪/登记.json` | 读稿代理抽作者过目 | W4 |
| 追踪/期待.json | `书/追踪/期待.json` | 读稿代理抽作者过目 | 计划那头 check-plan 按细纲的期待一节对账；这份是定稿后的记录 |

正文落 `书/正文/第N章.md`，每一稿留底 `书/稿/第N章.vK.md`；这两处没有模板，正文文件只有标题行加正文。

## 写法

- 字段行写成 `- 字段：值`，放在标题下、第一个 `##` 之前；小节标题用 `## `，表用 markdown 表。检查器只认这三种形状。
- 编号后面跟空格或标点，不要紧贴汉字（`J-310-甲-乙 的两难`，不是 `J-310-甲-乙的两难`），否则检查器切不出编号。
- 所有文件是作者本，可以带 J-、TH-、Q-、L-、D- 编号；正文一个不带，由 check-terms 兜底。
- 主题的写法轮廓行选 `references/写作层/轮廓.json` 里的哪张表（现在只有 webnovel），文风的阈值表逐项覆盖它。
