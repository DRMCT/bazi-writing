# 神煞叙事标签表

生成：2026-09-23，来源 `scripts/bazi_core/tables/shensha_tags.json`（17 种神煞、118 个变体）。

用途：人物档案「特色标签」的取材。命盘层由 `shensha_tags.for_chart` 按落柱、十二宫、同柱神煞、旬空、六冲、十神、性别、重数求值，命中的变体带编号进人物档案作溯源。「古籍判词」逐字取自校核卡的位置变体栏（出处随之）；「叙事标签」是自起草的译法，不是古籍原意，可反用、可弱化，作者是天。没有古籍判词的条目出自 DESIGN 附录 B。

条件写法：pillar = 神煞落在哪一柱：year 年、month 月、day 日、hour 时；列表中任一柱命中即可；stage = 日干在该神煞所在支的十二宫：生旺 = 长生、冠带、临官、帝旺；死绝 = 死、墓、绝；其余不判；with = 同柱另见的神煞名列表，须全部同柱；empty = 该柱地支为日柱旬空；clash = 该柱地支与他支六冲；god = 该柱天干或支本气的十神在此列表内；gender = 男 / 女，命主性别；未指定则两性皆用；count = 该神煞落柱数不少于此值；unlisted = true 表示条件不判，标签只在解读层按原句参考
