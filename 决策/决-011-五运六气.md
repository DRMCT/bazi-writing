#### 旧 7.4 五运六气：生年底子

问题（2026-09-24-8，作者提）：五行体质与气质底色表只按日主五行分五行，再叠五条寒暖燥湿修正，同一日主的人物体质必然撞车，写着就重复。五运六气按年干支加出生所值之气分，与日柱正交：同一个日主换个生年就换底子，六十年乘六步三百六十格，再乘日主五行与调候。

裁决（作者按建议）：做，但只喂"体质与外貌暗示"和"气质底色"两个字段，不碰用神、格局、十神性格；它是《内经》的医学覆盖层，不是第二个命理流派，"子平为主、调候为辅"不变。分工：运气给底子（易伤的脏腑、体格、生年大环境），调候给缺什么（寒暖燥湿修正照旧），日主五行给句法。两者重叠时同向叠加、反向成表里（寒盘生在寒水主政的年份写寒上加寒；寒盘生在君火相火主政的年份写外热内寒；燥盘同理，燥上加燥、外湿内燥），四条叠加行在表里。

口径：

- 盘面照作者自己的排盘项目：岁运按年干化五行、阳年太过阴年不及；司天在泉按年支组；客气六步司天居三之气、在泉居终之气；主气固定；交气以大寒为岁首每 60° 一步，边界用 almanac.term_time（两仓同一套公式，实测 1700、1986、2026 三年大寒到微秒相同）。年关系天符、岁会、天符兼岁会、同天符、同岁会、岁运与司天的五种生克结构、岁运与在泉的五种（同即同天符同岁会）、岁运与当步客气的五种（本仓推演，见下文交感）、客主加临五种、二火的君臣顺逆，都是查表可得的五行结构，作为事实给模型；顺化、天刑、小逆、不和一类带吉凶的后世名目不采。平气（岁运太过被司天克、不及得司天同气或年支之助）是后世推演，表里单列一行，给"平和底子"，不是每个人物都该有显著体质。六微旨"岁会，气之平也"按字面八个岁会年皆平，其中戊午、甲辰、甲戌、丙子四个太过之年不在后世十五年内；裁决从方宜口径，两者分列，"气之平"落在岁会那行修正（偏性归正），不并进平气。
- 岁半之法：初二三之气司天为纲，四五终之气在泉为纲；两行都进命盘，为纲的标出，另一头作背景。
- 主运客运（五步）不做：方宜自己的先天报告把它权重压到最低，客运太少两说并存，五步边界（黄经 12°、84°、156°、228°）与月柱无关、架空历定不出。归 v2。
- 现实历按出生时刻定运气年与步。运气年以大寒翻年、年柱以立春换年，大寒到立春之间生的人两者不同，命盘记 yunqiYearDiffers，运气盘面按运气年干支。
- 架空历只有四柱：年干支能定岁运、司天在泉、客气六步；哪一步要看年内位置。六气以中气交气、月柱以节换月，寅辰午申戌子六个月整月在一步内，卯巳未酉亥丑跨两步。跨步的月默认取中气后一段（与调候 periodUnresolved 同口径）并标 stepUnresolved；丑月例外，大寒后翻到次年运气年、年干支随之换，默认不翻年，作者用 `--yunqi-step 次年初之气` 指定；其余月给 `--yunqi-step 初之气…终之气` 或 1 到 6。
- 编号 YQ-：年主干（YQ-年-干支）、岁运、平气、司天、在泉、出生所值之气（步乘客气）、加临、君臣、五种年关系、运与司天（运天）、运与在泉（运泉）、运与当步（运步）、上临、叠加。人物档案的体质与气质底色引 YQ- 加 DM、Y-，至少引到主干、体或主之一。
- 校核：七篇论岁气与民病，没有"某年生人禀某气"之文，生年推底子是后世运气家的引申；卡的引文只抄民病与气化，叙事译法与表的三栏自起草并标明。去术语词表收司天、在泉、六气名、六步名、岁运名、天符岁会一类词为 error；客气、平气、太过、不及这些常用词不收，运气一词只提示。
- 副产品（2026-09-25 落地）：年景表 tables/yunqi_year.json（narrative-table/v1，三十行一对干支一行；主色标签按规则：岁运太过取本气、不及取乘它的那一气，上下半年按司天在泉，六步气候与疫季据卡；年景一句与疫季一句自起草，两个子代理各十五行、主会话审），投影 references/五运六气年景.md。yunqi.year_qi 出 scene，年表每年带 yearScene 标签，年度状态卡与群像事件卡带整句，同一年所有人物共享；只给场景打底不给人物用。

交感（2026-09-24-9，作者提）：岁运、司天、在泉、主气、客气原是分开出行的，作者问中医里气是相互交感的，是否应合看。捋下来经文有明文：五运行"上下相遘，寒暑相临，气相得则和，不相得则病"；六元正纪"天气不足，地气随之，地气不足，天气从之，运居其中而常先也"，六十年纪一年一条把上（司天）中（运）下（在泉）写在一起，太过之年正化日、不及之年胜复同为邪气化日并记灾宫；六政之纪按司天之政逐运给其运、其化、其变、其病；气交变太过不及之纪里岁运的病象被司天改写（土太过"上临太阳……病反腹满肠鸣溏泄"，火太过"上临少阴少阳……病反谵妄狂越"，木不及上临阳明、土不及上临厥阴、水不及上临太阴，共五对十二年）；至真要"主胜逆，客胜从"，六微旨"君位臣则顺"。经文的合看是有主次的结构合成，不是六个平行因子相加，也不是三百六十格的叙事表。原实现结构上已合（六步行据六元正纪按年支组写，本身含当年天地之气；岁半定纲；运与司天五种；加临五种；同化四种；平气；与调候叠加），叙事上没合：六条并列的体质句、修正行只说"底子"与"季节"不说谁压谁，模型自己捏合、方式不稳定，司天在泉行与六步行又把同一股气写两遍。

裁决（作者按建议，按此顺序做）：

1. 定主次，改输出顺序。运为体（岁运通主一年）、纲气为主（岁半之法定的那一头）、当步之气为用、修正为改写、另一头作背景。yunqi 节 features 按此排，hits 每条带 role，顶层 roles 按角色列编号；背景那一头只给气化与民病，不给体质句。check-character 加一条：引了 YQ- 的特质至少引到主干、体或主之一，只引背景与修正报出来。SKILL 与体质表头部写明捏合顺序：一句主干加一句当步加一句改写，不是六句并列。
2. 补两组关系行。运与在泉四种生克（同即同天符、同岁会，归年关系；出生在岁半之后的人以此为改写、运与司天作背景），运与出生所值之步客气五种（本仓推演，卡上标存疑；三之气、终之气的客气即司天、在泉，不另判）。盘面卡加运与在泉、运与当步两张，修正表加九行，机器表 relations 加两节，夹具手推补录。
3. "上临"进表。岁运卡的引文与采用规则里已有气交变的五对，表上原来没栏；岁运表加上临三栏（上临之司天、上临则气化与病反、上临的改写），只在司天对上时带出 YQ-上临-{司天}，十二年。
4. 本年气象主干。六元正纪六十年纪与六政逐运列法按对合写，一对干支（相隔三十年，运与司天在泉全同）一条、三十条，不做六十条（两年只差年支，岁会与否在年关系里）；卡 运气_六十年.md 七张（总卡与六政各一张），机器表 sixtyYears，体质表 sixty 分表三十行，据卡栏从语料抽（癸巳癸亥六十年纪语料缺，据巳亥之纪，化数留空），生年底子一句与气质一句自起草（两个子代理各十五行，主会话审），编号 YQ-年-{干支}，排在 features 最前作主干。太过十五对全正化、不及十五对全邪气化这条规律给写作层用：正化的年份底子做主、路数一贯，邪气化的年份先弱后反弹。
5. 样例重生成、换盘对照重跑、去术语词表收正化、邪气化、灾宫、胜复、同正、太一天符。

不做的：三百六十格手写叙事表（质量塌，经文也没这么写）；运太过先天不及后天把交气边界挪约十三日（后世口径，经文只说至先至后，只影响现实历边界附近的人）；主运客运；胜复郁发单列一栏（容易过度）。归 v2 待办。

病秧子问题（2026-09-24-10，作者提）：交感做完一数，体质栏九十三行里八十九行带病症词，沈砚一张盘从运气节拿到二十个不适短语，人人是病秧子。根子是语料本来是医书，"民病"说的是那一年天下人易得什么病，是岁气的倾向，不是那年生的人身上一定有什么；上一轮任务书让子代理"民病落到身子"，又五层叠加。经文自己有门：五运行"气相得则和，不相得则病"，六微旨"天符为执法，其病速而危；岁会为行令，其病徐而持；太一天符为贵人，其病暴而死"，六十年里相得与不加不临的年份该是"和"。民病里的情志词（善怒、悲忘、狂越、恐）同理，都是发作状态，放进气质会人人脾气怪。

裁决（作者提思路，讨论后定）：五运六气是给模型的疾病与情志事件参考，不是体质表。病在写作里是偶发事件，健康是默认，作者要用才用。分两层：

- 画像层只给**体格与体感**（身量、气色、皮肤干润、怕冷怕热、手脚温度、动作节律，据卡从五常政的其化其德其候与司天在泉、六步的气化取，不带病）和**一句薄弱处**（哪个脏腑先累着，写成习惯不写成症状，是画像层通向事件层的钩子）。气质底色不再从运气取，仍由十神性格、日主五行、调候给。
- 事件层给**疾病与情志候选**：什么病（受邪之脏、民病、甚则、死不治之候）、多重（严重档：相得与平气为和，不相得与岁会同岁会为显，太过之年天符太一天符同天符为危；太过者暴、不及者徐）、垮的时候往哪个方向垮（情志方向取民病里的情志词，无则按受邪之脏的五志通则，与薄弱处同一个脏）。什么时候得病要三层交汇：生年运气给薄弱处与档，故事年运气给那年那季流行什么（yunqi.year_qi 按流年干支查同一张表，六元正纪写明温厉、厉大至、善暴死、温病的步为疫季），八字年表给哪一年身心域被引动、多烈。年表只在身心域被引动的年份挂 L-…-病候，把三层写在一条里；流年司天或在泉克薄弱脏的年份标加重（五行通则，推演）。默认不写进人物档案，作者挑；一步大运最多一次，一条故事线最好只有一次主崩溃。
- 写作上的道理：读者判人物情绪不稳定，看的是发作有没有来由、章法、后果、多不多，不是有没有发作；一年一次、方向一贯、有前因后果的发作相反而让人物显得稳。

实现：yunqi_body.json 重排成九张分表（六十年主干、岁运、平气、司天在泉、六步、修正、叠加为画像层，疾病与情志候选、严重档为事件层），画像层的自起草栏重写并加硬规则：一个病症词都不许有；事件层可用病症词，不用医家病名。yunqi 节加 events（grade、tempo、organ、zhi、illness、mood、shangLin），编号 YQ-档-、YQ-病-、YQ-志-、YQ-上临-，role 事件；timeline 在身心域被引动的年份加 L-{岁}-{流年}-病候；check-character 对事件类编号不施主干规则。
