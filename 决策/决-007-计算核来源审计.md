  yunqi.py              五运六气（第 7.4 节）：盘面与年关系从作者的项目方宜搬入，对《素问》运气七篇卡；体质表自起草
  chart.py              统一入口：出生信息或四柱 → 命盘档案 JSON

旺衰用确定性算法的理由：反推搜索必须能对几十万个候选盘打分，且结果可复现。临界盘打标记，让模型在解读时补一句判断。

### 旧 附录 A：审计时的实测记录

- Python 3.14.5、Node 24。sxtwl 无 3.14 轮子，安装失败。
- tyme4py 与 lunar_python 在 3.14 上均可运行。tyme4py 的大运入口是 `ChildLimit(birth_time, gender)` 构造函数。
- tyme4py 地支只有冲、合、害三种关系方法，没有刑与破。神煞只有黄历日神煞，没有八字神煞。
- yueyuan-bazi 的 mingli_rules.py 明确不做旺衰最终判定，只给四个布尔标志；调候表自注"待核对"。
- zhexue-shushu 的旺衰打分只有强弱二分，没有中和区间；不算通根；不考虑调候。采用时补这三项。
- china-testing/bazi 是 1900 行单文件 CLI，逻辑与 print 混在一起，仓库无许可证。
